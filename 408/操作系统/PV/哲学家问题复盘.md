- 【问题描述】有**5个哲学家**共用1张圆桌，他们分别坐在圆桌周围的5把椅子上。在圆桌上有5个碗和**5根筷子**，他们的生活方式是交替地进行思考和进餐。哲学家**饥饿时**会试图取用左右两边最靠近自己的筷子，**只有在拿到2根筷子时才能进餐**（筷子需要**逐根拿起**）；**进餐毕**，**立即放下持有的两根筷子**，继续思考。

- **要求**：使用**信号量**和P、V操作（或wait()、signal()）描述以上同步或互斥关系，并说明所用信号量的作用和初值。
- 哲学家进餐问题无需演草。套用三种解决方案之一即可。

- 无论是什么类型的信号量，其值表示的就是**某类资源当前的可用数量**。（⭐⭐）

- 筷子是**临界资源**，在一段时间内只允许1位哲学家使用。
	- **每根筷子的位置不同**，本质上**不是同一类资源**。（⭐）
	- 因此，**5根筷子应该设置5个信号量**，其初始值为1，代表当前可用资源数量为1。
	- 为了便于进程访问，定义一个**信号量数组chopstick[5]**。
		- `chopstick[i]` 表示$哲学家i$**左手边**的筷子，`chopstick[(i+1)%5]` 表示$哲学家i$**右手边**的筷子。

- 同步关系：进程**与自身的同步关系**，哲学家必须等待左右两根筷子都可用才能进餐；吃完后**释放筷子并唤醒等待的邻居**。
	- 进程**与自身的同步关系**需要使用互斥信号量
- 互斥关系：进程**与自身的互斥关系**，每根筷子同一时刻只能被一个哲学家使用，相邻哲学家对同一根筷子的访问互斥。

- 方法①：仅当哲学家的**左右两根筷子均可用**时，才允许他拿起筷子进餐。
	- 也就是**一次性拿完左、右筷子**，也可以使用AND型信号量实现。
	- 在拿筷子时，其他哲学家不能拿，构成互斥。
```cpp
semaphore chopstick[5] = {1, 1, 1, 1, 1};
semaphore mutex = 1;
void philosopher_i()
{
	while(1){
		P(mutex);
		P(chopstick[i]);
		P(chopstick[(i+1)%5]);
		V(mutex);
		
		进餐;
		
		V(chopstick[i]);
		V(chopstick[(i+1)%5]);
		
		思考;
	}
}
```


- 方法②：**限制同时拿筷子的人数**，**最多4个人同时尝试进餐**。
	- 确保了**至少有一人能获得两根筷子**。
```cpp
semaphore chopstick[5] = {1, 1, 1, 1, 1};
semaphore seat = 4;
void philosopher_i()
{
	while(1){
		P(seat);
		P(chopstick[i]);
		P(chopstick[(i+1)%5]);
		
		进餐;
		
		V(chopstick[i]);
		V(chopstick[(i+1)%5]);
		V(seat);
		
		思考;
	}
}
```

- 方法③：对哲学家进行编号，规定**奇数号哲学家**先拿左筷、再拿右筷，**偶数号哲学家**先拿右筷、再拿左筷。
```cpp
semaphore chopstick[5] = {1, 1, 1, 1, 1};
void philosopher_i()
{
	while(1){
		if (i % 2 == 0)
		{
			P(chopstick[(i+1)%5]);
			P(chopstick[i]);
		}
		else
		{
			P(chopstick[i]);
			P(chopstick[(i+1)%5]);
		}
		
		
		进餐;
		
		V(chopstick[i]);
		V(chopstick[(i+1)%5]);
		
		思考;
	}
}
```
