- 【问题描述】系统中存在**一组生产者进程**和**一组消费者进程**，它们共享**一个初始为空、容量为n的缓冲区**。
- 消费者每次从缓冲区**取出一个产品**并进行消费。生产者每次**生产一个产品**，并将其放入缓冲区。
- 该问题需满足以下约束条件：仅当**缓冲区未满**时，生产者才能**放入产品**，否则必须等待；仅当**缓冲区非空**时，消费者才能**取出产品**，否则必须等待；**缓冲区是临界资源，所有进程必须互斥访问**。

- 要求：使用信号量和P、V操作（或wait()、signal()）描述以上同步或互斥关系，并说明所用信号量的作用和初值。

- 演草：
```c 
// 先用中文描述。
// 有两类进程：分别是生产者进程和消费者进程，要写两个函数。
生产者()
{
	// P什么？无需P
	生产产品
	
	// P什么？
	P(缓冲区的空位)
	// 有隐藏的互斥关系：访问缓冲区需要互斥
	P(互斥)
	访问缓冲区，将产品放入缓冲区
	V(互斥)
}

消费者()
{
	// P什么？
	P(缓冲区的满位)
	// 有隐藏的互斥关系：访问缓冲区需要互斥
	P(互斥)
	访问缓冲区，将缓冲区中某个产品取出
	V(互斥)
	
	// P什么？无需P
	消费产品
}
```
