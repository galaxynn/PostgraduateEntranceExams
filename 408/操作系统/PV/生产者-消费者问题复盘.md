- 【问题描述】系统中存在**一组生产者进程**和**一组消费者进程**，它们共享**一个初始为空、容量为n的缓冲区**。
- 消费者每次从缓冲区**取出一个产品**并进行消费。生产者每次**生产一个产品**，并将其放入缓冲区。
- 该问题需满足以下约束条件：仅当**缓冲区未满**时，生产者才能**放入产品**，否则必须等待；仅当**缓冲区非空**时，消费者才能**取出产品**，否则必须等待；**缓冲区是临界资源，所有进程必须互斥访问**。

- **要求**：使用信号量和P、V操作（或wait()、signal()）描述以上同步或互斥关系，并说明所用信号量的作用和初值。

- 生产者、消费者之间既有**同步关系**，又有**互斥关系**。

- **同步关系**体现在：生产者生产产品，消费者才有产品消费；消费者消费产品，生产者才有空位存放产品。
- **互斥关系**体现在：生产者、消费者要互斥访问临界资源（缓冲区）。

- 演草：
```c 
// 先用中文描述。
// 有两类进程：分别是生产者进程和消费者进程，要写两个函数。

// 注意：一个资源需要对应一个信号量，因为需要挂到对应资源的阻塞队列中，等什么资源就挂到什么资源的阻塞队列中。
// 缓冲区的大小为 n
缓冲区的空位 = n // 初始时，缓冲区全空，空位为n个
缓冲区的满位 = 0 // 初始时，缓冲区没有满位，为0个

互斥 = 1 // 用于互斥访问缓冲区，初始值通常为

生产者()
{
	// 注：动作是不断重复的
	while(1){
		// P什么？无需P
		生产产品
		
		// P什么？P了之后立刻找V的位置
		P(缓冲区的空位)
		// 有隐藏的互斥关系：访问缓冲区需要互斥
		P(互斥)
		访问缓冲区，将产品放入缓冲区
		V(互斥)
		V(缓冲区的满位)
	}
}

消费者()
{
	// 注：动作是不断重复的
	while(1){
		// P什么？P了之后立刻找V的位置
		P(缓冲区的满位)
		// 有隐藏的互斥关系：访问缓冲区需要互斥
		P(互斥)
		访问缓冲区，将缓冲区中某个产品取出
		V(互斥)
		V(缓冲区的空位)
		
		// P什么？无需P
		消费产品
	}
}
```

```c 
int in=0, out=0;
item buffer[n];

semaphore empty = n;
semaphore full = 0;

semaphore mutex = 1;

void producer()
{
	while(1){
		item nextp = produce(); // 生产产品nextp
		
		P(empty);
		P(mutex);
		buffer[in] = nextp; //访问缓冲区，将产品放入缓冲区
		in = (in + 1) % n
		V(mutex)
		V(full);
	}
}

void consumer()
{
	while(1){
		P(full);
		P(mutex);
		nextc = buffer[out]; //访问缓冲区，将产品从缓冲区中取出
		out = (out + 1) % n
		V(mutex);
		V(empty);
		
		consume(nextc); // 消费产品nextc
	}
	
}

// 可选
void main()
{
	cobegin
	producer(); consumer();
	coend
}
```
