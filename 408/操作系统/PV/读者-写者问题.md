【问题描述】：  
- 系统中存在**两组并发进程**：**读者**和**写者**，它们**共享一个数据文件或记录**。**多个进程可同时读该文件**，但**任何写操作都必须与其他读/写操作互斥**。根据不同调度优先级策略，分为以下**两种变种**：
- 变种一（第一读者-写者问题 / **读者优先**）：  
    不让读者等待。若**已有读者在访问文件**，后续到达的读者**即使在有写者等待的情况下，也可立即进入读文件**。写者只有在**所有读者退出后**才能访问文件（可能导致**写者饥饿**）。
- 变种二（第二读者-写者问题 / **写者优先**）：  
    一旦写者就绪，尽可能快地执行写操作。若**已有写者在排队等待**，**后续到达的新读者将被阻塞**，不允许开始读操作，直到写者完成写操作退出（可能导致**读者饥饿**）。

```cpp
semaphore rw = 1;

void reader()
{
	while(1)
	{
		P(rw);
		读文件
		int fd = open(".\file");
		read(fd);
		close(fd);
		V(rw);
		
	}
}

void writer()
{
	while(1)
	{
		P(rw);
		写文件
		int fd = open(".\file");
		write(fd);
		close(fd);
		V(rw);
	}
}
```
