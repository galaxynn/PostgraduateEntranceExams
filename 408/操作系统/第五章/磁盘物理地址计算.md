- 注意：**簇号**、柱面/磁道号、盘面/磁头号、扇区号都**默认从0开始编址**。
	- 从 0 开始编址的本质目的之一，就是为了**让逻辑地址与整数除法（商和余数）完美契合**，**无需任何偏移修正**。
	- 从0开始编址, 则**全部采用下取整，取模就是偏移量**。

- 物理地址三元组为：**(柱面号 C, 磁头号 H, 扇区号 S)**。

- **逻辑地址**转**物理地址计算**：
	- 注意单位，这里的逻辑地址是“**逻辑簇号**”。
	- 也可以先转为“**逻辑扇区号**”再算，结果一样。
    - **方法：自顶向下层级分解法**
        - 每个**柱面**有 2000 个扇区，对应 $2000 / 2 = 1000$ 个簇：
            - **柱面号C** = $\lfloor 100530 / 1000 \rfloor = \mathbf{100}$
            - **柱面内偏移簇数** = $100530 \pmod{1000} = 530$
        - 每个**磁道**有 200 个扇区，对应 $200 / 2 = 100$ 个簇：
            - **磁头号H**（磁道号）= $\lfloor 530 / 100 \rfloor = \mathbf{5}$
            - **磁道内偏移簇数** = $530 \pmod{100} = 30$
        - 每个簇占 2 个扇区：
            - **起始扇区号S** = $30 \times 2 = \mathbf{60}$（该簇占用 60 和 61 两个扇区）

- 已知地址，算**逻辑扇区号**（为第几个扇区，从0开始编号）：
- $$逻辑扇区号（LBA）= C×(磁头总数×每道扇区数)+H×每道扇区数+S$$
- 根据**逻辑扇区号**算**逻辑簇号**：
	- $簇号=⌊\frac{LBA}{每簇扇区数}⌋$
	- 先算“逻辑扇区号（LBA）”，再**换算为逻辑簇号**，**不容易错**。


- 假设每组（每个柱面）包含 $N$ 个**单元**（簇）：
#### 1. 从 0 开始编址（0-based，计算机标准）（常考）
各组容纳的编号区间如下：
- **第 0 组**：$0, 1, 2, \dots, N-1$
- **第 1 组**：$N, N+1, \dots, 2N-1$
- $\dots$
- **第 $k$ 组**：$k \cdot N, k \cdot N + 1, \dots, k \cdot N + (N-1)$

对于任意编号 $x$：
- **组号（柱面号）**：**$\lfloor x / N \rfloor$**（即整数除法 / 向下取整 `x // N`）
- **组内偏移量**：**$x \pmod N$**（取余数）

> **极简小例子**：假设每组 $N = 10$ 个元素：
> - 编号 $0 \sim 9$：$\lfloor 0/10 \rfloor = 0, \lfloor 9/10 \rfloor = 0$ $\implies$ 均在 **0 号组**。
> - 编号 $10 \sim 19$：$\lfloor 10/10 \rfloor = 1, \lfloor 19/10 \rfloor = 1$ $\implies$ 均在 **1 号组**。
> - 规律严格处处成立，整除商直接就是组号。


#### 2. 对比：如果从 1 开始编址（1-based，日常人类习惯）
如果组号从 1 开始，编号也从 1 开始：
- **第 1 组**：$1, 2, \dots, N$
- **第 2 组**：$N+1, N+2, \dots, 2N$

如果此时直接用向下取整：
- 算编号 $1$ 时：$\lfloor 1 / N \rfloor = 0$（错误！应该是第 1 组）
- 算编号 $N$ 时：$\lfloor N / N \rfloor = 1$
此时边界会错位。对于 1 开始编址的情况，通常有两种算商方式：
- **方式一（向上取整）**：组号 = $\lceil x / N \rceil$
- **方式二（先转 0 基准）**：组号 = $\lfloor (x - 1) / N \rfloor + 1$


### 二、 为什么 408 和硬件体系中全部采用 0 编址？

这不仅是数学公式好看，底层对应的是**硬件位运算（Bit Slicing）**：

在硬件电路中，如果 $N$ 是 2 的幂次（例如 $N = 2^k$）：
- **组号（高位）**：直接通过逻辑右移 $k$ 位（`x >> k`）截取高位，**位运算右移天然等价于向下取整**。
- **组内偏移（低位）**：直接通过掩码（`x & ((1 << k) - 1)`）截取末尾 $k$ 位。

> **总结口诀**：
> - **0 起始**：组号直接**向下取整（整除）**，偏移直接**取模**。
> - **1 起始**：必须“**减一折回 0 空间计算，最后再加一**”，或者用**向上取整**。


## 从0到1

> **核心口诀**：
> - **若仅簇号从 1 开始，硬件地址从 0 开始**：必须先算 $\text{簇号} - 1$，再求 $(C, H, S)$，此时高位中位都不会变。
> - **若硬件各级坐标 $(C, H, S)$ 也强制从 1 开始**：先在 0 空间算好 $(C_0, H_0, S_0)$，最后映射为 $(C_0 + 1, H_0 + 1, S_0 + 1)$。
