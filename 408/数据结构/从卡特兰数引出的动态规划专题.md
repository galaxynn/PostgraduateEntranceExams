
可以用动态规划解决的问题的特性：
- 最优子结构：原问题的最优解可以由子问题的最优解推出。
- 重叠子问题：递归拆解时，同一个子问题会被反复遇到多次。
- 无后效性：当前状态一旦确定，后续决策只依赖当前这个状态，不关心之前是怎么走到这个状态的。
## 问题1：当n个不同的元素按固定次序入栈时，可能的出栈序列总数为多少？

- 令 f(n)：n 个不同的元素按固定次序入栈，可以得到的总的出栈序列个数。
- 思路：考虑最后一个出栈的元素。
- 易知：f(0) = 1（设定好的）, f(1) = 1
- n=2 时，假设入栈序列为 A B
- 若 A 最后一个出栈，则 A 前方的 0 个元素都要出栈，后方的 1 个元素都要出栈，可能的出栈序列总数为 f(0) * f(1) 【乘法原理】
- 若 B 最后一个出栈，则 B 前方的 1 个元素都要出栈，后方的 0 个元素都要出栈，可能的出栈序列总数为 f(1) * f(0)【乘法原理】
- 综上，根据加法原理，得 f(2) = f(0)f(1) + f(1)f(0) = 2 个

-  n=3 时，假设入栈序列为 A B C
- 若 A 最后一个出栈，则 A 前方的 0 个元素都要出栈，后方的 2 个元素都要出栈，可能的出栈序列总数为 f(0) * f(2) 【乘法原理】
- 若 B 最后一个出栈，则 B 前方的 1 个元素都要出栈，后方的 1 个元素都要出栈，可能的出栈序列总数为 f(1) * f(1)【乘法原理】
- 若 C 最后一个出栈，则 C 前方的 2 个元素都要出栈，后方的 0 个元素都要出栈，可能的出栈序列总数为 f(2) * f(0)【乘法原理】
- 综上，根据加法原理，得 f(3) = f(0)f(2) + f(1)f(1) + f(2)f(0) = 5 个

- 根据数学归纳法，f(n) = f(0)f(n-1) + f(1)(n-2) + ... + f(n-2)(1) + f(n-1)(0)
- 上式，即卡特兰数的递推式。

## 问题2：总节点个数为 n 的二叉树，一共有多少种形态？
- 令f(n)：n个节点的二叉树，存在的形态总数。
- 思路：从根节点考虑。当前状态的根节点作为未来状态的子树的根节点。
