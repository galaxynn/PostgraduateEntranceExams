### 时间复杂度
定义：时间复杂度描述算法执行时间随问题规模 n 增大而变化的趋势，是关于 n 的渐进函数。

算法执行时间由**语句频度（某条语句的执行次数）** 来衡量。

设 T(n) 为算法中**所有语句**的频度之和。

n足够大时（趋于正无穷时），低阶项和常数对 T(n) 的影响可以忽略。
因此，我们只需关注 T(n) 中增长最快的项，而它对应着算法中**执行次数最多**的语句（一条或多条）。一般为最深层循环内的语句。

记为：T(n) = O(f(n))

分析多个代码段组成的程序时，可用以下规则进行分析：
加法规则：T(n) = T(n1) + T(n2) = **O(f(n)) + O(g(n)) = O(max(f(n), g(n)))**
乘法规则：T(n1) * T(n2) = **O(f(n)) * O(g(n)) = O(f(n) * g(n))**

### 空间复杂度
定义：算法在运行过程中所需的**额外**存储空间。

记为：S(n) = O(g(n))

输入数据所占空间只取决于问题本身，与算法无关，不计入空间复杂度。
指令，常数和与 n 无关的变量所占空间不随问题规模变换，不计入时间复杂度。

因此，在分析空间复杂度时，只关注**额外使用的辅助空间**（递归调用栈，临时辅助数组等）。


### 时间复杂度分析方法论
单层循环：
1. 通过循环的条件判断语句，找出循环结束的情况。以此确定出 循环变量 i 和 n 的关系。
	- 例如：$while (i * i < n)$ 最后情况：$i^2 = n$ ①
2. 设出总循环次数 t，列举表格，找到循环变量 i 和 t 的关系。
	- 例如：$while(i * i < n) \ \ i \ *= 2;$  关系：$i = 2^t$ ②
3. 最后根据①和② 用 n 表示出 t，即可得到时间复杂度。
	- 例如：$i = \sqrt{n} = 2^t, t = log{\sqrt{n}},$


多层循环：
- 各层的循环变量**均无依赖关系**
	- 时间复杂度为各层复杂度相乘。

- 各层的循环变量之间**存在依赖关系**
	- **定义法**（**求和符号嵌套**）：统计**最内层语句**的执行次数。
	- 需要设出循环次数为 k 的情况：`i += c, i *= c`，找规律，用 n 表示出 k。
	- 循环次数 k 即为求和总项数，利用求和公式求和。
