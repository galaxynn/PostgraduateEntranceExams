
## B树的定义
- B树的阶数，即**分叉数**。
- $k$个**关键字**，对应$k+1$棵**子树**。
- 一颗**m阶B树**或为**空树**，或为满足以下特性的**m叉树**（$m\ge2$）：
	1. 每个结点**最多有m棵子树**（即**最多**包含m-1个关键字）。（**m叉树**的性质。）
	2. 若**根节点不是叶结点**，则**最少**有2棵子树（即**最少**包含1个关键字）。
	3. 除根节点外，所有**非叶结点**最少有$\lceil \frac{m}{2} \rceil$棵子树（即**最少**包含$\lceil \frac{m}{2} \rceil－1$个关键字）。
	4. 每个**非叶结点**的结构
		-  $n|P_0|K_1|P_1|K_2|P_2|\dots|K_n|P_n$
		- 其中，
		- $n$为该结点中关键字的个数
		- $K_i$为关键字，且满足$K_1<K_2<\dots<K_n$
		- $P_i$为指向子树根节点的指针。指针$P_{i-1}$所指子树中所有关键字均小于$K_i$，指针$P_i$所指子树中所有关键字均大于$K_i$，小于$K_{i+1}$。
	5. **所有叶结点**都出现在**同一层次**上，且不实际存储数据，可视为查找失败的**外部节点**。（作用类似于折半查找判定树中的**失败结点**。）
		- 注：**统考真题**将B树的叶结点定义为**最底层终端结点**，而非外部叶结点(失败结点)。

- 要对B树的定义**熟稔于心**。
- 基于以上定义，B树有以下性质：
	1. 每个结点**所有的子树的高度都相同**。（平衡）
	2. 若B树中**一共**有$n$个**关键字**，则必有$n+1$个**外部叶结点**。
	3. 任意结点的子树个数＝关键字数＋1。
	4. 下层子树中的所有关键字均落在由上层结点关键字划分出的对应区间内（开区间）。
	5. 所有外部叶结点均位于最底层。

- B树各结点所包含子树、关键字个数归纳表：

|      | 子树个数                            | 关键字个数                               |
| ---- | ------------------------------- | ----------------------------------- |
| 根节点  | [2, m]                          | [1, m-1]                            |
| 非叶结点 | [$\lceil \frac{m}{2} \rceil$,m] | [$\lceil \frac{m}{2} \rceil-1$,m-1] |

## B树的查找
- 在B树上进行查找与二叉排序树相似，不同的是：B树中，每个结点都是多关键字的有序表。在该结点上所进行的是**多路分支决策**，而非二路分支决策。
- B树通常存储在**磁盘**上，要**依据想读取的目标结点的磁盘地址**，将结点**读入内存**，才可以在该结点的有序表中进行查找。

- B树的查找过程：
	1. 从**根节点**开始比较。
	2. 将结点从磁盘**读入内存**，在结点内的多关键字有序表中，使用**顺序查找或折半查找**：
		- 若找到目标关键字，**查找成功**。
		- 若未找到目标关键字，根据对应指针的信息，**定位下一个**要读入内存的结点，获取其**磁盘地址**，重复步骤2。若查找到**叶结点**，则说明树中不存在该关键字，**查找失败**。

## B树的高度
- B树通常存储在**磁盘**上，由B树的查找过程可知，因此所需**磁盘存取次数与树的高度成正比**。

- 注意：B树的高度**不包含**最底层**外部叶结点所处的那一层**。
- 假设存在一棵包含n个关键字，高度为h，阶数为m的B树：
	1. 最小高度情形：总关键字数固定时，每个结点的关键字数达到最大值时，B数的高度最小。对于m阶B树，每个结点最多包含m－1个关键字，最多有m棵子树。
		- 下面默认：1个结点有m-1个关键字，m棵子树。（最多）
		- 第一层：1个结点，m-1个关键字。有m棵子树。
		- 第二层：m个结点，m*(m-1)个关键字。有$m\times m = m^2$棵子树。
		- 第三层：$m^2$个结点，$m^2*(m-1)$个关键字。有$m\times m^2 =m^3$棵子树。
		- 第h层：$m^{h-1}$个结点，$m^{h-1}*(m-1)$个关键字。无子树。
		- 所以，高度为h的B树最多包含$n=(1+m+m^2+m^3+\dots+m^h-1)(m-1)=m^h-1$个关键字。
		- 由不等式$n \le m^h-1$，得$h \ge \log_m(n+1)$，则最小高度为$\log_m(n+1)$。

	2. 最大高度情形：总关键字数固定时，每个结点的关键字数达到最小值时，B数的高度最大。根节点最少1个关键字，非叶结点最少$\lceil \frac{m}{2} \rceil$个关键字。
		- 令 $d = \lceil \frac{m}{2} \rceil$
		- 下面默认：根节点有1个关键字，2棵子树；其余非叶结点有$d-1$个关键字，d棵子树。(最少)
		- 第一层：1个结点，1个关键字。有2棵子树。
		- 第二层：2个结点，2*(d-1)个关键字。有2d棵子树。
		- 第三层：2d个结点，2d*(d-1)个关键字。有$2d^2$棵子树。
		- 第h层：$2d^{h-2}$个结点。$2d^{h-2} \times (d-1)$个关键字。无子树。
		- 所以，高度为h的B树最少包含$n=1+(2+2d+2d^2+\dots+2d^{h-2})(d-1)=2d^{h-1}-1$个关键字。
		- 由不等式$n \ge 2d^{h-1}-1$，得$h \le \log_d(\frac{n+1}{2})+1$，则最大高度为$\log_d(\frac{n+1}{2})+1$。

- 综上所述，$\log_m(n+1) \le h \le \log_d(\frac{n+1}{2})+1$。

|         | 最小            | 最大                        |
| ------- | ------------- | ------------------------- |
| 关键字数$n$ | $2d^{h-1}-1$  | $m^h-1$                   |
| 高度$h$   | $\log_m(n+1)$ | $\log_d(\frac{n+1}{2})+1$ |
