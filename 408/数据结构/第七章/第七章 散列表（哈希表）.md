
## 散列表的基本概念
- 散列表（哈希表）：**根据关键字直接进行访问**的**数据结构**，它建立了关键字到**存储地址**的直接映射。（**下标通常从0开始。**）
- 散列函数（哈希函数）：将关键字**映射**到其对应**存储地址**的函数，记为
$$
Hash(key)=Addr \ 或 \  H(key)=Addr
$$
- 其中，地址可以是**数组下标**，索引或内存地址。

- **冲突**：散列函数将两个或两个以上**不同的**关键字**映射到同一地址**的现象。
- **同义词**：这些**发生冲突的不同关键字**。

- 好的哈希函数应该尽可能减少冲突的发生，但**冲突总是不可避免**的，因此还要设计有效的**冲突处理方法**。
- 以上陈述，提供了两个角度：1、**减少冲突**的发生的方法。 2、**处理冲突**的方法。
- 下面，我们以这两个角度来展开。

## 散列函数的构造方法
- 在**构造散列函数**时，必须注意以下几点：
	1. 散列函数的**定义域必须包含全部关键字**，而值域的范围则取决于散列表的大小。
	2. 散列函数计算出的地址应**尽可能均匀地分布在整个地址空间**，以有效减少冲突。
	3. 散列函数应尽量简单，能在**较短时间内计算**出任意关键字对应的散列地址。

## 常用的散列函数
### 1.直接定址法
- 方法：
	- 直接取关键字的某个**线性函数值**作为散列地址，其散列函数为$$H(key)=key\ 或\ H(key)=a×key+b$$，其中$a$和$b$为常数。
- 该方法计算**最简单**，且**不会产生冲突**，适用于关键字**分布基本连续**的情况；否则会造成地址空间浪费。
### 2.除留余数法（最常用）
- 方法：
	- 设散列表长度为$m$，选取一个**不超过m且尽可能接近m**的**质数p**，通过以下公式将关键字映射为散列地址：$$H(key)=key ％ p$$
- 除留余数法的关键在于合理选择$p$，使得**地址空间分布更均匀**，从而尽可能减少冲突。
- 注意：模$p$后的**结果**落在$[0, p-1]$中。

### 3.数字分析法
- 方法：
	- 设关键字是**r进制数**，其各位上的数码（共**r**种）出现的概率可能不同：某些数位上数码分布较为均匀，各种数码出现的机会接近均等；而另一些数位上分布不均，仅有少数几种数码频繁出现。
	- 此时应选取那些**数码分布较为均匀的数位**，以其组合构成散列表。

### 4.平方取中法
- 方法：
	- 取**关键字平方值的中间几位**作为散列地址。具体取多少位根据散列表大小和关键字范围确定。

## 处理冲突的方法
- 任何散列函数都**无法绝对避免冲突**。
- **冲突处理机制**：为发生冲突的关键字**寻找下一个可用的散列地址**。
	- $H_i$：表示**第$i$次探测**所得的**散列地址**。
	- 初始地址：$H_0=H(key)$
	- 基本思想：若$H_0$发生冲突，则尝试$H_1$，...，若$H_k$发生冲突，则尝试$H_{k+1}$，直到找到**首个不发生冲突**的地址，将其作为当前关键字的存储地址（通常为**数组下标**）。

### 1.开放定址法
- 开放定址法是指散列表中的**所有空闲地址均可用于存放任意关键字**（无论是否与其同义）。
- 其**递增探测序列**由如下递推公式给出：	$$
		H_i=(H(key)+d_i) \% m
	$$	其中，$H(key)$为散列函数，$d_i$为第$i$次探测的**增量**，$0\le i \le m-1$，$d_0$恒为0。
- 注意：$H_i$是**基于初始地址的偏移**，而非递推公式。

- **一旦确定增量序列**，对应的冲突处理方法即被确定。
- **常见的增量序列取法**有以下四种：
	1. **线性探测法**，也称**线性探测再散列法**。增量序列$d_i=0,1,2,\dots,m-1$。
		- 特点：**顺序查看**表中下一个单元，可以探测到**所有地址**，但容易引发“**聚集**”现象，即原本映射到地址$i$的同义词被存入地址$i+1$，以此类推。导致**大量元素在相邻地址上堆积**，降低查找效率。
	2. **平方探测法**，也称**二次探测法**。增量序列$d_i=0,1^2,-1^2,2^2,-2^2,\dots,k^2,-k^2 (k\le m/2)$。
		- 其中，散列表长度$m$必须是一个形如$4k+3$的**素数**，**才能探测到所有地址**。
		- 特点：能**有效避免"堆积"问题**，是一种**较好的冲突处理方法**。缺点是**无法探测所有地址**，但至少可以覆盖**一半**的地址空间。
	3. **双散列法**。增量序列$d_i=iH_2(key)$。
		- 特点：该方法使用了**第二个散列函数**$H_2(key)$。当通过第一个散列函数$H(key)$得到的地址发生冲突时，使用**第二个散列函数**$H_2(key)$计算**地址增量**。
	4. **伪随机序列法**。增量序列由一个**伪随机产生器**产生，即$d_i=第i个伪随机数$。

- 注意：（⭐⭐）
- 采用**开放定址法**时，**不能直接物理删除**表中已有元素。否则可能**截断**其他同义词的查找序列，导致**查找失败**。
- **正确的做法是**，对被删除元素所在位置**设置一个删除标记**，即**逻辑删除**。且逻辑删除的位置**不被视为是空位置**。（⭐）
	- 也就是说，**无论是**计算ASL成功还是ASL失败，**当查找位置为删除标记时，应继续往后查找**。（**视删除而不见，将其视为一个正常关键字**。）


### 2.拉链法（链接法）
- ![[第七章 散列表哈希表拉链.png]]
- 为了处理冲突，可以将**散列到同一地址的所有同义词**组织成一个**链表**。（类似于**邻接表的存储结构**。）
- 每个链表由其对应的散列地址**唯一确定**。

- 若散列地址为$i$，则该同义词链表的**头指针**存放在散列表的第$i$个单元中。查找、插入和删除操作主要在**相应的同义词链表中**进行。

- 有$m$个散列地址就有$m$个单链表，同时用数组$HT[0…m−1]$存放**各个链表的头指针**，凡是散列地址为$i$的记录都**以节点方式插入**以$HT[i]$为头节点的单链表。

- 对于**各个同义词链表**，通常采用**头插法**。（**也可**尾插。）


## 散列查找及性能分析的应用
- 散列表的**查找过程**与**构造过程**基本一致。
- 对于**给定的关键字key**，先通过散列函数**计算其初始地址**，然后再按如下步骤进行：
	1. 初始化$Addr=H(key)$
	2. 检查散列表中地址$Addr$处是否有记录(**是否为空**)：
		- 若**无记录**，则**查找失败**（在**开放定址法**的ASL失败中，**计入**对比次数）。（⭐）
		- 若**有记录**，则**比较**该记录与key的值，若**相等**，则**查找成功**，否则转到步骤3。
	3. 按指定的**冲突处理方法**（开放定址法、拉链法）计算下一个探测地址，将Addr**更新**为此地址，返回步骤2。

- 散列表的**查找效率**主要取决于**三个因素**：**①散列函数、②冲突处理方法和③装填因子**。（⭐）
	- **装填因子**：通常记为$\alpha$，定义为散列表的**填充程度**。$$\alpha = \frac{表中记录数/关键字数n}{散列表总长度m}$$
	- 散列表的平均查找长度（ASL）**主要依赖于装填因子**$\alpha$，而**不直接依赖于**$n$或$m$。
	- 装填因子$\alpha$**越大**，关键字**越多**，**冲突越多**。装填因子$\alpha$**越小**，关键字**越少**，**冲突越少**。（⭐）

- ASL成功：**成功查找到表中各个关键字**所需的**关键字比较次数**的<u>加权平均值</u>，$p=\frac{1}{关键字数n}$。

- ASL失败：从**可以映射到**的**各个位置开始查找，查找到空位置（依据对应的冲突处理方法进行查找）**，所需的**比较次数**的<u>加权平均值</u>，$p=\frac{1}{散列表长度m}$。
	- 在**开放定址法**中，**空位置也计入1次比较**；而在**拉链法**中，空位置**默认不计入**比较次数。
	- 拉链法的查找，是**遍历对应的同义词链表**。
	- 计算ASL失败时，从**各个可能的位置开始**，**也要**依据所采用的冲突处理方法依次查找，直到查找失败。（**线性探测法是一直往后找**，**而其他的方法不一定**。）

## 开放定址法做题规范总结
1. 确定表长$m$，和哈希函数的模数$p$，装填因子$\alpha$等。
2. 表长为$m$，则**哈希表的下标地址**为$[0,m-1]$。
3. **画出以下表格**，**第二行**可以根据哈希函数所需的值，灵活调整。

| key              | 1   | 2   | 3   | ... |
| ---------------- | --- | --- | --- | --- |
| k*key            | k   | 2k  | 3k  | ... |
| H(key)=(k*key)%p |     |     |     |     |

- 将H(key)作为index，在**对应位置处填入key**。
- 若发生冲突，则使用对应的**冲突处理方法**，确定下一个位置。
- 注意**记录冲突次数**（草稿纸上），无冲突时，冲突次数为**0**。
- **成功查找到该关键字的比较次数＝冲突次数＋1**

- 注意：计算ASL失败时，**从各个可能的位置开始**，也要依据**所采用的冲突处理方法**依次查找，**直到查找失败**（**失败也计入一次比较**）。（线性探测法是一直往后找，而其他的方法不一定。）
	- 模数为$p$，则**查找失败的入口**为$[0, p-1]$。

| index    | 0   | 1   | 2   | ... | p-1 | ... | m-1 |
| -------- | --- | --- | --- | --- | --- | --- | --- |
| key      |     |     |     |     |     |     |     |
| 冲突次数(草稿) |     |     |     |     |     |     |     |
