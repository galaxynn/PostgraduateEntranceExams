
## 红黑树的定义 
- 为了保证AVL树的平衡，在插入和删除操作后，容易破坏其平衡特性（条件太严格），导致频繁调整树的拓扑结构。因此，红黑树在AVL树的平衡标准上进一步放宽条件。
- 口诀：**左根右，根叶黑，不红红，黑路同**。
- 一棵红黑树是满足如下**红黑性质**的**二叉排序树**：
	1. 每个结点**或是红色，或是黑色**的。（单重颜色）
	2. **根结点**是**黑色**的。
	3. **叶结点**（虚构的**外部结点**）都是**黑色**的。
	4. **不存在**两个**相邻的红结点**。
	5. 对每个结点，从该结点（**不含**该结点）到任意一个叶结点（外部结点）的简单路径上，所含**黑色结点的数量相同**。（这个数量被称为黑高，见下。）
- 红黑树是一棵二叉树，对于二叉树，n个节点，**必有n+1个外部节点**（空链域）。

- 结点的黑高：从某个结点出发（**不含**该结点）到达一个**叶结点**的**任意一个简单路径**上的**黑结点总数**称为该**结点的黑高**。
- 红黑树的黑高：即**根结点**的**黑高**。

- 结论1：从根到叶结点的最长路径$\le$最短路径的2倍。（左右子树高度相差最多2倍。）
	- 原因：
	- 根据性质5可知，从根到任意一个叶结点的**最短路径**一定**全由黑结点组成**，将根节点的黑高设为**bh**，其值等于该最短路径长度d。
	- 根据性质4和性质5可知，要保证黑高bh不变，到叶结点的最长路径必然是由黑结点和红结点**交替构成**的，此时红结点的数量**最多等于**黑结点的数量，即bh。则最长路径长度为bh+bh = d + d = 2d，恰好是最短路径的**两倍**。

- 结论2：含**n**个**内部结点**的红黑树，它的高度$h \le 2\log_2(n+1)$
	- 原因：
	- 根据结论1，从根到叶结点（不含叶结点）的任意一条简单路径上都至少有**一半是黑结点**，因此**根的黑高至少**为$h/2$。
	- 由此推出 $n\ge2^{h/2}-1$，得$h \le 2\log_2(n+1)$

	- 由此，可以继续推出，黑高为$bh$的红黑树的**内部结点数最少**是$2^{bh}-1$（满树状态，路径全黑），**最多**是$2^{2bh}-1$（满树状态，路径红黑交替）。

- 红黑色采用"适度平衡"策略，允许左右子树高度相差最多2倍，显著降低了插入/删除时结构调整的频率。
- 对于动态操作表：若插入/删除操作频繁，采用红黑树更合适；若查找操作频繁，采用平衡二叉树更优。

## 红黑树的插入
- 性质：**新插入的初始结点，着为红色**。
	- 若着为黑色，则会导致某条路径的黑节点数加1，违反了性质5，**调整代价大**。

- 红黑树的插入过程：
	1. 用**二叉查找树的规则**插入新结点，将其染为**红色**。然后，先判断父节点颜色。
		- 若插入后，其为**根节点**，染成**黑色**，树的黑高加1。
		- 若插入后，其为非根结点，且**父节点为黑色**，红黑树的性质**未被破坏**，插入结束。
	2. 若插入后，其为非根节点，且其**父节点为红色**。
		- 父节点为红色，核心：**看叔脸色**，**从爷结点开始判断**是什么型。
		- 黑叔：**从爷结点开始判断**类型，按照**AVL树的旋转调整方法**调整，最后再**染色**（颜色取反，原父节点染黑，原爷结点染红）。
		- 红叔：将**父**节点和**叔**结点染成**黑色**，将**爷**结点染为**红色**。
			- 爷结点变红后，可能与其父节点再次形成红－红冲突。
			- 将爷结点**视为新的"待调整结点"**，继续向上回溯检查。
			- 直到满足两个条件之一：
			- 1、待调整结点进入黑叔的情况，调整后结束。2、待调整结点成为根节点，染黑后结束。
