定义：仅允许在一段进行插入和删除操作的**线性表**。是一种操作（插入、删除）受限的线性表。
- 仅允许在**栈顶**进行插入(入栈)和删除(出栈)操作。

存储方式：顺序存储、链式存储。

### 顺序存储
采用顺序存储的栈称为顺序栈。

其栈顶指针(top)的位置有两种定义方式。
1. 栈顶指针指向当前栈顶元素。栈空：top = -1; 栈满：top = n - 1;
2. 栈顶指针指向栈顶上方的空位。栈空：top = 0; 栈满：top = n;

栈顶指针定义方式的不同，会使得判空、判满、入队、出队的条件判断不同。要根据具体问题具体分析。

若栈已满，但仍将元素入栈，则会发生上溢。解决办法：使用共享栈 或 链栈。

#### 共享栈
两个栈共用同一片连续空间。
栈顶指针指向各自的栈顶元素。初始时：top1 = -1, top2 = n; 栈满时：top2 - top1 == 1;

### 链式存储
- 栈顶在**首部**。

- 使用**头插法**将元素入栈，出栈也从首部移除元素。

- 带头节点和不带头节点均可。
- 默认不带头节点。
- 带头节点更方便进行头插法。操作更统一，无需特判。

#### 中缀表达式转后缀表达式
- 本人已经总结出来本质了，不用死记。

- 本人独创记忆法如下：

- 维护一个**运算符优先级严格单调递增的栈**（有点**单调栈**的思想。）
- 但是还要增加几点性质：
- 栈中可以**以左括号分隔**各段**严格递增子序列**。遇到左括号**直接入栈**，无需任何操作。
- 当遇到**右括号**时（右括号本身**不入栈**），需要**不断弹栈**，**直到遇到左括号**为止。（左括号也弹出。）
- 当前遍历到的运算符一定要入栈，同时需要保证运算符优先级严格单调递增。所以，当前遍历到的运算符优先级**相同或更低**时，弹出栈顶，直到遇到优先级**严格比它低**的运算符或**左括号**（因为左括号分隔各段递增子序列）为止。
