- 定义：队列也是一种操作受限的线性表，仅允许在表的一端进行插入，而在另一端进行删除。
- 特性：先进先出。
- 队首：允许删除，即出队的一端。队头：允许插入，即入队的一端。
- **核心：在队首删除，在队尾插入。**

- 要和栈做好区分。队列有两端能操作，而栈只有一端能操作。脑中要有大概的图像。
- 存储方式：顺序存储，链式存储。

### 队列的顺序存储
- 与**顺序栈**类似，分配一块**连续的存储单元**存放队列元素，并附设并维护两个指针，**front指针**和**rear指针**。
- 注意：入队 和 出队，两个指针**都是增加的**。**具体细节要看定义**。

- 为了解决**顺序队列假溢出**的问题，引入了**循环队列**。
- 假溢出：队列**仍有空闲空间**，而队尾指针达到MaxSize。

- 所谓**循环队列**，就是**利用模运算实现指针的循环**，将顺序存储空间**在逻辑上组织为环状结构**。

- 设 n = Maxsize，即数组总长度，**与队列实际长度无关**。

- 指针**自增**时，记得**取模**即可。
- **入队**，队尾指针进一：rear = (rear + 1) % n;
- **出队**，队首指针进一：front = (front + 1) % n; // **逻辑删除**
- **队列长度公式**：length = (rear - front + n) % n
- 实际上它们是**同余关系**，可以随意移项，用来求 rear 或 front 指针。
	- 即 length % n = (rear - front + n) % n -> front = (rear - length + n) % n

- front指针和rear指针在各题目的**指向定义不同**，需要依据题目条件，灵活判空、判满、计算队列元素等，无需死记硬背，而是**随机应变**。
- 基本思路是：**维护这两个指针的定义不变**，判空和判满条件**不可一致**。

- 引入循环数组后，我们将**无法得知** rear == front 时队列是**空还是满**，**解决方法**：
1. <u>牺牲一个存储单元</u>，**若数组长度为 n，则队列最大长度为 n - 1**。
	- 牺牲的那个存储单元是队首指针front的**前一个**存储单元，即使得 (rear + 1) % n == front 的 rear指针 指向的那个存储单元。（**常用**）
2. 在**队列的结构体**中，<u>增设 size 成员</u>，用于记录 **当前队列长度**，size == 0 时队空，size == n 时队满，而不用牺牲空间。（方便）
3. 在**队列的结构体**中，<u>增设 tag 标志位</u>，表明最近一次操作的类型（0表示出队，1表示入队）。
	- 若 tag == 0 && rear == front，则说明队空。
	- 若 tag == 1 && rear == front，则说明队满。


- **最常见**的循环队列定义：
	- front指向**队首元素**，rear指向**队尾元素的下一个位置**。
	- **队空**条件：rear == front
	- **队满**条件：(rear + 1) % n == front (<u>牺牲一个存储单元</u>)

- 做题方法：**画图**（**环形图**，注意<u>区分队首和队尾</u>），**灵活举例子**：队列中**只含一个元素**时指针的指向，**队列满时**的指针的指向。
	- 以此来**判断采用了以上哪一种解决方法**，从而得到判空和判满的条件。（前提：<u>判空和判满条件不可一致</u>。）

### 队列的链式存储
 - **带头节点**和**不带头节点**。（默认**带头节点**）

 - 本质是一个**同时带有队首指针和队尾指针的单链表**。
 - 维护front指针和rear指针。
	 - front指向**链首节点**（第一个，不区分是否是头节点）
	 - rear指向**链尾节点**（最后一个）。

 - 首部**出队**（链表删除节点），尾部**入队**（链表插入节点）。

### 双端队列
- 定义：允许在**两端**进行插入和删除操作的线性表。两端的地位是平等的。

- <u>变体</u>：**输入受限的双端队列**， **输出受限的双端队列**。

- 做题**核心思想**：**模拟**。

- **输出受限**双端队列做题方法：依据**输入序列的顺序**，<u>往左右两边添加序列中的元素</u>，可以**快速判断**是否合法。
