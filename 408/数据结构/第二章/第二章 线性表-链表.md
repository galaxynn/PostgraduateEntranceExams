- 定义：链表既线性表的链式表示。通过一组**任意(不要求地址连续)的存储单元**来存储线性表中的数据。通过指针域链接各个存储单元。
- 分类：单链表、双链表，循环单链表、循环双链表，静态链表。

- 注意：做题时，若未具体指明，则默认含头节点。
- 头指针和头节点区别：头指针始终指向第一个节点，头节点是为了便利插入和删除设置的不含实际有效数据的辅助节点。

- 补充：
1. 链式存储结构比顺序存储结构能**更方便**地表示各种逻辑结构。
2. 若题目给出一个数组，求时间复杂度，则**默认数组无序**（最坏情况）。
3. 对于任意链表L，L本身是一个**头指针（head）**，指向头节点，**值**是**头节点的地址**。
4. 注意区分**设置指针**（如设置头指针、尾指针）和**设置指针域**（如p->next = q）。

- 注意：**循环链表**尾节点rear->next = L; 一定指向**第一个节点**，**有头节点就指向头节点**。

- 插入、删除操作的**核心**：找到**前驱节点**。但这不意味着每次都要找到前驱节点，有特殊情况不需要找前驱节点，如不带头节点的链表，删除首节点，则无需找到前驱节点。

- 做题时，多多**画图**，不然脑子容易转不过来。
- 两个链表交叉（如a1, b1, a2, b2, ...）合并，时间复杂度为 $O(min(m, n))$，而非 $O(m + n)$

### 单链表
- 脑海有图。
- 带头节点判空：L->next = NULL
- 不带头结点判空：L = NULL
- 技巧（算法题可能会用）：若数据可复制，可以通过**交换数据**，O(1)实现**前插和删除**的操作。（**给定节点**的情况下。）
### 循环单链表
- 脑海有图。
- 带头节点判空：L->next = L，头节点指针都指向自己
- 不带头结点判空：L = NULL
### 双链表
- 脑海有图。
- 带头节点判空：L->next = NULL 或 L->prior = NULL，若**规范**则两者同时成立。
- 不带头结点判空：L = NULL
### 循环双链表
- 脑海有图。
- 带头节点判空：L->next = L 且 L->prior = L，即头节点指针都指向自己。
- 不带头结点判空：L = NULL

### 静态链表
- 应用：**操作系统的FAT表**，即文件分配表。
- 本质：结构体数组。
- 指针"域"指向对应节点的数组下标。 
- 不能随机存取。仍然按照遍历链表的方式顺序存取、插入、删除。
- **内存空间连续**的链式存储结构，大小固定。
