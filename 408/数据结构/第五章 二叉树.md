
## 二叉树的定义和性质
P129	
- 定义：**二叉树**是一种特殊的树形结构，其核心特征在于：每个结点**至多**拥有**两棵**子树，即不存在度大于2的结点。且这两棵子树**具有明确的左右之分**，其次序是固定的，**不可交换**。
- 二叉树也是树，也以递归的方式定义。
- 二叉树是包含 $n (n\ge0)$ 个结点的有限集合：或者为**空二叉树**，或者由**一个根节点**以及两颗互不相交的被称为**根的左子树和右子树**构成，且左右子树本身也是二叉树。
- 二叉树属于**有序树**，若交换某结点的左右子树，则会得到另一棵不同的树。若某个结点仅有一棵子树，也要区分它是左子树还是右子树。

- **度为2的有序树**和**二叉树**有着本质区别：
	- 度为2的有序树至少包含3个结点，而二叉树可以为空。
	- 度为2的有序树，若某个节点只有一个孩子，则无需区分左右次序。而在二叉树中，子树的左右位子都是确定且不可省略的，仍要区分左右子树。

- 性质：
	1. **非空二叉树**的叶结点数**等于**度为2的结点数加1，即 $n_0 = n_2 + 1$。(⭐⭐⭐)
	2. **非空二叉树**的第$i(1 \le i \le h)$层**最多**有$2^{i-1}$个结点。
	3. **高度**为$h$的二叉树**最多**有$2^h - 1$个结点。

## 特殊的二叉树
### 满二叉树
- 定义：一棵高度为$h$且包含$2^h-1$个结点的二叉树称为**满二叉树**。它的每一层都含有该层所能容纳的最大结点数。
- 特征（性质）：
	1. 所有**叶结点**（度为0的结点）均位于**最后一层**（第 $h$ 层）。
	2. 只有度为0和度为2的结点，**不存在度为1的结点**。
	3. 第 $i (1≤i≤h)$ 层**必有**$2^{i-1}$个结点。

### 满二叉树和完全二叉树的编号规则
- 可对**满二叉树或完全二叉树**按**层序**进行编号：约定**根节点编号为1**，**自上而下，自左向右**依次编号。
- 在此编号规则下，对于编号为 $i$ 的结点，若存在双亲，则双亲编号为 $\lfloor \frac{i}{2} \rfloor$；若**存在**左孩子和右孩子，则左孩子编号为 $2i$，右孩子编号为 $2i+1$。注意：左右孩子存在时才可用此公式，题目可能在此设下陷阱。

### 完全二叉树
- 定义：高度为$h$且包含$n$个结点的二叉树的**每个节点**与高度为h的满二叉树中**编号**为$1 \sim n$的结点**一一对应**时，称为**完全二叉树**。
- 满二叉树是特殊的完全二叉树。
- 特征（性质）：
	1. 完全二叉树的$1 \sim h-1$层，必为一棵**满二叉树**。
	2. **叶结点**只可能存在于第$h$层和第$h-1$层。（最后两层。）
	3. 若存在**度为1的结点**，则**最多只可能有一个**，即 $0 \le n_1 \le 1$；且该结点只有左孩子而无右孩子，即该结点为**最后一个分支结点**。由此可得：由 $n_0 = n_2 + 1$，且 $n = n_0 + n_1 + n_2$，可推出 $n = (2n_2 + 1) + n_1$，其中 $2n_2 + 1$ 必为奇数，若 $n$ 为**奇数**，则说明 $n_1 = 0$；若 $n$ 为**偶数**，则说明 $n_1 = 1$。
	4. 最后一个分支结点的编号为$\lfloor \frac{n}{2} \rfloor$（**堆**要用到这个特征。）；因此，若 $1 \le i \le \lfloor \frac{n}{2} \rfloor$，则结点$i$为分支结点，否则为叶结点。
	5. 编号为 $i$ 的结点所在深度（层次）为 $\lfloor \log_2i \rfloor + 1$（记忆。）
	6. 具有 $\mathbf{n}$ 个结点的二叉树的高度的高度$h$为 $\lceil\log_2(n+1)\rceil$ 或 $\lfloor \log_2n \rfloor + 1$（二叉树高度即编号为 $n$ 的结点所在深度。）注意：这两个式子**恒等价**。

#### 具有 $\mathbf{n}$ 个结点的二叉树的高度的高度推导
1. 建立 $n$ 与 $h$ 的核心不等式：
高度为 $h$ 的完全二叉树（根结点在第 1 层），结点数 $n$ 必须满足：
- 前 $h-1$ 层最多有 $2^{h-1} - 1$ 个结点
- 前 $h$ 层最多有 $2^{h} - 1$ 个结点

第 $h$ 层至少要有 1 个结点，故核心不等式为：
$$(2^{h-1} - 1) + 1 \le n \le 2^{h} - 1$$
即
$$2^{h-1} \le n \le 2^{h} - 1$$

2. 推导公式一：$h = \lceil \log_2(n+1) \rceil$

由右半部分：
$$n \le 2^{h} - 1 \implies n+1 \le 2^{h}$$

取对数：
$$\log_2(n+1) \le h$$

由于 $h$ 为整数且是最小满足该不等式的值（左半部分保证了 $h$ 再小 1 就不成立），所以：
$$h = \lceil \log_2(n+1) \rceil$$


3. 推导公式二：$h = \lfloor \log_2 n \rfloor + 1$

对核心不等式取对数：
$$\log_2(2^{h-1}) \le \log_2 n \le \log_2(2^{h} - 1)$$

因为 $\log_2(2^{h} - 1) < \log_2(2^{h}) = h$，且左端 $= h-1$，故：
$$h-1 \le \log_2 n < h$$

由向下取整定义，$\lfloor \log_2 n \rfloor = h-1$，因此：
$$h = \lfloor \log_2 n \rfloor + 1$$


4. 两种公式等价性（对正整数 $n$）

$$\lceil \log_2(n+1) \rceil = \lfloor \log_2 n \rfloor + 1$$

验证（$n=1$）：
- 公式一：$\lceil \log_2 2 \rceil = 1$
- 公式二：$\lfloor \log_2 1 \rfloor + 1 = 0 + 1 = 1$

> 使用场景：若题目要求高度（层数），两式皆可；若在数组存储中计算下标深度，常使用公式二（$\lfloor \log_2 i \rfloor$ + 1）。
	

## 二叉树的存储结构
1. 顺序存储结构：使用一组连续的存储单元，按照满二叉树/完全二叉树的编号规则，依次按层序存储树中的结点元素。通常将编号为$i$的结点，存储在下标为$i$的数组单元中。
	- 满二叉树/完全二叉树特别适合使用顺序存储结构。
	- 一般的二叉树，若仍想通过下标反映逻辑结构，则需要**插入若干“空结点”**，使其结构与同高度的**完全二叉树**一致，再将所有结点（包括**空结点**）按层序存入数组。这种做法在**最坏情况**下效率极低。**最极端情况**：各结点**只有右子树**的单支二叉树，此时需要插入最多的空结点，插入后为**完全二叉树**的结构。
2. 链式存储结构（**二叉链表**）
	- 至少包含三个域：左指针lchild, 右指针rchild, 数据域data。
	- 在实际应用中（即应用题，代码题中），还可根据需要**增加parent指针域**，指向其双亲（父节点），构成**三叉链表**。
	- 重要结论：含有**n**个结点的**二叉链表**中，共有 **n + 1** 个空链域。
	- 推导过程：
		- 1. 求**指针域**总个数：含有**n**个结点，一个结点有**2**个指针域（左右指针），则共有**2n**个指针域。
		- 2. 求**非空指针**域总个数：除了根节点外，其余节点头上都有**1**个指针（"天线"，若为三叉链表（指向父节点），则头上涉及2个指针；若为三叉树的三叉链表，则头上仍涉及1个指针。），共 1 * (n - 1) = **n - 1** 个非空指针域。
		- 3. 求**空指针域**总个数：$空指针域 ＝ 总指针域个数 - 非空指针域个数 = 2n - (n - 1) = n + 1（个）$。
	- 三叉链表的空链域个数，也可依照此推导过程进行推导。
