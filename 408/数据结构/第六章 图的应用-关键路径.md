## 关键路径
### 前置知识
- **AOE网**：有向无环图，以**顶点表示事件**，**有向边表示活动**，以边上的权值表示**完成该活动所需的开销**（如时间），则称这种图为用边表示活动的网络，**A**ctivity **O**n **E**dge Network，即AOE网。
- AOE网有事件的概念。顶点为事件，边为活动，边上有权值，代表完成活动所需开销；而AOV网的边仅用于表示依赖关系。
- 事件：**一瞬间发生的事，可视为一个标志(里程碑)**。事件用“**发生**”。
- 活动：**需要消耗时间**或资源，是我们要管理和优化的**具体任务**。所有计算都是**为活动服务**的。活动用“**开始**”。在AOE网中，有些活动可以**并行**进行。

- AOE网的**基本性质**：
	1. 只有在某个顶点所代表的**事件发生后**，**从该顶点出发的**各有向边所代表的**活动才能开始**。
	2. 只有当**进入某顶点的**各有向边所代表的**活动都已完成**时，该顶点所代表的**事件才能发生**。
- 在AOE网中，通常**仅有一个入度为0的顶点**，称为开始顶点（**源点**）；**仅有一个出度为0的顶点**，称为结束顶点（**汇点**）。

### 关键路径和关键活动的定义
- **关键路径**：**所有从源点到汇点的路径**中，**路径长度最大**的路径。
	- **完成整个工程所需的最短时间**＝关键路径的长度。
	- **所有**路径长度**最大**的路径，**都是关键路径**，各路径所涉及的活动都是**关键活动**。（⭐）
	- 因此，图较小时，可尝试**枚举**各路径，求出长度，找出最大值，即可找到关键路径。

- **关键活动**：关键路径上的**活动**。
	- **任一关键活动延迟**，**整个工程**的完成时间将**随之推迟**。（⭐）

### 求关键活动和关键路径
- $Ee(k)或Ve(k)$：表示事件$v_k$的**最早发生时间**。
	- $Ee(s)=0$，$v_s$是源点。
	- $Ee(j)=max(Ee(i)+Weight(v_i,v_j))$，对于各有向边$<v_i,v_j>$。
	- 其中，$Ee(i)+Weight(v_i,v_j)$表示$v_j$的**前置活动(入边)**$<v_i,v_j>$的**最早结束时间**。
	- 不能推出，事件的最早发生事件，应**取各前置活动最早结束时间的最大值**，因为要**等所有前置活动都完成时，才能开始本事件**。对应AOE网的**性质2**。
	- 求该值时，只关心本顶点的**入边**。
	- 手算时，推荐**先求出拓扑排序序列**，按照序列顺序计算。

- $El(k)$或$Vl(k)$：表示事件$v_k$的**最晚发生时间**。
	- $El(d)=Ee(d)$，$v_d$是汇点。
	- $El(i)=min(El(j)-Weight(v_i,v_j))$，对于各有向边$<v_i,v_j>$。
	- 其中，$El(j)-Weight(v_i,v_j)$表示$v_i$的**后续活动(出边)**$<v_i,v_j>$的**最晚开始时间**。
	- 不能推出，事件的最晚发生时间，应**取各后续活动最晚开始时间的最小值**，因为要迁就所有后续任务的底线，给后续活动留足时间，**不能让任何一个后续活动推迟**。
	- 求该值时，只关心本顶点的**出边**。
	- 手算时，推荐**先求出逆拓扑排序序列**，按照序列顺序计算。

- 正向求最早发生时间取最大值，是因为要等所有前置活动都完成才能开始（一个没干完，大家都得等）。
- 反向求最迟发生时间取最小值，是因为要迁就所有后续活动的底线（一个不能超，整体就不能超）。

- $e(k)$：活动$a_k$的**最早开始事件**。设该活动为边$<v_i,v_j>$。
	- $e(k)=Ee(i)$，其中$v_i$是该边的**弧尾顶点**。
- $l(k)$：活动$a_k$的**最晚开始时间**。设该活动为边$<v_i,v_j>$。
	- $l(k)=El(j)-Weight(v_i,v_j)$，其中$v_j$是该边的**弧尾顶点**。

- $d(k)$：活动$a_k$的最迟开始时间和最早开始时间的**差额**，称为**时间余量**，表示活动可拖延的时间。
	- $d(k)=l(k)-e(k)$
	- 若一个活动的**时间余量为0**，则该活动为**关键活动**，即该活动必须按期完成。
### 结论
- **缩短任一**关键活动的持续时间**有可能缩短总工期**，但**不能任意缩短**关键活动的持续时间。过度缩短会引发**关键路径的转移**，再缩短时，总工期不再受其影响。
- 关键路径可能**不止一条**。只有加快那些**同时**出现在**所有关键路径**上的关键活动（**公共关键活动**），**才能达到**缩短工期的目的。（注意：是“**所有**”，出现在**多条**关键路径也不行，必须是"所有"。）
- **任何一个活动**的持续时间的改变（由第一条知，只有**缩短关键活动的持续时间**才可能）可能会导致**关键路径的改变**。
- 任一关键路径上活动的时间**延长**多少，整个工期也就**随之延长**多少。（关键活动的性质。）
- 延长**公共关键活动**的时间，**不会导致**关键路径的**改变**，会延长工期。

- 总结：想缩短工期就得**缩短全部**关键活动；延长工期可以**延长任意**关键活动。

## 做题技巧
- 若题目要求**关键路径长度**，且图较小，可以**枚举从源点到汇点的各条路径**，分别计算长度。**最长路径长度**即为**关键路径长度**。

- 图论的题目（最小生成树、最短路径、关键路径），建议**总结**出自己的一套**规范做题流程**。（⭐⭐⭐）
- 比如：求关键路径时，用**不同颜色的笔**，在**各顶点(事件)上方**写下它的**最早发生时间和最晚发生时间**，方便计算。
- 比如：求最短路径和Prim求最小生成树时，**以列为顶点，以行为轮次**，构成一个矩阵，该矩阵的值为dist数组的值，在旁边**打上标记**，代表已选入集合，**圈起来**代表本轮选择该顶点。

## 做题步骤总结-求关键路径
1. 画**两个表**, 如下表所示。

| k<br>(顶点编号) | 1   | 2   | 3   | 4   | 5   |
| ----------- | --- | --- | --- | --- | --- |
| Ve(k)       | 0   |     |     |     |     |
| Vl(k)       | 0   |     |     |     |     |

| k<br>(边编号) | a   | b   | c   | d   | e   | f   | g   |
| ---------- | --- | --- | --- | --- | --- | --- | --- |
| e(k)       |     |     |     |     |     |     |     |
| l(k)       |     |     |     |     |     |     |     |
| d(k)       |     |     |     |     |     |     |     |

2. 在图上各顶点的**左上方**, 用**不同颜色的笔**标出它们各自Ve和Vl, 方便观察和计算。

3. 分别**速算**拓扑排序序列（选**入度为0**的顶点）和逆拓扑排序序列（选**出度为0**的顶点）。

4. 依照**拓扑排序序列**计算各顶点的Ve, 关注的是它的**入边**, 加权值, 取**最大值**。计算结果写在图上相应位置。

5. 依照**逆拓扑排序序列**计算各顶点的Vl, 关注的是它的**出边**, 减权值, 取**最小值**。计算结果写在图上相应位置。各顶点的Ve和Vl都算完后, 填写表格。

6. 再依据定义**计算各条边的e和l**（可以先统一算e, 再统一算l, 也可以一起算出来）, 填写表格, 计算时间余量。时间余量为0的活动即为关键活动, 构成了关键路径。
