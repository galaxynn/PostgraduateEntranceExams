**模式匹配**的定义：在主串中查找与模式串（待查找的字符串）**完全相同的子串**（主串中一段连续的字符串），并**返回其首次出现的位置**（取决于下标从$0$开始，还是下标从$1$开始）。

下面，我们设 $S$ 为主串，$T$为模式串。$i$ 为指向主串的指针，$j$ 为指向模式串的指针。
## 简单模式匹配算法
- 核心思想：**暴力匹配**，$i$指针**会回溯**。

- 某字符**匹配失败**（$S[i] != T[j]$）时，令$i = i - j + 2$，$j = 1$；（下标从$1$开始时）
- 含义：
- $i - j$：表示主串中当前正在匹配的子串首元素的前一个位置（下标）。
- $i - j + 1$：表示当前主串中正在匹配的子串的首元素所在的位置（下标）。
- $i - j + 1 + 1 = i - j + 2$：表示主串中将要匹配的下一个子串的第一个位置（下标）。

## KMP算法
- 原理：**充分利用上一趟匹配时，已知的信息**，以减少不必要的回溯操作。
- 核心特征：**每趟匹配失败**时，**主串指针$i$永不回溯**，仅模式串指针$j$调整。

- 实际上，**模式串是固定**的，**并不会真正的右滑**。
- 模式串逻辑上右滑，本质上是$j$指针**物理上左移**。
 
- 模式串 **右滑位数$d$** = $j - next[j]$ 或 $d = j - nextval[j]$

- **公式使用情况**：
	- **不论**下标从$0$开始还是从$1$开始，**皆可用此公式**。
	- $next[j] == -1$时，也适用。例如：当 $j = 4$, $next[j] = -1$时，模式串右滑位数$d = 4 - (-1) = 5$

- $next[j]$的**含义**：**本轮模式串**第$j$位字符**失配**时，**下一轮开始**时，模式串的$j$指针应指向的位置为$next[j]$。

- $next$数组在**某些情况下存在的缺陷**：
	- 若$T[j] == T[next[j]]$ 且 $T[j] != S[i]$ 时，算法会将 $j$ 设为 $next[j]$，而我们已知 $T[j] == T[next[j]]$，这就造成了不必要的开销。
	- 解决办法：使$next$数组中不出现 $T[j] = T[next[j]]$，于是就有了$nextval$数组。

- $nextval$数组是对$next$数组的**优化和改进**，进一步**减少了不必要的开销**。
- 求解$nextval$数组的方法见下。

- **特殊情况**：$j = next[j] = 0/-1$ 或 $j = nextval[j] = 0/-1$ 时，此时在**下一轮循环**中，会使 $i++$, $j = 1/0$（或让$j++$）。

### 做题方法总结
- 假设各字符串以及各数组**下标均从 $1$ 开始**。
- 如果下标从$0$开始，则$next$数组的值和$nextval$数组的值总体减一。
- 下标从1开始, 因此我们**设**有：$S[1 \dots n]$，$T[1 \dots m]$, $next[1 \dots m]$
#### 求 $next$ 数组方法
- $next[1]$ **无脑**写 $0$，$next[2]$ **无脑**写 $1$。（**下标从$0$开始**时，分别写 $-1$ 和 $0$。）
- **此后**，$j$ 从 $3$ 开始，$next[j]$ = 模式串 $T[0 \dots j-1]$ 构成的子串中，前后缀**最大**重合字符数 $+ 1$（**下标从$0$开始时**，则**无需** $+ 1$，更方便，因此题目**未说明下标情况**时，**更推荐下标从$0$开始**。）
- 依照以上方法, 计算出所有$next[j]$。


- **前后缀最大重合字符数**，也可理解为**最长相等前后缀长度**（在书中被定义为**部分匹配值$PM$**）。
- 这意味着，模式串$T$的最后一位字符在求$next$数组的过程中，不发挥作用。（了解即可）

- 书中记载：$next[j] = PM[j - 1] + 1$，本质上和以上过程**完全一致**。
- 因为$PM[j]$ 表示 模式串 $T[0...j]$ 构成的子串 的部分匹配值。

- 例子：
- 求模式串"**abcac**"的$next$数组。
- $next[1] = 0$, $next[2] = 1$;
- $next[3]$ 怎么求？看模式串 $T[0]$ 到 $T[3 - 1]$ 即 子串 "ab" ，前后缀最大重合字符数为$0$。则 $next[3] = 0 + 1 = 1$。
- $next[4]$ 同理。$next[4] = 0 + 1 = 1$。
- $next[5]$ 怎么求？看模式串 $T[0]$ 到 $T[5 - 1]$ 即 子串 "abca"，前后缀最大重合字符数为$1$，对应前后缀 "a"，则 $next[5] = 1 + 1 = 2$。

#### 求 $nextval$ 数组的方法
- $next[1]$**无脑**写$0$。（**下标从$0$开始**，则写 $-1$）
- $j$ 从 $2$ 开始，求 $nextval[j]$：
- **从前往后算，即下标从小到大算。**
- 若 $T[j] == T[next[j]]$，则令 $nextval[j] = nextval[next[j]]$，注意是两个$nextval$之间的赋值。
- 否则，即 $T[j] != T[next[j]]$时，令 $nextval[j] = next[j]$，即保持此$next[j]$值不变。直接**抄过来**。
- 用以上方法，以此算出所有$nextval[j]$即可。
