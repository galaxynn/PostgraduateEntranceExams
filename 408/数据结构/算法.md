
## 链表相关

### 快慢指针：找中间位置
```cpp
node* mid(node *L)
{
	node *slow = L, *fast = L;
	while(fast != NULL && fast->next != NULL)
	{
		slow = slow->next;
		fast = fast->next->next;
	}
	return slow;
}
```

### 链表原地逆置
- 原地头插（不带头结点，要**维护头指针**。）
```cpp
void reverse(node *L)
{
	node *head = NULL;
	node *p = head;
	while(p != NULL)
	{
		node *next = p->next; // 暂存 p->next，防止断链
		p->next=head;
		head = p; // 维护头指针
		p = next;
	}
}
```

### 链表交叉合并
- 不带头节点。
```cpp
void merge(node *L1, node* L2)
{
	node *p=L1, *q=L2;  // p和q均指向第一个数据结点
	while(p != NULL && q != NULL)
	{
		node *next1 = p->next;
		node *next2 = q->next;
		
		q->next = p->next;
		p->next = q;
		
		p = next1;
		q = next2;
	}
}
```
