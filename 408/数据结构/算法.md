## 链表相关

### 快慢指针：找中间位置
```cpp
node* mid(node *L)
{
	node *slow = L, *fast = L;
	while(fast != NULL && fast->next != NULL)
	{
		slow = slow->next;
		fast = fast->next->next;
	}
	return slow;
}
```

### 链表原地逆置
- 原地头插（不带头结点，要**维护头指针**。）
```cpp
void reverse(node *L)
{
	node *head = NULL;
	node *p = head;
	while(p != NULL)
	{
		node *next = p->next; // 暂存 p->next，防止断链
		p->next=head;
		head = p; // 维护头指针
		p = next;
	}
}
```

### 链表交叉合并
- 不带头节点。
```cpp
void merge(node *L1, node* L2)
{
	node *p=L1, *q=L2;  // p和q均指向第一个数据结点
	while(p != NULL && q != NULL)
	{
		node *next1 = p->next;
		node *next2 = q->next;
		
		q->next = p->next;
		p->next = q;
		
		p = next1;
		q = next2;
	}
}
```

## 树相关递归算法
- 递归就是处理规模更小的子问题，该问题和原问题一样，只是**问题规模变小**。

- 我们要**假设递归函数能正常运行**，赋予递归函数一个定义，并时刻牢记。
- 分析树形递归的方法：**三角分析法**，它的**左右子树能给它带来什么**？**它自身需要做什么**，要不要特判？这个函数是要做什么？

- 写递归要用**子问题思维**，或者说**拆解问题的思维**。如果用线性思维，会**陷入递归的细节中**，反而写不好代码了。
- 啥时候需要有返回值，啥时候不需要返回值啊？
	- 看你怎么写递归，如果是**自顶向下**的，**可以没有返回值**；如果是**自底向上**的，就**一定要有返回值**。这对应着视频中讲的两种写法。

### 2010年真题
- 轮转数组
https://leetcode.cn/problems/rotate-array/

- **三次反转数组**, 实现**向右轮转k个位置**。
	1. 第一次反转整体
	2. 第二次反转左子数组
	3. 第三次反转右子数组
	- 空间复杂度O(1)

- 反转数组代码: 
```c
void reverse(int *nums, int l, int r)
{
    int t = 0;
    while (l < r)
    {
        t = nums[l];
        nums[l] = nums[r];
        nums[r] = t;
        l++;
	    r--;
    }
    
}
```
