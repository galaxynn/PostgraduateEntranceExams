- 第16题：PC相对寻址，偏移量的计算公式？是谁减谁？
	- **跳转指令的有效地址**就是**转移目标地址**。
	- **有效地址/EA = 当前指令的下一条指令的地址 + 偏移量A**
	- 则**偏移量A = 有效地址EA - 当前指令的下一条指令的地址**，因此A可正可负，**用补码表示**。

- 第20题：**总线带宽 = 总线工作频率 × 总线宽度**
	- **总线工作频率**。指总线**每秒能进行的有效数据传输次数**。
	- 总线工作频率 = 一个**总线时钟周期**内传输一个总线宽度的数据的**次数** × 总线时钟频率 = 1s内传输总次数
	- 本题中，一个**总线时钟周期**内传输一个总线宽度的数据的**次数** = 0.5次

- 第24题：**响应比** = （等待时间 + 执行时间）/ 执行时间

- 第25题：**死锁阈值**是 $n × (m-1) + 1$，n是进程数，m是进程所需资源数。
	- 资源数量 ≥ 阈值，则不会发生死锁。资源数量 < 阈值，可能发生死锁。 
	- 临界条件：n个进程，每个进程都持有m-1个资源，只要再提供1个资源，就不会发生死锁。

- <font color="#00b0f0">第38题</font>：CSMA/CD协议，**核心不等式**：$t_{发送} ​≥ 2t_{传播}​$，注意**不要忘了2**。
	- 变化口诀总结：**左边减少，右边也要减少；右边增加，左边也要增加**。（⭐）
		- 用此**口诀**，可以将“增加”的排除。
		- 原理：数学上，左边减少，右边至少要减少到不大于左边；右边增加，左边至少要增加到不小于右边；**但严格说，不是“自动同步变化”，而是“必须满足约束”：若原来有余量，可以在余量内不动，但余量会变小**。
	- **本题核心**：找$s_1(原距离)$和$s_2(改变后的距离)$的大小关系。
		- 联立：$N/t_{发送} = s_1 / t_{传播}$，$(N - 800)/t_{发送} = s_2 / t_{传播}$，以N为中介，找$s_1$和$s_2$的关系，即$s_1 - 80 = s_2$
		- 技巧：涉及不等式时，一般可以**直接取等号简化计算**。

- 第40题：FTP主动模式和被动模式？21和20是谁的端口，对应什么连接？
	- 主动和被动是从**客户**视角来看的，**主动**指的是**主动把端口号给对方**。
	- 主动模式：**我主动把端口号给你**，让你的20号端口连接我的随机端口。
	- 被动模式：**我被动接收你的端口号**，我的随机端口来连接你的随机端口号。
	- 仅主动模式用20，其他随机。
	- 21：服务器的**控制连接端口**（1的控制欲很强），20：服务器的**数据连接端口**
