## 第2题 遗忘 考点：含n个结点的不同形态的二叉树个数 / 卡特兰数
- 题目：![[2015 2.png]]
- 错因/我的问题 + 修正：
	- **卡特兰数的公式**遗忘。
		- $$卡特兰数 =\frac{C_{2n}^{n}}{n+1}$$
		- 元素 $1, 2, 3, ..., n$ 依次入栈，**不同出栈序列个数**。
		- 含$n$个结点的不同形态的二叉树个数。
		- 先序/中序/后序序列为$1,2,3,...,n$的不同形态的二叉树个数。

- 下次怎么做：
	- 记住公式，同时也要学会**递推**的思想。
		- $f(n)$：$n$个节点的二叉树的形态总数。
		- **初始条件**：$f(0) = 1, f(1) = 1, f(2) = 2$
		- **卡特兰数的递推式**：$f(n) = f(0)f(n-1) + f(1)(n-2) + ... + f(n-2)(1) + f(n-1)(0)$
