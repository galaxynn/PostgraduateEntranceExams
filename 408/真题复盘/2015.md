## 第2题 大遗忘 考点：含n个结点的不同形态的二叉树个数 / 卡特兰数
- 题目：![[2015 2.png]]
- 错因/我的问题 + 修正：
	- **卡特兰数的公式**遗忘。
		- $$卡特兰数 =\frac{C_{2n}^{n}}{n+1}$$
		- 元素 $1, 2, 3, ..., n$ 依次入栈，**不同出栈序列个数**。
		- 含$n$个结点的不同形态的二叉树个数。
		- 先序/中序/后序序列为$1,2,3,...,n$的不同形态的二叉树个数。

- 下次怎么做：
	- 记住公式，同时也要学会**递推**的思想。
		- $f(n)$：$n$个节点的二叉树的形态总数。
		- **初始条件**：$f(0) = 1, f(1) = 1, f(2) = 2$
		- **卡特兰数的递推式**：$f(n) = f(0)f(n-1) + f(1)(n-2) + ... + f(n-2)(1) + f(n-1)(0)$

## 第12题 错 考点：计算机系统层次结构
- 题目：![[2015 12.png]]
- 错因/我的问题 + 修正：
	- 理解错误，**概念不清**，**误以为硬件描述语言是微指令**。
		- 硬件描述语言程序：
			- 硬件描述语言（HDL，如 Verilog、VHDL）**主要用于描述数字电路的结构与行为**。它通常需要经过逻辑综合生成门级网表，用于配置 FPGA 或制造专用集成电路（ASIC），或者在仿真器中运行，**计算机硬件无法直接执行 HDL 源代码**。

- 下次怎么做：
	- **机器语言**是由二进制代码（0 和 1）构成的指令集合，是计算机硬件（CPU）**唯一能够直接识别并执行**的语言。

## 第18题 小遗忘 | 不确定 考点：
- 题目：![[2015 18.png]]
- 错因/我的问题 + 修正：
	- 不确定**是不是低位是体号**。
