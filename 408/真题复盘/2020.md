## 第19题 不确定 考点：总线带宽
- 题目：![[2020 19.png]]
- 错因/我的问题：
	- 不确定 **工作频率** 和 **每秒传送次数**的关系。

- 思考：
	- <u>总线工作频率 = 每秒的传送次数</u>
		- QPI时钟频率为 **2.4GHz**（即<u>每秒有 2.4G 个时钟周期</u>）
		- <u>每个时钟周期传递</u> **2次**（这就是常说的双倍数据速率 DDR）
		- 所以，**每秒传送次数** = 2.4G × 2 = **4.8G 次/秒**。
	- 解析公式中的“2B” 和 “2”
		- 在计算**有效带宽**时，我们只算真正的数据位，即 16 位。16位（bit） = **2 Byte（2B）**。
		- 题目指出，QPI 是一种**全双工**总线，“总线上的设备可同时接收和发送信息”。
		- 前面算出的“每次 2B”是指**单一方向**上的带宽。因为可以**同时双向传输**，所以**总带宽要乘以 2**。

## 第28题 遗忘 | 不确定 考点：请求分页系统平均访存时间
- 题目：![[2020 28.png]]
- 错因/我的问题：
	- <u>不知道</u>有效（平均）访存时间的**计算公式**，不<u>会类比</u>Cache的访存时间。
	- **不确定**<u>从外存读取页面</u>**是否算缺页处理时间**。

- 思考：
	- 在**请求分页系统**中，有效（平均）访存时间的计算公式为：  $EAT=(1−p)×内存访问时间+p×缺页处理时间$（<u>和Cache类似，类比</u>）
		- 缺页处理时间是指：**从 CPU 发现缺页（发生异常）开始，一直到所需页面被调入内存，且该进程准备好重新执行这条指令为止，所经历的总时间。**

		- 问：“既然进程阻塞了，CPU 去执行别的进程了，**这部分时间为什么还要算在这个进程的访存时间里**？”
		- 答：因为我们在计算 EAT 时，是站在“**发生这次访存请求的进程**”的**视角**来看的。
			- 虽然对于**系统整体（CPU）** 来说，这段时间被其他进程利用了（提高了 CPU 利用率），没有浪费，但对于 **当前进程的 EAT** 而言，这 5 毫秒是<u>逃不掉的</u>。

## 第40题 错 | 遗忘  考点：DNS / HTTP / TCP
- 题目：![[2020 40.png]]
- 错因/我的问题：
	- <u>遗忘了访问URL时的完整流程</u>，**误以为**TCP连接提前建立好了，**误以为**不用考虑TCP建立的时间。
	- DNS域名解析过程**理解不到位**。
		- 把服务器A对下游（客户B）承诺的服务方式，错误地当成了它对上游（其他服务器）发起请求时的行为限制。

- 思考：
	- URL访问流程：
		- ① 访问URL。
		- ② DNS域名解析 → 获取域名对应的IP地址。
			- **域名解析**使用的是 UDP，端口号53。
		- ③ 三报文握手，**建立**TCP连接。
			- <u>获取 IP 地址后</u>，**才能建立**TCP连接！
		- ④ 第三个报文中**携带HTTP请求报文**。
		- ⑤ 服务器发送**HTTP响应报文**。
		- ⑥ **释放**TCP连接。（<u>非持续连接</u>）
		- ⑦ 浏览器**解析**html文件。
		- ⑧ 解析后发现**引用的图像**，**需要继续发送HTTP请求**。（非持续连接需要**重新建立**TCP连接，持续连接**不用**。）
	- “服务器A <u>只提供迭代查询服务</u>”的意思：
		- 客户B **只能**发送<u>迭代查询请求报文</u>给 服务器A。
		- 服务器A 收到<u>迭代查询请求报文</u>后，要么直接返回**对应域名的IP地址**，要么返回**下一步应该查询的服务器的IP地址**。
		- 一句话总结：你**只提供迭代查询服务**，就是说**我只能给你发送迭代查询请求**，**你告诉我下一步去那里查，我自己去查**。
	- “服务器A <u>只提供递归查询服务</u>”的意思：
		- 客户B **只能**发送<u>递归查询请求报文</u>给 服务器A。
		- 服务器A 收到<u>递归查询请求报文</u>后，则服务器A **需要帮客户B找到域名对应的IP地址**，而不是返回下一步应该查询的服务器的IP地址。
		- 此时，服务器A 本身**又作为客户**，请求其他服务器的服务，**取决于其他服务器提供什么服务**。
			- **不是说**我只提供递归服务，我就不能用迭代查询请求了。
	- <u>域名解析</u>，只需要解析到 “www.”**之前**的那层域名服务器即可！
		- 例如：www.abc.com
		- 涉及的服务器：本地域名服务器、根域名服务器、**.com**域名服务器、**.abc.com**域名服务器
