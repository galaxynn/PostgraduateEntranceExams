# 选题做题技巧
1. **选择选项前，再检查一遍题干**，以防计算之后**工作记忆丢失**，**遗忘了**题干的相关内容，导致粗心错误。

# 大题做题技巧
1. 每写**一个小问**时，**快速浏览题干**，看**是否有未用到的信息**，可能**这一问就要用到**。
2. 如果**题目**要让<u>分析理由/给出过程</u>，则**直接在答题卡上推导出结果**，而**不是**先写出结果，再写理由，这样可以**节约时间**！

# 1. 循环队列的判空判满
- **判空**：
	- <u>特例法</u>：假设队列中**有1个元素**，**根据题目定义，把此时的指针指向画出来**，**逆推**队列为空时的指针状态。
- **判满**：
	- 根据题干判断题目采用哪种方式判满：
		1. 牺牲一个存储单元
			- <u>特例法</u>：假设队列**有$m-1$个元素**（满），**根据题目定义，把此时的指针指向画出来**，看两个指针之间的**位置关系**。
		2. 添加 size 字段
		3. 添加 tag 字段
