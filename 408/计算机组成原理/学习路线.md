## 第一阶段：自底向上，掌握物理硬件基石

在这个阶段，先不要管操作系统，专注于搞懂计算机到底是用什么物理介质存数据的。

- **1. 计组：3.1 存储器概述**
    
    - 了解存储器的分类、层次化结构和主要性能指标。建立起“速度、容量、价格”相互制约的宏观认知。
        
- **2. 计组：3.2 主存储器**
    
    - 重点理解 SRAM 和 DRAM 的区别，这是后续理解 Cache 和主存的基础。
        
- **3. 计组：3.3 主存储器与 CPU 的连接 & 3.4 外部存储器**
    
    - 了解内存条是如何插在主板上与 CPU 交换数据的，以及磁盘/固态硬盘的物理特性。
        

## 第二阶段：速度优化与局部性原理（从硬件过渡）

Cache 的设计思想是贯穿整个计算机科学的核心，它在硬件层面的映射算法，与后面 OS 中的分页管理有着异曲同工之妙。

- **4. 计组：3.5 高速缓冲存储器 (Cache)**
    
    - 重点吃透 **3.5.1 程序访问的局部性原理**。这个原理不仅是 Cache 的灵魂，也是后续 OS 虚拟内存和页面置换算法的理论基石。
        
    - 认真学习 **3.5.3 Cache 和主存的映射方式** 以及 **3.5.4 替换算法**。这里的替换算法可以为后续 OS 里的页面置换算法做铺垫。
        

## 第三阶段：操作系统视角的基础内存划分

现在把视角切换到操作系统。假设系统里有多块连续或不连续的物理内存，OS 该怎么分配给各个正在运行的程序（进程）？

- **5. OS：3.1 内存管理概念**
    
    - 从 **3.1.1 内存管理的基本原理和要求** 开始，了解连续分配管理方式 (3.1.2) 的痛点。
        
    - 重点攻克 **3.1.3 基本分页存储管理**、**3.1.4 基本分段存储管理** 和 **3.1.5 段页式存储管理**。此时你只需要理解“逻辑地址如何转换成物理地址”，以及“页表/段表”在软件逻辑上的概念，暂不涉及数据在磁盘和内存之间的换入换出。
        

## 第四阶段：高潮迭起，虚拟内存的软硬大融合

这是最核心、也是考研或面试中最爱考的交叉点。必须将两本书的内容揉在一起看。

- **6. 概念对读：OS 3.2.1 vs 计组 3.6.1**
    
    - 对比阅读 OS 的 **3.2.1 虚拟内存的基本概念** 和 计组的 **3.6.1 虚拟存储器的基本概念**。体会两者在描述同一概念时的不同侧重点。
        
- **7. 硬件支持（计组视角）：计组 3.6.2 - 3.6.4**
    
    - 学习 **页式、段式、段页式虚拟存储器**。在这里，你要重点弄懂 TLB（快表）这个纯硬件机制是如何加速页表查询的。
        
- **8. 软件策略（OS视角）：OS 3.2.2 - 3.2.6**
    
    - 回到 OS，学习当发生“缺页中断”（硬件机制）时，OS 是如何通过 **3.2.2 请求分页管理方式** 来处理的。
        
    - 深入钻研 **3.2.4 页面置换算法**（如 LRU、OPT、CLOCK 等）以及 **3.2.5 抖动和工作集**。这里完全是操作系统的软件策略舞台。
        
- **9. 终极串联：OS 3.2.9 & 计组 3.6.5**
    
    - 通过 OS 的 **3.2.9 地址翻译的示例**，在脑海中走通一整个流程：CPU 给出虚拟地址 -> 查 TLB -> 查页表 -> 发生缺页/命中 -> 查 Cache -> 查主存。
        
    - 最后，用计组的 **3.6.5 虚拟存储器与 Cache 的比较** 总结收尾，理清两个层级缓存系统的异同。
