- 真值：就是**带正负号的真实数值**，是我们人类习惯的书写形式（如 +15、-3.5、-10）。在计算机学科中，通常指用二进制表示但带 +/- 符号的数（如 +1011 和 -1011）。

- 机器数：是**数字化后的编码**，即**真值在计算机内部的“二进制存储形式”**。它必须解决两个问题：符号如何表示（通常用最高位0代表正，1代表负）和小数点如何隐含。常见的机器数有原码、反码、补码和移码。

## 定点数
- 机器数＝**符号位**＋数值位。
- 根据小数点的位置**是否固定**。计算机中的数值表示分为**定点表示**和**浮点表示**。

- 小数点的位置被**固定**在位权$2^0$与位权$2^{-1}$之间，是人为约定好的。
- 本质上，定点整数和定点小数是**同一套**编码规则。因此，在**定点数**的编码和运算中，**无需区分该数表示的是小数还是整数**。

- **定点数**的**编码表示法**主要有四种：**原码、补码**、反码和**移码**。
	- 本质上是对真值$x$的**不同二进制编码规则**，关键的是**以何种规则解释该二进制编码**。

## 原码表示法
- **最高位**表示符号位（0正，1负），其余各位表示**数的绝对值**。
- 零的表示有+0、-0，不唯一。
- $n$位原码整数，其真值的表示范围：$-(2^{n-1}-1) \le x \le 2^{n-1}-1$，关于原点对称。
- $n$位原码小数，其真值的表示范围：$-(1-2^{-(n-1)}) \le x \le 1-2^{-(n-1)}$，关于原点对称。

- 原码可直观的比较大小。
## 补码表示法
- **最高位**表示符号位（0正，1负）。

- 利用了**模运算**的性质，使得补码的加法和减法运算均可通过**加法**实现。
	- 若计算机字长为$n$位，则补码运算**天然对$2^n$取模**（**符号位**的**下一位**对应的位权），即仅**保留低$n$位**。与无符号数一致。

- **正数的补码**：**与原码相同**。
- **负数的补码**：等于模与该负数绝对值之差。（具体转换为原码方法，见[[第二章 数据的表示和运算-补码]]）
	- 其他转换为原码的方法：除符号位外，其余位取反加1。
	- 取反加1，**速算技巧**：最右边的1及其右边所有位不动，左边的所有位（除符号位）取反。(普遍规律)

- 零的表示**唯一**。多出来的一个，比原码多表示一个$2^{n-1}$。
- $n$位**补码整数**，其真值的表示范围：$-2^{n-1} \le x \le 2^{n-1}-1$。

- 同为**负数**的前提下，补码或反码的数值部分越大，其真值也越大。

## 移码表示法
- 无符号位的概念。

- 移码主要用于表示浮点数的**阶码**，且仅用于表示**整数**。
- 将真值$x$**加上**一个**固定的偏置值**，实现数轴整体右移。

- 移码本身是一个无符号的二进制值，任何二进制值都可转换为十进制值。
- 注意：移码二进制**本身**对应的十进制值**不是**真值，要**减去偏置值**，才为**真值**。

- 零的表示**唯一**。
- $n$位**移码整数**，其真值的表示范围：$-2^{n-1} \le x \le 2^{n-1}-1$。（与**补码**一致，记住即可。）

- 注意：字长为$n$位时，移码**只有**取偏置值为$2^{n-1}$时，补码把符号位取反可得到对应移码。
- 但是，在IEEE754中，偏置值为$2^{n-1}-1$，**不满足**此规律，要按对应规则算移码。
