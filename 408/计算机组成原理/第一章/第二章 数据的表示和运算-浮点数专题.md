## 一、IEEE 754 标准浮点数表示

### 1. 单精度浮点数（32位 float 型）
- **表示公式**：$$N = (-1)^s \times (1.f)_2 \times 2^{e-127}$$
- **阶码特性**：阶码 $e$ 的取值范围为 $1 \sim 254$（全0和全1保留），指数真值范围为 $-126 \sim 127$。$e$ 在存储器中存储的是**移码**（即真值加偏置值）。
- **位分配**：
  - 符号位 $s$：1 位
  - 阶码 $e$：8 位
  - 尾数 $f$：23 位（尾数部分最高位的 `1` 被隐含在小数点之前，即规格化数为 $1.f$）
- **偏置值**：$$2^{8-1} - 1 = 127$$

### 2. 双精度浮点数（64位 double 型）
- **表示公式**：$$N = (-1)^s \times (1.f)_2 \times 2^{e-1023}$$
- **阶码特性**：阶码 $e$ 的取值范围为 $1 \sim 2046$（全0和全1保留），指数真值范围为 $-1022 \sim 1023$。
- **位分配**：
  - 符号位 $s$：1 位
  - 阶码 $e$：11 位
  - 尾数 $f$：52 位
- **偏置值**：$$2^{11-1} - 1 = 1023$$

### 3. 特殊值处理（阶码 $e$ 全 0 或全 1）
- **阶码全 0 ($e = 0$)**：
  - 尾数全为 0：表示 $\pm 0$（具体符号取决于符号位 $s$）。
  - 尾数不全为 0：表示**非规格化数**（具体符号取决于符号位 $s$）。
- **阶码全 1 ($e = 255$ 或 $2047$)**：
  - 尾数全为 0：表示 $\pm \infty$（具体符号取决于符号位 $s$）。
  - 尾数不全为 0：表示 **NaN** (Not a Number，非数)。

- **非规格化数**：其指数真值固定为 $-126$ (32位) 或 $-1022$ (64位)。
  - 表示公式为：$$N = (-1)^s \times (0.f)_2 \times 2^{-126 \text{ 或 } -1022}$$。尾数最高位的 `1` 不再隐含。

### 4. 表示范围推导
- 若需使浮点数绝对值**最大**：阶码取最大值，尾数取最大值（尾数全为1）。
- 若需使浮点数绝对值**最小**（接近 0）：阶码取最小值（非规格化数时阶码取固定最小值 $-126$ 或 $-1022$），尾数取最小值（最小正整数）。


## 二、IEEE 754 浮点数加法运算流程

### 1. 真值形式转换
- 先将两个待加数的**真值**表示为 $\pm 1.f \times 2^m$ 的**规格化形式**。
	- 若$f$的位数**超过23位或52位**（如无限循环小数），要根据被截断部分**判断G、R、S**，**先进行一次舍入**。（舍入过程见下。）

### 2. 对阶（阶码对齐）
- **核心原则**：**小阶向大阶看齐**。
- **操作**：将**阶码较小**的数，其尾数**向右逻辑移位**（即小数点左移），移动的位数为**两阶码差值的绝对值**。
	- 若**阶码差的绝对值**≥25位或54位（有效位数＋1），则会出现**大数吃小数**的情况。（**小数隐藏位被移出保护位**，后续舍入时，被直接截断。）
- **隐藏位处理**：尾数中隐含的最高位 `1` 在移位时需**参与**。
- **移出的部分必须保留，不可立即截断**，**移出的位按规则形成 G、R、S**（只保留这3位）。尾数加减运算完成后再进行处理。
	- 也就是说, 被截断部分被**浓缩**成G、R、S这三位。

### 3. 尾数加减运算
- 对**尾数（定点原码小数）** 进行**加减运算**（可转换为二进制真值的加减法）。
	- 此步运算包含隐藏的最高位 1，并且带有 G、R、S 附加位一起进行 ALU 运算。
	- 阶码较小的数, **对阶形成的 G、R、S 位参与加减运算**。
	- 阶码较大的数, 默认其**G = 0、R = 0、S = 0**。
- **操作逻辑**：先**判断结果符号**，再**用绝对值较大的数去加（或减）绝对值较小的数**。
	- 同号：两个对阶后的尾数直接相加。结果的符号位与原操作数相同。
	- 异号：将较小的尾数从较大的尾数中减去。结果的符号位取绝对值较大的那个数的符号。

### 4. 规格化与舍入
- **规格化**：对运算后的结果进行**规格化**处理，即移动尾数直至最高位为隐含的 `1`。
	- **G、R、S位也跟着移动**, 保留被移出的部分, 重新更新S位。
	- 左规：**整体左移，新 S 补 0。**
	- 右规：两个尾数相加产生了进位, **右规最多只会发生 1 次**, 

- **舍入辅助位**：为了精确控制舍入，定义如下三个标志位：
  - **保护位 (Guard bit, G)**：被截断部分的第 1 位。
  - **舍入位 (Round bit, R)**：被截断部分的第 2 位。
  - **粘滞位 (Sticky bit, S)**：舍入位之后的所有位中，只要存在 `1`，则 S 置为 1，否则为 0。

- **舍入规则（默认采用“就近舍入”模式）**：

| 保护位 G | 舍入位 R | 粘滞位 S | 舍入策略                                   |
| :---: | :---: | :---: | :------------------------------------- |
|   0   |   0   |   0   | **直接舍去**被截断部分（向下舍入）                    |
|   0   |   0   |   1   | **直接舍去**被截断部分（向下舍入）                    |
|   0   |   1   |   0   | **直接舍去**被截断部分（向下舍入）                    |
|   0   |   1   |   1   | **直接舍去**被截断部分（向下舍入）                    |
|   1   |   0   |   0   | **向偶数舍入**（策略：若尾数最低位为 1 则加 1，若为 0 则截断。） |
|   1   |   0   |   1   | **尾数加 1**（向上舍入）                        |
|   1   |   1   |   0   | **尾数加 1**（向上舍入）                        |
|   1   |   1   |   1   | **尾数加 1**（向上舍入）                        |

- 其他舍入策略：
	- 正向舍入：朝数轴正无穷方向舍入。
	- 负向舍入：朝数轴负无穷方向舍入。
	- 朝原点舍入（截断法）：直接截取所需位数，丢弃后面被截断部分。


### 5. 溢出判断
1. 将运算结果**再次**进行**规格化。**
2. 检查最终的**阶码**是否超出了当前格式所能表示的范围，以判断是否发生了**上溢**或**下溢**。

- 浮点数的溢出**由阶码是否超出可表示范围决定**，因为尾数溢出可以通过规格化修正。


## C语言中的浮点数类型
- 当不同类型的数据混合运算时，遵循类型提升原则：**较低类型自动转换为较高类型**。
- 常见的**转换序列**为：
	- char->int->long->double 
	- float->double

1. int转float时，**不会发生溢出**，但会**导致精度损失**。（float的尾数含隐藏位，仅有24位有效，而int为32位。）
2. int或float转double时，**能精确表示其原值**，无损转换。
3. double转float时，可能会**发生溢出或精度损失**。
4. float或double转int时，**小数部分会被直接丢弃**，浮点数值超出int的表示范围时会发生整数溢出。
