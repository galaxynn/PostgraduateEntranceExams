## 1. 位权分配
对于长度为 $n$ 位的**二进制补码**，每一位都带有固定的“权重（权值）”：
*   **最高位（第 $n-1$ 位）**：权值为 **$-2^{n-1}$**（**唯一一个负数**）。
*   **其余位（第 $n-2$ 到 $0$ 位）**：权值分别为 $2^{n-2}, 2^{n-3}, \dots, 2^1, 2^0$（**全部为正数**）。

> **一句话口诀**：整个二进制数，**只有最左边那一位带负号**，其余全是正号。

## 2.十进制真值（负数） ➡️ 补码
> 实际运算中，选**离真值最近的负的2的幂次**即可，再通过**符号扩展**成想要的位数$n$。
- 设$-N$是**离真值最近的负的2的幂次**（$N$选大了也无所谓，不要超过$n$位的最高位权即可）。例如：离-6最近的是-8，离-9最近的是-16。

- 已知数值 $X$（要表示的十进制整数）和位数 $n$：
1.  **列方程**：最高位必须取 $1$，代表它的负权。方程设为 $-N + M = X$。
2.  **拆解 M**：将 $M$ 转化为二进制，按权值 $2^{n-2} \dots 2^0$ 拆解，使等式成立。
3.  例子：-9(X) = -16(-N) + **4 + 2 + 1**(M)。
4.  **拼接结果**：最高位写 `1`，低位写拆解后的二进制数。
5.  **符号扩展**为$n$位。

**案例演示（5位补码求 -6）**：
*   可选最高位权：$-2^{4} = -16$（第5位为1）；或者，选$-8$也可以（第4位为1）。
*   拆解得$-16 + 8 + 2 = -6$（对应 `101010`）；或者，$-8+2 =-6$（对应`1010`
*   最终补码：**`11010`**；或`1010`->符号扩展为`11010`

## 3. 补码 ➡️ 十进制真值（正、负数均可）
- **技巧**：直接找**高位连续1的最低位**, 作为**负权值**。其余高位的1视为**符号扩展**。（⭐）

已知一段二进制补码和它的位宽 $n$：
1.  **列位权**：**最高位写负权**，其余位写对应**正权**。
2.  **直接求和**：把所有为 `1` 的位权**相加减**，所得之和即为真值。

**案例演示（求 8位二进制 `11111010` 的值）**：
*   权重组合：$-128, 64, 32, 16, 8, 4, 2, 1$。
*   计算：$1\times(-128) + 1\times64 + 1\times32 + 1\times16 + 1\times8 + 0\times4 + 1\times2 + 0\times1$。
*   结果：$-128 + 64 + 32 + 16 + 8 + 2 = -6$。

## 4. 位宽扩展规则（符号扩展）
当把 $n$ 位补码**扩展**到更多位（如从 5位 转为 8位，或从 8位 转 16位）时：
*   **操作规则**：直接在二进制数的**最左边补充**与原有**最高位数值相同**的位。正数全补 `0`，负数全补 `1`。
*   **为什么数值不变？**
    *   扩展时，**新的最高位变成了唯一的负权**（例如 5位的 $-16$ 变成了 8位的 $-128$）。
    *   但是，中间补充进来的那些新位 `1`（如 $64, 32, 16$ 等正权）**自动抵消**了这些**多出来的负权**。总和依然等于原值。

## 5. 核心原理解析（为什么最高位必须是负数？）
最高位带负权，是**人为设计**的数学约定，主要是为了**迎合计算机底层物理电路**：
*   计算机CPU**只有加法器**，没有减法器。
*   在“位权法”体系下，运算 $A - B$ 变为 $A + (-B)$。
*   如此一来，CPU直接进行普通的二进制加法运算，算出来的结果就完美符合我们的实际十进制减法。
*   这套规则在数学上**等价于**经典的“按位取反，末位加1”，但**权值法更符合人类的直觉，计算不易出错**。
