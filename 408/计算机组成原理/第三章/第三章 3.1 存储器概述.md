	## 存储器的分类
- 根据存储器的特点和使用方法的不同, 可以有以下几种分类方法：
	1. 按**存储元件**分类。
		- 存储元件必须具备**两个截然不同的物理状态**, 才能被用来**表示二进制数0和1**。
		- 常用的存储元件主要有**半导体器件、磁性材料**和**光介质**。
			- 半导体器件利用**电荷或电压状态**存储信息, 构成**半导体存储器**（如**DRAM、SRAM**）
			- 磁性材料通过**磁化方向**表示数据, 用于**磁表面存储器**（如**硬盘、磁带**）
			- 光介质则依靠折射率或相变特性记录信息, 构成**光存储器**（如**光盘**）
	2. 按**存取方式**分类
		- **随机存取存储器**（Random Access Memory, **RAM**）：可**对任意存储单元进行读/写**, 且**存取时间与物理位置无关**。
			- 优点：读写灵活, 使用方便。
			- 典型代表：**半导体存储器**, 常用于**主存或高速缓存**。
		- **顺序存取存储器**（Sequential Access Memory, SAM）：信息**按顺序存放和读出**, **存取时间取决于数据在介质中的位置**, 通常以记录块为单位编址。
			- 典型代表：**磁带**, 容量大, 速度慢。
		- **直接存取存储器**（Direct Access Memory, DAM）：**兼具随机访问和顺序访问的特点**。可先直接定位到目标位置, 再按顺序读取数据。
			- 典型代表：**传统机械磁盘(机械硬盘)**。
		- **相联存储器**（Associative Memory, AM）：**按内容而非地址进行存取**。 
			- 优点：**查找速度快**且**与存储位置无关**。
			- 缺点：**成本高、容量小**。
			- 用途：主要用于**快表(TLB)、路由表**等小容量高速查找场景。
	3. 按**信息的可更改性**分类
		1. 可读可写存储器
			- **RAM**是一种可读可写存储器。
		2. **只读存储器**（Read-Only Memory, **ROM**）
			- **ROM**中的信息一旦确定, **通常情况下**只读不写, 但**在某些情况下也可以重新写入**。
		- RAM和ROM都采用**随机存取方式**进行信息的访问。
	4. 按**断电后信息的可保存性**分类
		1. **易失性存储器**（Volatile Memory）：断电后, 信息即**丢失**。
			- 如**RAM、Cache**等。
		2. **非易失性存储器**（NonVolatile Memory）：断电后, **信息仍能保存**。
			- 如**ROM**、Flash存储器、**磁盘和光盘**等。
		- **破坏性读出**：读取操作会**破坏存储单元中的原有信息**, 读出后**需要立即执行再生操作**恢复数据。
		- **非破坏性读出**：若读取**不改变原内容**, 无需再生。

## 主存储器的组成和基本操作
![[主存储器的组成.png]]
- **存储阵列**：存储器的**核心部件**, 也称存储矩阵、存储体。
	- 由大量**存储0或1的记忆单元**构成。
	- 这种**记忆单元**也称为**存储元、位元**, 是**具有两种稳态**的能表示二进制0和1的物理器件。

- **编址**：为了存取存储体中的信息, **必须对存储单元编号, 所编的号码就是地址**。
	- **编址单位**：**具有相同地址的那些位元**构成的**一个单位**, 可以是**一个字节**或**一个字**。（⭐）
	- **编址方式**：对存储单元进行**编号的方式**。可以**按字节编址**, 也可以按字编址。（⭐）
		- 现代计算机都**采用字节编址方式**, 此时存储体内**一个地址对应1B(8bit)**（若无特殊说明, **默认采用字节编址**）（⭐）
	- **一个存储单元一定对应一个地址**。

- 当CPU执行指令需要**访问主存**时, 
	1. 首先将**目标地址**送入**存储器地址寄存器（MAR）**, 并通过**地址线**传至**主存的地址寄存器**。
	2. **主存的地址译码器**据此选中对应的存储单元。
	3. 同时, CPU通过控制线向主存**发送读/写控制信号**。
		- 若为**写操作**, CPU将待写入数据送入**存储器数据寄存器（MDR）**, 在控制电路的作用下, 经**数据线**写入选中单元。
		- 若为**读操作**, 主存将选择单元的内容经**数据线**送至**存储器数据寄存器（MDR）**。

- 虽然名称中含"存储器", 但**MAR和MDR位于CPU中**, 主存中**也有**一个地址寄存器, 但**不叫MAR**。
	- **MAR**的位数 = **地址线位数**。A 对应 Address  
		- 地址线的位数决定了**主存的最大可寻址范围**。
		- 按**字节编址**时, **n位地址**的**寻址范围**（地址编号范围）为$0 至 2^{n} - 1$, 共 $2^{n}$ 个字节。
	- **MDR**的位数 = **数据线宽度**。D 对应 Data
		- 按**字节编址**时, **数据线为64位**, 则, 每次可**并行存取**8个字节。
		- MDR的位数**不一定等于**存储字长。通常**大于等于**存储字长。

- 读写控制信号：含**片选线**、**读/写控制线**。
- **低电平有效**的好处：抗干扰, 更安全, 不会误触发。

## 存储器的层次化结构
- 为**缓解存储系统在容量、速度与成本之间的矛盾**, 现代计算机普遍采用多级存储器结构。
- 从上至下, 各层存储器的**单位价格组件降低**, **存取速度变慢**, **容量增大**, **CPU访问频率也相应降低**。
 ![[存储器层次结构1.png]]

![[存储器层次结构2.png]]

![[存储器层次.png]]
- 存储层次的核心思想：
	1. 将**上一层存储器作为下一层的高速缓存**。（上一层的内容始终是下一层内容的**副本**。）
	2. 当CPU访问数据时, **按Cache->主存->辅存的顺序**逐级查找。
	3. 若所需数据不在上层, 则**从下层逐级调入**：先从磁盘读入主存, 在从主存加载到Cache。

- **Cache-主存层**：
	- 在Cache-主存层中, **Cache和主存可以直接与CPU交换信息**。
	- Cache-主存层的**速度**接近**Cache**, 容量和单位成本接近**主存**。
	- 用于**缓解CPU与主存速度不匹配的问题**。
	- **数据调度由硬件自动完成,** 对**所有程序员**透明。

- **主存-辅存层**：
	- 在主存-辅存层中, **辅存**需要通过主存**间接**与CPU通信, **主存作为枢纽**, 能与CPU、Cache、辅存**双向交换数据**。
	- 主存-辅存层的**速度**接近**主存**, 而容量和单位成本接近**辅存**。
	- 用于**解决存储容量不足的问题**。
	- 数据调度**由硬件和操作系统(软件)协同完成**, 对**应用程序员**透明。

- 随着**主存-辅存层**的不断发展, 逐渐形成了**虚拟存储系统**。
	- 在该系统中, **程序员使用的地址空间（虚拟地址空间）** 远大于**实际主存容量**。

## **存储器的**主要性能指标
- **存取时间**：指存储器**启动一次读写操作**（从**接收到有效地址和命令**开始）到**操作完成**（**数据有效输出或成功写入**）所需的**内部物理延迟**。
    - **读出时间**：从主存**接收到有效读地址**起，到读出数据在数据线上**稳定有效**（可以输出）为止的耗时。
    - **写入时间**：从主存**接收到有效地址**以及**待写入数据**起，到数据被**成功固化/写入**到指定存储单元（内部状态翻转稳定）为止的耗时。

- **⚠️辨析重点（易错点）**：**存取时间 ≠ 总线传输时间**。
    - 存取时间仅反映存储器芯片**内部电路**的动作延迟。
    - 数据从存储器**总线接口**传输到 CPU（或 Cache），或者在总线上完成多轮数据传输所需的时间，属于**总线传输时间**。
    - 在设计**总线事务周期**时，需要将存取时间和总线传输时间**分开累加计算**。

- **存储周期/存取周期**：存储器**进行连续两次独立的读操作或写操作**所需的**最小时间间隔**。
	- **一次存取到下一次存取**所需最小时间间隔。
	- 在计算**总线事务**时间时，**存储体准备数据的时间**为**一个存储周期/存取周期**。（⭐⭐）

![[存取时间和存储周期的关系.png]]
- 注意：**存取时间≠存储周期**。
	- 通常情况下, **存储周期 > 存取时间**。
	- **存储周期 = 存取时间 + 复原时间**（⭐）
	- 因为每次读/写操作后, **存储器需要一定时间恢复内部状态**。
		- 不论是破坏性读出还是非破坏性读出, **都需要复原时间**。
		- 对于**破坏性读出, 其复原时间更长**。

- **存储器带宽**：也称为**数据传输率**。
	- **存储器带宽 = 一个周期能传输的数据量 / 存储周期**
	- 一个周期能传输的数据量即数据线位数, **不一定等于存储字长**。

- **存储器容量**：
	- 存储器容量 = 存储单元个数 * 存储字长
