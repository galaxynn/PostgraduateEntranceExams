## 数据通路的功能
- 随着技术的发展，越来越多的**功能逻辑**被集成到CPU芯片中，包括 **Cache、MMU**、**浮点运算逻辑**、**异常和中断处理逻辑**等，因而CPU的内部组成**越来越复杂**，甚至在一个 CPU芯片中集成了多个处理器核。

- 但不论CPU的内部结构多么复杂，它都可视为由**数据通路(Data Path)** 和**控制部件(Control Unit)** 两大部分组成。
	- 其中，**控制部件**也称为**控制器**。

- 在**数据通路**中，专门负责**数据运算**的部件通常被称为**执行部件**（Execution Unit）。
	- **执行部件**在**完成指令执行**时，主要**依赖**两类元件：
		- ① **组合逻辑元件**（又称**操作元件**）。
		- ② **存储元件**（又称**状态元件**）。
	- 连接这两类元件的方式有两种：**总线方式**和**分散连接方式**。

- **数据通路**：
	- 定义①：**数据**在指令执行过程中**所经过的路径**，以及路径上**涉及的硬件部件**。
	- 定义②：由操作元件和状态元件通过总线或分散方式连接而成的**进行数据存储、处理和传送的路径**。
	- 例如，ALU、 通用寄存器、状态寄存器等，都是指令执行时数据流经的部件，属于**数据通路的一部分**。
	- 数据通路描述了**数据从何处开始，中间经过哪些部件，最终被传送到哪里**。
	- 整个数据通路由**控制部件**（**控制器**）控制，后者根据每条指令的功能，生成相应的**控制信号**，以**驱动数据通路**完成指定操作。

## 数据通路的组成
### 1. 组合逻辑元件（操作元件）
- **组合逻辑元件**主要用于执行**数据运算**与**路径选择**，也称**操作元件**，其输出只取决于**当前的输入**。
	- **特征**：
		- ① 任意时刻的**输出仅由当前输入决定**，不依赖历史状态。
		- ② 内部不含记忆单元，**不受时钟控制**，且无输出到输入的反馈通路，因而**具有确定性和即时响应性**。

- 数据通路中**常用的组合逻辑元件**包括**加法器**、**算术逻辑单元(ALU)**、**译码器**、**多路选择器(MUX)** 和**三态门**等。
- ![[第五章 5.3数据通路 组合逻辑元件1.png]]
- ![[第五章 5.3数据通路 组合逻辑元件2.png]]
- 图中**虚线表示控制信号**，
	- 多路选择器需要**控制信号Select**确定**选择哪个输入被输出**；
	- 加法器**不需要控制信号控制**，因为它的操作是确定的；
	- ALU需要有操作**控制信号OP**，由它**确定ALU进行哪种操作**。

- **译码器**常用于**操作码译码或地址码译码**，对于$n$位输入，可产生$2^n$个互斥输出。

- **多路选择器**（MUX）根据**控制信号 Select** 从多路输入中选择一路输出，若**输入路数**为 $N$，则需 $\lceil \log_2 N \rceil$ **位控制信号**。

- **三态门**可视为一种**受控的总线开关**，由**控制信号 EN** 决定**信号线的通断**，当 $\text{EN} = 1$ 时，三态门被**打开**，输出（out）信号**等于**输入（in）信号；当 $\text{EN} = 0$ 时，输出端呈**高阻态**（隔断态），所连寄存器与总线**断开**。
	- 注意EN是**低电平有效**还是**高电平有效**，此处为高电平有效。

### 2. 时序逻辑元件(状态元件)
- **时序逻辑元件**的输出**不仅取决于当前输入**，还**依赖于电路的历史状态**，因此其内部必然**包含用于存储信息的记忆单元**，此外，这类元件必须**在时钟的同步控制下工作**。
	- **输入状态**在**时钟控制**下被写到电路中，并保持电路的输出值不变，直到下一个时钟到达。输入端状态由时钟信号决定何时被写入，输出端状态随时可以读出。

- 数据通路中常见的**时序逻辑元件**包括**各类寄存器**和**存储器**，例如**通用寄存器组**、**程序计数器(PC)**、**状态/暂存寄存器**等。

- ![[第五章 5.3数据通路 状态元件.png]]
- **暂存寄存器**
- 暂存寄存器有一个写使能(Write Enable)信号WE，
	- 当 WE=0 时，时钟信号(CLK)边沿到来**不会改变输出值**；
	- 当 WE=1 时，时钟边沿到来后，经过Clk-to-Q时间的延迟，输出端(DataOut)开始**变为输入端(Dataln)的值**，表示**输入信息被写入寄存器**。
	- 若数据通路中某个寄存器**在每个时钟到来时都需要写入信息**，则该寄存器**无须WE信号**。

#### 通用寄存器组介绍
- 32 个暂存寄存器可以构成一个如图 5.3(b) 所示的通用寄存器组，**每个寄存器地址是一个 5 位的二进制编码**（$2^5 = 32$，恰好对应 32 个寄存器）。
##### 接口说明
- ![[第五章 5.3数据通路 通用寄存器.png|650]]

| 接口       | 位宽   | 方向  | 类型     | 作用                                      |
| -------- | ---- | --- | ------ | --------------------------------------- |
| **Ra**   | 5 位  | 输入  | **地址** | 读端口 A 的地址，指定从哪个寄存器读出数据到 busA            |
| **Rb**   | 5 位  | 输入  | **地址** | 读端口 B 的地址，指定从哪个寄存器读出数据到 busB            |
| **Rw**   | 5 位  | 输入  | **地址** | **写端口的地址**，指定将 busW 上的数据写入哪个寄存器         |
| **busA** | 32 位 | 输出  | 数据     | 读端口 A 的数据输出总线，输出 Ra 所指定寄存器的内容           |
| **busB** | 32 位 | 输出  | 数据     | 读端口 B 的数据输出总线，输出 Rb 所指定寄存器的内容           |
| **busW** | 32 位 | 输入  | 数据     | 写端口的数据输入总线，提供要写入寄存器的数据                  |
| **WE**   | 1 位  | 输入  | 控制     | 写使能信号（Write Enable），$\text{WE}=1$ 时允许写入 |
| **CLK**  | 1 位  | 输入  | 时钟     | 时钟信号，写操作在时钟触发边沿到来时执行                    |

##### 读操作（组合逻辑操作）
- 读操作属于**组合逻辑操作**，**无须**时钟信号 CLK 控制。
- 当地址 Ra 和 Rb 到达后，经过一个"**取数时间**"的延迟，busA 和 busB 上的信息开始有效。

$$\text{Ra} \xrightarrow{\text{取数时间}} \text{busA 有效} \qquad \text{Rb} \xrightarrow{\text{取数时间}} \text{busB 有效}$$

##### 写操作（时序逻辑操作）
- 写操作属于**时序逻辑操作**，**需要**时钟信号 CLK 的控制。
- 在 $\text{WE} = 1$ 的情况下，时钟触发边沿到来后，经过 **Clk-to-Q** 时间延迟，从 busW 传来的值开始写入 Rw 指定的寄存器中。

$$\text{WE}=1, \; \text{CLK 边沿} \xrightarrow{\text{Clk-to-Q}} \text{busW 的值写入 Rw 指定的寄存器}$$

##### 总结对比

| | 读操作 | 写操作 |
|--|--------|--------|
| **逻辑类型** | 组合逻辑 | 时序逻辑 |
| **是否需要 CLK** | 否 | 是 |
| **地址信号** | Ra、Rb | Rw |
| **数据总线** | busA、busB（输出） | busW（输入） |
| **控制信号** | 无 | WE（写使能） |
| **延迟** | 取数时间 | Clk-to-Q |
