- **指令流水线设计**的第一步是**要对每条指令的执行过程进行分析**，以**确定流水线每个功能段的功能和执行时间**。

- **每条指令前两个功能段都一样**：
	- **取指(IFetch)**：从**指令存储器**中取出指令，并**计算PC + 4**。
	- **寄存器/译码(Reg/Dec)**：从**寄存器堆**中**读取操作数**，并**对指令进行译码**。
	- 后续功能段则根据具体指令类型有所不同，见下。

## 1. R型指令的功能段划分
- R型指令属于**寄存器-寄存器型(RR 型)指令**，其操作数和结果均位于**通用寄存器**中。
- 典型的R型指令**从寄存器 Rs 和Rt 读取源操作数**，在 ALU 中完成指定运算，并**将结果写入目的寄存器 Rd**。
	- 注意：像 add 和 sub 等指令还要**判断结果是否溢出**，只有**不溢出时才写结果到Rd**，否则转异常处理程序执行。

- R型指令在流水线中经过 **IFetch 阶段**后，进入: 
	- **寄存器/译码(Reg/Dec)**：**读取寄存器Rs、Rt**中的操作数，并对指令进行译码。
	- **执行(Exec)**：在 ALU 中**完成运算**。 
	- **写回(Write)**：将 ALU 的结果**写入寄存器堆中的 Rd**。

## 2. I型运算类指令功能段划分
- I型带立即数的**运算类指令**都涉及**对16位立即数进行符号扩展或零扩展**,然后和**Rs的内容**进行运算，最终把ALU的运算结果**送目的寄存器 Rt**。
- 显然，**I型运算类指令**的功能段划分与**R型指令**相同。

## 3. lw 指令功能段划分
- lw 指令也是**I型指令**，但不是运算类指令。
- lw指令的功能为：`R[Rt] <- M[R[Rs] + SEXT(imm16)]`，即从存储器中**读取一个字**并**写入寄存器 Rt**。
	- 它将 Rs 的值与**符号扩展**(Sign Extension)后的16位立即数相加，形成**有效地址**，再从该地址**读取数据**。
- lw 指令在流水线中经过 **IFetch 阶段**后，进入：
	- **寄存器/译码(Reg/Dec)**：**读取寄存器Rs**中的操作数，并对指令进行译码。
	- **执行(Exec)**：**计算内存地址**`(R[Rs] + SEXT(imm16))`
	- **访存(Mem)**：从数据存储器中**读取一个字**。
	- **写回(Write)**：将读取的数据**写入寄存器堆中的Rt**。

## 4.sw指令功能段划分
- sw 指令也是**I型指令**，但不是运算类指令。
- sw指令的功能为：`M[R[Rs] + SEXT(imm16)] <- R[Rt] `，即把寄存器Rt的内容**写入存储器**中。
