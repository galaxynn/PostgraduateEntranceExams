- 指令不仅要规定所执行的操作，还要给出**操作数**或**操作数地址**。
	- 操作数可能是一个**常数**，或一个**简单变量**，或是数组和结构中的某个元素，也可能是栈(stack)中的数据，还可能是外设**I/O接口**中的**状态字或控制字**等。
	- 从指令的角度来看，**操作数存放位置**可以是CPU 中的**通用寄存器**、**主存存储单元**和**I/O端口**。

- **有效地址**：指令中给出的**操作数所在存储单元的地址**。
	- **存储单元地址**可能是**主存物理地址**，也可能是**虚拟地址**。
		- 若**不采用**虚拟存储机制，有效地址就是**主存物理地址**；若**采用**虚拟存储机制，则有效地址就是**虚拟地址**。

- **寻址方式**是指**确定指令或操作数有效地址的方法**，包括**确定下一条待执行指令的地址**以及<font color="#ff0000">本条指令所需操作数的地址</font>。

- 寻址方式分为**指令寻址**和**数据寻址**两大类。
	- **确定下一条将要执行的指令地址**称为**指令寻址**。
	- **确定本条指令操作数地址**称为**数据寻址**。


## 指令寻址
- **确定下一条将要执行的指令地址**称为**指令寻址**。

- 指令寻址有两种方式：**顺序寻址**和**跳跃寻址**。

- (1) **顺序寻址**
	- 通过**程序计数器**(PC)加上**当前指令的字节长度**，**自动形成**下一条指令地址。
	- **PC自增的大小**与**编址方式和指令字长**有关。（⭐⭐）
	- 现代计算机通常按**字节编址**，PC + **“1”** 代表：
		- 若**指令字长为16位(2字节)**，则**PC自增为(PC)+2**
		- 若**指令字长为32位(4字节)**，则**PC自增为(PC)+4**。
		- 也就是说，计算机按字节编址，**取指令时，每取1字节，PC自动加1**。
	- 如果**不是按字节编址**（按字节编址**也能用**），依据：**指令字长占n个地址，PC自增为(PC) + n**。（⭐）
	- 如果是**变长指令字结构**，系统会**根据操作码判断这条指令的长度**，自增相应的值。

- (2) **跳跃寻址**
	- 通过**转移类指令**的**数据寻址**实现。（**用数据寻址实现**指令寻址的跳跃寻址。）
	- 是否发生转移通常由**状态寄存器中的条件码**决定，**转移目标地址由指令给出**。
	- **转移方式**分为：
		- ① **绝对转移**，地址码**直接给出目标地址**。
		- ② **相对转移**，地址码**给出相对于当前PC值的偏移量**。
		- 无论何种方式，**转移指令**的**执行结果都是修改PC的值**，CPU随后根据新的PC从主存取出下一条指令。

## 数据寻址
- **数据寻址**指如何**在指令中表示或计算操作数的地址**。

- 为**区分不同寻址方式**，指令字中**通常设有寻址特征字段**，其**位数决定了可支持的寻址方式种类**。典型指令格式如下：（⭐）
	- ![[第四章 4.2寻址方式 指令格式.png]]

- **指令中的地址码字段**所包含的地址称为**形式地址(A)**，它**不代表**操作数的**真实地址**。
- **真实地址**需通过**寻址方式**由形式地址**计算得出**，称为**有效地址(EA)**。
	- 若为**立即寻址**，则**形式地址的位数**决定了**操作数的取值范围**。（⭐）
	- 若为**直接寻址**，则**形式地址的位数**决定了**可寻址的存储空间大小**。（⭐）
	- 若为**寄存器寻址**，则**形式地址的位数**决定了**通用寄存器的最大数量**。（⭐）
	- 若为**寄存器间接寻址**，则**寄存器的位数**决定了**可寻址空间大小**。（⭐）

- (A)表示**地址A处所存放的内容**，A可以是**寄存器编号**或**内存地址**。

- 指令是**固化在机器指令的二进制代码里**的，是**编译时确定的**。（⭐⭐）
	- **指令的静态属性**：指令本身（**含操作码和形式地址A的字段**）被**固化在二进制代码中**，经过编译后是**只读的**，**运行时不会、也不能随意修改**。
	- **运行时的动态属性**：**存储单元**（内存）和**寄存器**属于硬件资源，**其内容是动态的**，可以随时被CPU或操作系统**修改**。
	- **动态寻址的本质**：正是利用了这种差异，在某些寻址方式（如变址寻址、间接寻址、相对寻址）中，**同一条静态指令在多次执行时**，通过改变**寄存器内容**（如变址寄存器IX）或**间接指向的存储单元内容**，就能**动态算出不同的有效地址**（EA）。
	    - **具体细分**：
	        - 直接寻址：A不变，EA固定，**无法遍历数组**。
	        - 变址寻址：A固定（作为基准），**IX动态改变**，实现**数组遍历**。
	        - 寄存器间接寻址：A指向一个寄存器，**寄存器内存放动态的地址**，常用于链表遍历。
	        - 相对寻址：通过**修改程序计数器PC的当前值**，实现**程序的转移**。
	- **结论**：用户程序选择**动态改变**“寄存器”或“存储单元”的值，而**不是修改指令里的A**，不仅硬件上效率更高，也**避免了破坏指令流水线和指令只读保护机制**。
### 1. 隐含寻址
- **隐含寻址**是指**指令中不显式给出操作数地址**，而**将操作数地址隐含在特定寄存器中**。
	- 例如，在**累加器型结构**中，单地址指令**仅显式指定一个操作数地址**，另一个操作数**默认来自累加器(ACC)**，运算结果也**通常存回ACC**。
	- ![[第四章 4.2寻址方式 隐含寻址.png]]
- 优点：可有效缩短指令字长。
- 缺点：依赖存储隐含操作数的硬件(如ACC)。

### 2. 立即寻址
- 在立即寻址中，指令的形式地址字段**并不表示操作数的地址**，而是**直接存放操作数本身**，称为**立即数**，通常**以补码形式表示**。（⭐）
	- 如图所示，#表示**立即寻址特征**，A即为**立即数**。
	- ![[第四章 4.2寻址方式 立即寻址.png]]
- 优点：操作数已包含在指令中，执行阶段**无须访问存储器**，**指令执行速度最快**。
- 缺点：**立即数的大小**受限于**形式地址字段的位数**，寻址范围非常有限。

### 3. 直接寻址
- **直接寻址**是指**指令中的形式地址A就是操作数的真实地址EA**，即 **EA=A**。

- ![[第四章 4.2寻址方式 直接寻址.png]]
- 优点：实现简单，无须额外计算操作数地址，执行阶段**只需访存一次**。
- 缺点：**形式地址A的位数**限制了**寻址范围**，且**地址固定**，难以动态修改。
	- 例如，若形式地址字段占24位，则**直接寻址**范围为$2^{24}$=16M。

### 4.间接寻址
- **间接寻址**是**相对于直接寻址**而言的，指令中的**形式地址A并不直接给出操作数的有效地址**，而是**指向一个主存单元**，**该单元中存放操作数的有效地址**，即**EA=(A)**。
- ![[第四章 4.2寻址方式 间接寻址.png]]
	- 注：间接寻址特征为@。

- 除了一次间接寻址，还可有**多次间接寻址**。

- 优点：可**扩大寻址范围**(有效地址 **EA 的位数**通常**大于**形式地址**A的位数**，由**存储字长**决定)，并支持**地址动态生成**(如实现指针和转移表)。
- 缺点：指令执行阶段需**多次访存**(一次间址需**2次访存**)。
	- 由于访存开销较大，若需**兼顾寻址范围与执行效率**，通常采用**寄存器间接寻址**。

- **间址周期**：解析**间接寻址**方式下的**有效地址(EA)**。（⭐）
	- 仅在指令的**寻址特征位**表明为"**间接寻址**"时**才进入该周期**。
	- 直接寻址、立即寻址、寄存器寻址等**均无间址周期**。

### 5.寄存器寻址
- 与直接寻址类似，**寄存器寻址**将**操作数存放在寄存器中**，指令的地址字段给出的是**操作数所在寄存器的编号**，即 EA = $R_i$ ，**操作数**位于**由$R_i$指定的寄存器内**。
	- 可以把寄存器编号$R_i$视为一个**特殊的地址**。
- ![[第四章 4.2寻址方式 寄存器寻址.png]]
- 例如，若 CPU 有32个通用寄存器，则**寄存器编号需5位**，**形式地址字段仅需5位**即可**寻址全部寄存器**。
- 优点：**执行阶段无须访存**，仅访问寄存器，**执行速度快**；且因寄存器数量**远少于**内存单元，地址码位数较少，有助于**缩短指令字长**。
- 缺点：寄存器成本高，CPU中**可用寄存器数量有限**。

### 6. 寄存器间接寻址
- **寄存器间接寻址**结合了**间接寻址**和**寄存器寻址**的特点，指令中的$R_i$所指寄存器中**存放的不是一个操作数**，而是**操作数所在主存单元的地址**，即EA=($R_i$)。
- ![[第四章 4.2寻址方式 寄存器间接寻址.png]]

- 相比**间接**寻址，**寄存器间接寻址**在执行阶段**只需一次访存**，减少了访存开销。
- 相比**寄存器**寻址，这种方式在执行阶段需要**从主存获取操作数**，增加了访存需求。
- 由于该方式**使用寄存器来存储有效地址**，其**寻址范围不受形式地址字段位数限制**，从而**扩大了寻址范围**。

### 7. 相对寻址（⭐⭐）
- **相对寻址**是指**将程序计数器(PC)的内容与指令中的形式地址A相加**，形成**转移目标地址**，即 **EA = (PC) + A**。
	- 其中，PC为取指完成后自动更新的值（PC + "1"后的值），即PC指向**下一条指令的地址**；A是**相对于该PC值的偏移量**，是一个**带符号整数**，**可正可负**，通常以**补码**表示。（⭐）
	- 也就是：**EA = 当前指令的下一条指令的地址 + A**（⭐）
	- **偏移量 A** 是**编译器、汇编器和链接器**这类“工具”**自动计算并填入指令**的。（⭐）
- ![[第四章 4.2寻址方式 相对寻址.png]]
- **相对寻址**主要用于**转移类指令**，**形式地址 A 的位数**决定了**转移范围**。
	- JMP等转移指令**将数据寻址计算出的EA送入PC**。（用数据寻址实现指令寻址的跳跃寻址）
	- 例如，假设某机器按**字节**编址，**指令长度为2B**。
	- 一条相对转移指令(JMP A)位于地址 1000H，其形式地址 A = 0005H (**补码表示**)，则**取指完成后PC = 1002H**，**实际转移目标地址**为**1002H** + 0005H = 1007H。

- 优点是**目标地址不固定**，而是**相对于当前指令位置偏移**，因此**程序可在内存中任意浮动而不 影响转移正确性**，便于**实现重定位和共享代码**。


### 8. 基址寻址
- **基址寻址**是指将**基址寄存器(BR)的内容**与**指令中的形式地址A** 相加，形成**操作数的有效地址**,即**EA = (BR) +A**。
	- 其中，**BR**（**B**ase address **R**egister） 可以是专用基址寄存器或**指定的通用寄存器**。

- ![[第四章 4.2寻址方式 基址寻址.png]]

- 在**多道程序环境**下，基址寄存器的内容**由操作系统设定**，**在程序执行期间保持不变(作为基地址)**；而**形式地址A作为偏移量**，由**用户程序指定**。（⭐）
	- 也就是：**BR不变，A变**。
		- 注意，**变**指的是：**不同指令**中的A是不同的，而不是指**同一条指令**在循环过程中A会自动变化。
	- 当使用**通用寄存器**作为基址寄存器时，尽管**用户可选择哪个寄存器扮演此角色**，但其内容**仍由操作系统控制**。

- 例子：
	1. **程序员视角（形式地址 A）**：程序员在代码中写了一条指令，想要读取**本程序开头往后偏移 100 个字节**的数据。因此，这条指令中的**形式地址 A = 100**。这个 A 是由用户程序指定的，是相对偏移量。
	2. **操作系统视角（基址寄存器 BR）**：操作系统将程序 P 加载到了主存的**物理地址 5000** 开始的位置。由于在多道程序环境下，基址寄存器内容**由操作系统设定**，因此操作系统把基址寄存器 **BR 的值设为 5000**。
	3. **CPU 执行过程**：当 CPU 执行这条指令时，ALU 进行加法运算：
	    - **有效地址 EA = (BR) + A = 5000 + 100 = 5100**。
	    - CPU 就会直接去主存的 **5100** 号地址读取操作数。

- 优点：
	- 可**扩大寻址范围**(因基址寄存器位数通常大于形式地址A)，能访问更大的地址空间；
	- **简化编程**，用户**无须关注程序在主存的具体位置**，有利于**多道程序设计**和**浮动程序**的实现，类似于动态重定位。
		- 如果系统**内存紧张**，操作系统想**把程序 P 从 5000 挪到 8000 的位置**，它**只需要将基址寄存器 BR 的值修改为 8000** 即可。程序内部的代码（A=100）**一行都不用改**，依然能访问到正确相对位置的数据。用户**无需知道**自己程序在内存中的具体物理地址。

- 缺点：形式地址A的位数较短，**限制了偏移量的范围**。

### 9. 变址寻址
- **变址寻址**是指将**变址/索引寄存器(IX)的内容**与**指令中的形式地址A**相加，形成**操作数的有效地址**，即 **EA = (IX) + A**。
	- 其中，**IX**（**I**nde**X** register）可以是专用变址寄存器或**指定的通用寄存器**。
- ![[第四章 4.2寻址方式 变址寻址.png]]

- 变址寄存器**面向用户**，其**变址寄存器的内容**(作为**偏移量**)可以**在程序执行中由用户动态修改**，而**形式地址A**(作为**基地址**)**保持不变**。
	- 也就是：**IX变，A不变**。

- 优点：该方式不仅**扩大了寻址范围**，还特别适用于**数组**等数据结构的处理，即通过**调整IX的值**，可**高效访问数组中任意元素**，非常**适合编写循环程序**。
	- 例如，假设**数组B首地址为1000H**，存储在**形式地址A**中，**变址寄存器IX初始为0**。要访问B[3]元素(每个元素占4B)，可**将IX置为0CH(3x4=12)**，则该元素 EA=(IX)+A=0CH+1000H=100CH。

- 尽管变址寻址与基址寻址均通过“**寄存器内容 + 形式地址**”生成有效地址，但**二者本质不同**: 
	- **基址寻址面向系统**，BR 的内容**由操作系统设定且运行时不可变**，用于支持多道程序和存储分配，**不适用于循环遍历**。
	- **变址寻址面向用户**，IX 的值可**由程序动态调整**，用于**灵活的数据访问**，适用于循环遍历。

## 偏移寻址
- **相对寻址、基址寻址和变址寻址**均属于**偏移寻址**，其共同特点是**通过某个寄存器的值与形式地址相加**来确定操作数的有效地址，便于统一理解和应用。

- **EA = (R) + A**
	- 从**语义**上，可以理解为**无符号地址**加上**有符号偏移**。
	- 从**硬件**上，是把偏移**符号扩展**后，与 PC 做**普通二进制加法**。
	- 加法器**本身不区分有符号还是无符号**，**最终的值**取决于**解释方式**。

- (R)是一个无符号数，二进制即为其真值的二进制。
- A是一个**有符号数**，其二进制用**补码表示法**。
- 但是，在计算机的视角里，它们**都是普通的二进制**，加法器只是简单地**将这两个二进制相加**，而**不区分它们是用什么编码表示的**。

- **普通十进制字面量**通常**默认是 int 型（补码表示）**，但它们**参与表达式或赋值给其他类型时**，会按目标类型或表达式规则**转换类型**。

## 10. 堆栈寻址
- 堆栈是**存储器(或寄存器组)** 中一块**按后进先出原则管理的特定存储区**，其**读/写单元的地址**由一个称为**堆栈指针(SP)** 的**特定寄存器**给出。
- **堆栈**可分为两类：
	- **硬堆栈**由**高速寄存器**构成，成本较高，容量较小；
	- **软堆栈**则是**从主存中划分一段区域实现**，更为**经济实用**。

- 在采用**堆栈结构**的计算机中，多数指令**表面上表现为无操作数形式**，因为其**操作数地址由SP隐含指定**。在**访问堆栈**时，SP会**自动更新**以指向新的栈顶位置。


- 上述各寻址方式的**有效地址计算方法**及**访存次数**(**不含取本条指令**)的总结见下表。

| 寻址方式          | 有效地址             | 访存次数（**不含取本条指令**） |
| :------------ | :--------------- | :---------------- |
| 隐含寻址          | EA = 隐含（如累加器ACC） | 0                 |
| 立即寻址          | A 即是**操作数**      | 0                 |
| 直接寻址          | EA = A           | 1                 |
| 一次间接寻址        | EA = (A)         | 2                 |
| 寄存器寻址         | EA = Rᵢ          | 0                 |
| **寄存器间接一次寻址** | EA = (Rᵢ)        | 1                 |
| **相对寻址**      | EA = (PC) + A    | 1                 |
| **基址寻址**      | EA = (BR) + A    | 1                 |
| **变址寻址**      | EA = (IX) + A    | 1                 |
| 堆栈寻址          | EA = (SP) 或栈顶    | 1                 |


- 实际应用中，往往**需要多种寻址方式复合使用**。
	- 方法：**把先寻址的结果EA，作为后寻址的输入A**。（⭐）
	- 例如：基址寻址 + 变址寻址、间接寻址 + 相对寻址、等等。
