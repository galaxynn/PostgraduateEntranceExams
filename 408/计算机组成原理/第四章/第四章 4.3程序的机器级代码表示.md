## 常用汇编指令介绍
- 汇编指令通常可分为**数据传送指令**、**算术与逻辑运算指令**和**控制流指令**。

- 以下**用于操作数的标记**分别表示寄存器、内存和常数。
- `<reg>`：表示**任意寄存器**，若其后**带有数字，则指定其位数**。
	- `<reg32>`表示32位寄存器(eax,ebx, ecx, edx, esi, edi, esp或ebp);
	- `<reg16>`表示16位寄存器(ax, bx, cx或dx);
	- `<reg8>`表示8位寄存器(ah, al, bh, bl, ch,cl,dh, dI)，
- `<mem>`：表示**内存地址**(如[eax]、[var+4]或dwordptr[eax+ebx])。
- `<con>`：表示8位、16位或32位常数。
	- `<con8>`表示8位常数；
	- `<con16>`表示16位常数；
	- `<con32>`表示32位常数。

- x86 指令采用**变长编码**，其**操作码通常为1字节**，但**整条指令长度可变**。
	- 同一指令(如mov) 因**操作数类型或寄存器不同**，可能对应**多种机器码编码**，例如：
	- ![[第四章 程序的机器级代码表示 mov1.png]]

- `dword/word/byte ptr + [A]`：指明内存读写长度为**双字**/**单字**/**单字节**。
- [A]：表示取**寄存器或地址A**中的**内容**。类似于C语言中，**指针解引用**。

### 数据传送指令
#### 1. mov指令
- 格式：`mov dest, src ;dest <- src`
	- **操作数 = 数据本身 或 数据的存放地点**
	- **源操作数**可以是**立即数、寄存器或主存单元**，**目的操作数**可以是**寄存器或主存单元**，但**不能是立即数**。
- 作用：把1字节或**字**（需要显式表示）的**操作数**从**源地址 src** 传送至**目的地址 dest**。
```
mov al, 4; al <- 4，将立即数的值传送到al寄存器（立即数寻址）
mov byte ptr [2000h], 5 ; 将常数5存入地址 2000h 处的1字节内存单元（直接寻址），byte ptr 说明是字节操作
```
- **双操作数指令**的**两个操作数不能同时为内存**，即 mov 指令不能用于直接从内存复制到内存。 
	- 若**需在内存之间复制**，可先将**源内存内容加载到寄存器**，再**从该寄存器写入目标内存**。（利用**寄存器中转**。）

#### 2. push指令
- 格式：`push <reg32>/<mem>/<con32>`
- 作用：**将操作数压入栈中**，常用于**函数调用和现场保护**。
- 栈中元素**固定为32位**，即**4字节**。
- ESP是**栈顶指针寄存器**，入栈前**先将ESP减4**(栈向**低地址方向**增长)，再将操作数**压入**ESP所指地址。（先减，再压。）
	- 不变量：ESP指针**始终指向当前栈顶元素**。
```
push eax ; 将 eax 的值压栈
push [1000h] ; 将 地址1000h 处的 4字节内容 压入栈中
```

#### 3. pop指令
- 格式：`pop <reg32>/<mem>`
- 作用：与push指令相反，从栈中**弹出栈顶**，并将其**保存到指定位置**。
- 出栈前先将ESP所指地址的内容**读出**，再将**ESP加4**。（先读，再加。）
	- 不变量：ESP指针**始终指向当前栈顶元素**。
