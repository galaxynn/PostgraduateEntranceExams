# I/O 时间占 CPU 总时间比例：定义、证明与计算方法

## 1 稳态假设与局部推整体的正确性证明

### 1.1 基本假设

系统满足稳态均匀 I/O 工作条件：

1. 外设以恒定频率发起 I/O 请求，相邻请求时间间隔固定；
2. CPU 处理单次 I/O 操作的时钟周期数恒定；
3. CPU 主频保持不变，无频率动态调整。

### 1.2 符号定义

- $f$：CPU 主频，单位 $\text{Hz}$，表示每秒总时钟周期数
- $N$：单次 I/O 操作消耗的 CPU 时钟周期数
- $k$：每秒 I/O 请求总次数
- $T_0$：单次 I/O 物理耗时，$T_0 = \dfrac{N}{f}$
- $T_s$：相邻两次 I/O 的时间间隔，$T_s = \dfrac{1}{k}$
- $\eta$：I/O 时间占 CPU 总时间的比例
- $T_{\text{total}}$：任意全局观测时长，$T_{\text{total}} > 0$

### 1.3 核心定理

在稳态均匀 I/O 假设下，单个 I/O 周期内的 I/O 时间占比恒等于全局任意时长内的 I/O 时间占比，即：

$$
\eta = \frac{T_0}{T_s} = \frac{\text{全局总 I/O 耗时}}{\text{全局总观测时间}}
$$

### 1.4 严格证明

1. 全局总 I/O 耗时：在时长 $T_{\text{total}}$ 内，I/O 总次数为 $k \cdot T_{\text{total}}$，总耗时为
   $$
   T_{\text{io,total}} = k \cdot T_{\text{total}} \cdot T_0
   $$

2. 全局占比定义：
   $$
   \eta = \frac{T_{\text{io,total}}}{T_{\text{total}}} = \frac{k \cdot T_{\text{total}} \cdot T_0}{T_{\text{total}}} = k \cdot T_0
   $$

3. 代入 $T_0 = \dfrac{N}{f}$、$T_s = \dfrac{1}{k}$，可得：
   $$
   \eta = \frac{T_0}{T_s}
   $$
   即局部单周期占比与全局占比相等，与观测总时长 $T_{\text{total}}$ 无关。

## 2 两种标准计算方法

### 2.1 方法一：物理时间法（宏观视角、时间角度）

**计算公式**
$$
\eta = \frac{\text{单次 I/O 物理耗时}}{\text{相邻 I/O 时间间隔}}
$$

**适用场景**

题目给出数据传输率、I/O 物理耗时、外设准备时间等时间类参数。

**计算步骤**

1. 由外设传输速率计算间隔时间 $T_s = \dfrac{1}{k}$；
2. 由周期数与主频计算单次 I/O 耗时 $T_0 = \dfrac{N}{f}$；
3. 代入公式得到占比。

### 2.2 方法二：时钟周期法（微观视角、频率角度）

**计算公式**
$$
\eta = \frac{\text{每秒 I/O 总周期数}}{\text{CPU 每秒总周期数}} = \frac{N \cdot k}{f}
$$

**适用场景**

题目给出 CPU 主频、单次 I/O 周期数、每秒 I/O 次数等周期/频率类参数。

**计算步骤**

1. 计算每秒 I/O 总周期数：$N \cdot k$；
2. CPU 每秒总周期数即为主频 $f$；
3. 两者比值为 I/O 时间占比。

## 3 两种方法等价性证明

由物理时间法展开：
$$
\eta = \frac{T_0}{T_s} = \frac{\dfrac{N}{f}}{\dfrac{1}{k}} = \frac{Nk}{f}
$$
结果与时钟周期法公式完全相同，因此两种方法数学等价。

## 4 解题选用原则

1. 题干以时间、传输速率为主要已知条件 → 优先使用物理时间法（时间角度）；
2. 题干以主频、时钟周期数、I/O 频率为主要已知条件 → 优先使用时钟周期法（频率角度）；
3. 两种方法计算结果一致，可互相校验。

注意：DMA方式算时间占比，若题目给出了传输速率，则无需考虑DMA接口中数据缓冲寄存器的位数。
因为速率本身已经隐含（考虑）了：数据缓冲寄存器的位数、总线宽度、单次DMA传送的数据宽度等。
