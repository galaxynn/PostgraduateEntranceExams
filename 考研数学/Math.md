## **观察法** 或 **凑微分法** 解微分方程
> 核心口诀：看到 $f(y)\cdot y'$，就凑成 $\bigl(F(y)\bigr)'$，其中 $F'(y)=f(y)$，然后令 $u=F(y)$。

| 观察形式                             |                      凑成导数 |
| -------------------------------- | ------------------------: |
| $y y'$ 或 $2y y'$                 |       $\left(y^2\right)'$ |
| $\cos y \cdot y'$                |    $\left(\sin y\right)'$ |
| $\sec^2 y \cdot y'$              |    $\left(\tan y\right)'$ |
| $\frac{y'}{y}$                   |                 $(ln y)'$ |
| $e^y \cdot y'$                   |       $\left(e^y\right)'$ |
| $\frac{1}{\sqrt{1-y^2}}\cdot y'$ | $\left(\arcsin y\right)'$ |
