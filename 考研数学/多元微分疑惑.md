### 总结要点

| 比较维度     | 方法一：直接求导法                                      | 方法二：公式法                      |
| :------- | :--------------------------------------------- | :--------------------------- |
| **对象设定** | $z = z(x,y)$，依附于自变量                            | 构造 $F(x,y,z)$，$x, y, z$ 地位对等 |
| **计算关键** | 遇到 $z$ 必须连带乘出 $\dfrac{\partial z}{\partial x}$ | 求某变量偏导时，其余变量一律视作常数           |
| **适用场景** | 适合概念理解或方程形式简单时                                 | 适合复杂方程、高阶偏导或标准化计算            |

### 一、核心本质对比
- ![[3db8d378e8a95a92a5de5367f48b32c7.jpg]]
- ![[11f50ff193dabda84a3d7e4ebaa4257e.jpg]]
两种求导方法的核心区别在于：**变量之间的依赖关系（即自变量与因变量的设定）不同**。

* **直接求导法（图 1）**：方程被视为“**动态**”约束。$x$ 与 $y$ 是自变量，$z$ 是**因变量**，即 $z = z(x,y)$。对 $x, y$ 求偏导时，**$z$ 必须按照复合函数求导法则（链式法则）处理**。
* **隐函数求导公式法（图 2）**：将原方程转化为三元**静态**函数 $F(x,y,z) = 0$。在定义 $F$ 时，$x, y, z$ **暂时被视为三个地位平等的独立自变量**。求 $F_x'$ 时，直接将 $y$ 和 $z$ 均视为**常数**。


### 二、方法一：直接对等式两边求偏导

设由方程确定的隐函数为 $z = z(x, y)$。

原方程为：
$$(x^2 + y^2)z + \ln z + 2(x + y + 1) = 0$$

两边对自变量 $x$ 求偏导：
1. 对第一项 $(x^2 + y^2)z$ 求导（利用乘积法则）：
   $$\frac{\partial}{\partial x}\left[(x^2+y^2)z\right] = 2xz + (x^2+y^2)\frac{\partial z}{\partial x}$$
2. 对第二项 $\ln z$ 求导（利用链式法则）：
   $$\frac{\partial}{\partial x}[\ln z] = \frac{1}{z} \frac{\partial z}{\partial x}$$
3. 对第三项 $2(x+y+1)$ 求导：
   $$\frac{\partial}{\partial x}[2(x+y+1)] = 2$$

将各项代入原等式：
$$2xz + (x^2+y^2)\frac{\partial z}{\partial x} + \frac{1}{z}\frac{\partial z}{\partial x} + 2 = 0$$

移项并提取公因式 $\dfrac{\partial z}{\partial x}$：
$$\left(x^2 + y^2 + \frac{1}{z}\right) \frac{\partial z}{\partial x} = -(2xz + 2)$$

解得：
$$\frac{\partial z}{\partial x} = -\frac{2xz + 2}{x^2 + y^2 + \dfrac{1}{z}} = -\frac{2z(xz + 1)}{(x^2 + y^2)z + 1}$$

### 三、方法二：利用隐函数求导公式

构造三元辅助函数：
$$F(x, y, z) = (x^2 + y^2)z + \ln z + 2(x + y + 1)$$

此时 $x, y, z$ 被视作相互独立的三个变量，分别求一阶偏导数：

* 对 $x$ 求偏导（将 $y, z$ 均视作常数）：
  $$F_x' = 2xz + 2$$
* 对 $z$ 求偏导（将 $x, y$ 均视作常数）：
  $$F_z' = x^2 + y^2 + \frac{1}{z} = \frac{(x^2 + y^2)z + 1}{z}$$

根据多元隐函数求导公式 $\dfrac{\partial z}{\partial x} = -\dfrac{F_x'}{F_z'}$，代入得：
$$\frac{\partial z}{\partial x} = -\frac{2xz + 2}{\dfrac{(x^2 + y^2)z + 1}{z}} = -\frac{2z(xz + 1)}{(x^2 + y^2)z + 1}$$

### 四、公式推导与严谨性补充

隐函数求导公式 $\dfrac{\partial z}{\partial x} = -\dfrac{F_x'}{F_z'}$ 的本质，正是利用多元复合函数的链式法则推导而来的：

将 $z = z(x,y)$ 带回方程，恒等式为：
$$F\big(x, y, z(x,y)\big) \equiv 0$$

两端对自变量 $x$ 求偏导：
$$\frac{\partial F}{\partial x} \cdot \frac{\partial x}{\partial x} + \frac{\partial F}{\partial y} \cdot \frac{\partial y}{\partial x} + \frac{\partial F}{\partial z} \cdot \frac{\partial z}{\partial x} = 0$$

因为 $x, y$ 互为独立自变量，故：
$$\frac{\partial x}{\partial x} = 1, \quad \frac{\partial y}{\partial x} = 0$$

代入简化为：
$$F_x' + F_z' \frac{\partial z}{\partial x} = 0 \implies \frac{\partial z}{\partial x} = -\frac{F_x'}{F_z'} \quad (F_z' \neq 0)$$
