
## 第 3 题｜考点/题型：数列极限
- 题目：![[数学2014年真题 3.png]]

### 分析
- 我的问题：
	- 没思路，**想不到凹凸性**，**还以为是泰勒公式**？
	- 遗忘：**二阶导函数的正负**反映**曲线的凹凸性**。

- 错因：
	- 知识性错误 / 方法性错误 

- 正确思路/方法：
	- 利用好**凹凸性**。
	- ![[数学2014年真题 3-3.png]]
	- **弦的方程**可以利用曲线上的任意两点求出来。
	- 曲线与弦的位置关系 和 曲线切线的位置关系恰好**相反**。
	- **题目给的方程g(x)实际上就是弦的方程**！（**要敢于整理**）
		- $g(x)$即过$(0, f(0)), (1，f(1))$的**弦的方程**。
		- 所以， $g(x) \ge f(x)$ 表示**弦在曲线之上**，$g(x) \le f(x)$ 表示**弦在曲线之下**。
	- ![[数学2014年真题 3-4.png]]
	- 仅凭**单调性**(即$f'(x)$的正负)**无法判定曲线与弦的位置关系**，反例见上。
		- $f'(x)$**取等号**是**广义单调增/单调减**，即**单调不减/单调不增**
	- 凹凸性(即$f''(x)$的正负)才能判定曲线与弦的位置关系。
		- $f''(x) \ge 0$，凹曲线。（**取等号**是广义凹曲线）
		- $f''(x) \le 0$，凸曲线。（**取等号**是广义凸曲线）
	- 补充：$x_1$和$x_2$两个系数相加为1就有这个不等式。（相当于左边式子把$f$乘进去了一样。）![[数学2014年真题 3-5.png]]
- 下次提醒，如何避免：
	- 下次**遇到函数/方程时**，要**敢于整理**，或**作逆运算**。
	- 见到**二阶导正负**时，要能想到可以利用**凹凸性解题**。
		- 凹凸性应用：考虑**两个位置关系**，与**弦**的位置关系，与**切线**的位置关系，**这两条直线都能用$f(x)/f'(x)$表示出来**。

	- **思维定势调整方法**：
		- 某思路**做不出来**时，想一下：**好像这个思路不对，不一定是这个思路，有没有别的思路**？
		- 也就是说，一个思路/方法做不出来时，**不要死磕，换一种返璞归真的方法说不定就做出来了**！

- 错因：
	- 知识性错误 / 方法性错误

- 正确思路/方法：
	- 使用**逆推的思路**：求含$ξ$的极限，那$ξ$能不能**利用题目条件**，把它用$x$表示出来？从而得到了**解决问题的起始点**。

- 下次提醒，如何避免：

## 第 6 题｜考点/题型：多元函数最值与极值的关系/判定极值充分条件
- 题目：![[数学2014年真题 6.png]]

### 分析
- 我的问题：
	- 没思路。**不知道偏导和最值的联系**。

- 错因：
	- 知识性错误 / 方法性错误 

- 正确思路/方法：
	- **最值 和 极值 有联系，极值 和 偏导有联系**，因此 最值 和 偏导 有联系。
	- **有界闭区域**D中的**连续**函数**必有最大值和最小值**。
		- **最值点**要么在**区域D内部**，要么在**区域D的边界**。
			- **区域D内部的最大/最小值必为极大/极小值**。（核心）
				- $D内有最值 → D内有极值$
				- **逆否命题**：$D内无极值 → D内无最值$（核心）
		- **极值点**只能在**区域D内部**取得。
			- 区间端点、区域边界点处**不定义为极值点**。
			- 由题目条件可知**偏导数信息**，再由**判断极值的充分条件**，推出区域D内部**无极值**，则**无最值**，所以**最大/最小值只能在区域D的边界上取到**。
	- $A + B = 0 \rightarrow AB \le 0(异号)$（**常用条件**）
- 下次提醒，如何避免：
	- 判断**最值**时，要想到利用**极值**作为中介条件，想到**最值和极值的关系**。
	- 总结一下**极值和最值的关系**。

## 第 8 题｜考点/题型：向量组线性相关性 | 充分性不确定
- 题目：![[数学2014年真题 8.png]]

### 分析
- 我的问题：
	- 必要性会证明，**充分性不确定**，证不出来，所以选了A。但**没举出反例**。

- 错因：
	- 知识性错误

- 正确思路/方法：
	- 反例/特例：设$\alpha_1, \alpha_2$线性无关，令$\alpha_3 = 0$，则$\alpha_1 + k\alpha_3 = \alpha_1$，$\alpha_2 + l\alpha_3 = \alpha_2$，线性无关。但**含零向量的向量组必然线性相关**，则$\alpha_1, \alpha_2, \alpha_3$线性相关，充分性不成立。
		- 事实上，举反例就是举**特例**，**取特值**（类似代码的**边界条件**）。
	- 证向量组线性相关/无关的方法：
		- ① 定义法，**设向量组的线性组合为0**，**再证其系数全为0**。
			- 又分为：拆分重组、大胆同乘(**将式子化短，便于逐个击破**)。
		- ② 用秩：列向量组列满秩/行向量组行满秩。
		- ③ 方程组角度：齐次方程组只有零解/有非零解。

- 下次提醒，如何避免：
	- 证充分性/必要性时，证不出来时，要学会**举特例**，特殊一点，通常是令 某东西 = 0。

## 第 21 题｜考点/题型：多元函数微分学/定积分几何应用(二重积分)
- 题目：![[数学2014年真题 21.png]]

### 分析
- 我的问题：
	- 用了武的公式，计算的时候出现**知识性错误**：将**上限**的$y$**代入**被积函数的$y$，从而被积函数与$y$无关，然后把它提到前面了。
	- 隐藏错误：**曲线的函数图像没画出来**，没找到零点。

- 错因：
	- 知识性错误

- 正确思路/方法：
	- 用武的公式没问题，但是**不要混淆了**$y$。
	- $r(x,y)$ 是**被积函数**。
	- 被积函数中的$x或y$**不能直接代入**，**不要动被积函数，被积函数是固定的**！**除非换元**。
	- 本题中，**曲线的函数图像分为两半**（因为平方开根号要**加绝对值**），一半在$y=-1$上方，一半在$y=-1$下方，由于是求**旋转体体积**，**仅用上方区域即可**。

- 下次提醒，如何避免：
	- 下次积分时：
		- 上限**不确定**时，**可以暂时写为**$y(x)$，但**不能混淆**了被积函数中的$y$和上限中的$y$！（$x$也类似）。
		- **曲线的$y/x$不要乱代入**被积函数的$y/x$，**被积函数只有换元时才改变**。
	- **平方开根号，加绝对值**。

- 答案：答案用的是**微元法**，我们用武公式就行。
