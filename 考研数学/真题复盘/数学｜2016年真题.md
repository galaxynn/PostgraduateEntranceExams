- 题目：![[数学2016年真题 5.png]]

### 分析
- 我的问题：
	- 见到凹凸性(二阶导) → 2条性质：曲线和弦的位置关系，曲线和切线的位置关系。
		- 凸曲线，切线在曲线上方 → 排除 C、D
	- 根据曲率公式和$f_1'(x_0) = f_2'(x_0)$，推出$f_1''(x_0) < f_2''(x_0)$后，就**没有思路了**。

- 错因：
	- 知识性错误

- 正确思路/方法：
	- ① 构造函数$F(x) = f_1(x) - f_2(x)$ + 极值的第二充分条件。
		- 具体而言：
			- 公切线, 有$f_1(x_0)=f_2(x_0), f_1'(x_0)=f_2'(x_0)$；由曲率大小关系，$f_1''(x_0) < f_2''(x_0)$
			- 则 $F(x_0) = f_1(x_0) - f_2(x_0) = 0$，$F'(x_0) = f_1'(x_0) - f_2'(x_0) = 0$，$F''(x_0) = f_1''(x_0) - f_2''(x_0)<0$
			- $F(x)$在$x=x_0$的一阶导=0，二阶导＜0，由极值的第二充分定理可知，$F(x_0)$是极大值
			- 由极大值的定义可知，在邻域内有$0 = F(x_0)\ge F(x)$，则$0 \ge f_1(x) - f_2(x), f_2(x) \ge f_1(x)$
	- ② 几何法
		- **公切线的题目**举特例思路 → **两条凸/凹曲线在一点处相切**。
		- **根据凹凸性画曲线**（**不需要像答案一样精确**，大致曲线即可），曲率大的曲率半径小（圆小，在大圆内部），曲率小的曲率半径大（圆大，在小圆外部）。
		- 根据位置关系即可快速判断。

- 下次提醒，如何避免：
	- 可用 **构造辅助函数 + 极值的第二充分条件** 判断函数大小。
	- **公切线的题目**举特例思路 → **两个圆的曲线在一点处相切**，学习一下几何法。

## 第 16 题｜考点/题型：带绝对值的定积分定义的函数/分段函数求导
- 题目：![[数学2016年真题 16.png]]
	
### 分析
- 我的问题：
	- 对$x$的**取值范围**讨论**不完整**，**漏掉**了$x\ge1$的情况，从而导致误以为$0<x<1$的函数表达式就是$x\ge1$的函数表达式。
	- **没有完善的方法论**。

- 错因：
	- 知识性错误 / 方法性错误

- 正确思路/方法：
	- 分析可得积分变量是$t$，本题中$t$的取值范围固定为$[0, 1]$，所以应该**讨论函数自变量$x$的取值范围**，**画数轴讨论**。
	- **第一步：找零点（寻找绝对值变号点）**
	   * 明确**积分变量是 $t$**，将自变量 $x$ 视为**常数**。
	   * **令绝对值内部为 $0$**：$t^2 - x^2 = 0 \implies t = x$（因 $x > 0, t \in [0, 1]$，负根舍去）。
	   * **变号点**即为 $t = x$。
	-  **第二步：划区间（比较零点与积分上下限的位置）**
	   * **积分区间**为 $t \in [0, 1]$。
	   * ![[数学2016年真题 16-4.png]]
	   * 考察零点 $t = x$ 与区间 $[0, 1]$ 的**相对位置**：
	     * **零点落在区间外**：当 $x \ge 1$ 时，$t \in [0, 1] \implies t \le x$，绝对值内部符号**恒定为负**，**无需分段积分**。
	     * **零点落在区间内**：当 $0 < x < 1$ 时，零点将 $[0, 1]$ **截断**为 $[0, x]$ 和 $[x, 1]$ 两段，**必须拆区间分段积分**。
	- **第三步：积分显式化，严格求导与最值分析**
	   * 计算积分，得到 $f(x)$ 的**分段表达式**。
	   * **严谨性关键**：在区间内部直接求导，而在**分段连接点**（本题为 $x=1$）处，**必须利用导数定义（或左右导数极限）检验其是否可导**。
	   * 根据导数符号列表分析单调性，确定最值。

- 下次提醒，如何避免：
	- 遇到**带绝对值的定积分定义的函数**时，**对定义域的讨论**要**涵盖所有区间**，不要漏掉任何一个区间！（画**数轴讨论**，不会遗漏情况。）
	- 分段函数**求导数**，需要**分别计算左、右导数**。
		- **左导数 = 右导数 = A** 的**充要条件**是 **导数 = A** 
	- 细节：由**分段**函数$f(x)$的**连续性**，才能保证**最小值点**是$x=1/2$！

## 第 17 题｜考点/题型：多元微分学/求隐函数的极值
- 题目：![[数学2016年真题 17.png]]

### 分析
- 我的问题：
	- 用公式法，**计算错误**，上下同乘$z$的时候，下面**漏了**$z$。
	- 用公式法，代值的时候，**算错数**（-2-2-2算成-8了！）
	- 用公式法，先代后求的时候，**代了$z$**（**不能先代**$z$，因为$z$是**自变量**！下次注意！）
	- 极值点类型判断错误（A<0时，是**极大值点**！）

- 错因：
	- 知识性错误 / 方法性错误 / 计算性错误 

- 正确思路/方法：
	- **求极值目标**：
		- ① 求$z(x,y)$的**驻点**，**驻点**的**两个偏导数为0**。
		- ② **判定极值**：用极值的**充分条件**$Δ=AC-B^2$判定极值，需要用到**二阶偏导数**，所以需要求**二阶偏导数**（驻点处的，因此不一定要求出二阶偏导表达式，只需要直到它在某一点处的值即可）。
	- 思路①：答案用了**两边求偏导数的方法**构造**一阶偏导数方程**，**注意**因变量$z$是自变量$x,y$的函数，**不能**将$z$视为常数。
		- 然后利用**驻点**的**两个偏导数为0**这个条件代入方程，解出$x,y,z$之间的关系，再代回原方程**求解出驻点**。
		- 再对一阶偏导数方程三次偏导，得出**二阶偏导数方程**，再**代入驻点**，即可求得A、B、C（驻点处的二阶偏导数）。
	- 思路②：**隐函数求导公式**（一阶偏导公式+二阶偏导公式） + 驻点的必要条件简化计算（**无需**先代后求）
		- **隐函数求导公式**构造了一个**新的函数**$F(x,y,z)$，它的自变量是$x,y,z$，在这个函数中，$z$**不再是因变量**！所以对$x,y$求偏导的时候，**可以**将$z$视为常数。
		- **对一阶偏导公式再求偏导**，可推导出**二阶偏导公式**！
	- 注意观察法求$z$时，要证明其唯一性（用**单调性**）。

- 下次提醒，如何避免：
	- **先代后求**时**不能先代入因变量**$z$，所以**另寻他法**。
		- 而且**驻点较少的时候**，才用先代后求，否则计算量更大。
	- **两种思路都要练习，学会**！

## 第 20 题｜考点/题型：定积分的几何应用/参数方程/体积/表面积
- 题目：![[数学2016年真题 20.png]]

### 分析
- 我的问题：
	- 当时**没想到**用大体积减去小体积，<u>想用一个式子计算出来</u>，但**实际上做不到**。
	- **完全不知道**<u>表面积是可以相加求得的</u>。

- 错因：
	- 知识性错误 / 方法性错误

- 正确思路/方法：
	- ![[数学2016年真题 20-4.png]]
	- 设球体的半径为 $R$
	-  **球体体积公式**：  $$V = \frac{4}{3}\pi R^3$$  
		- 若为半径为 $R$ 的半球体，其球体内部体积为 $V_{\text{半球}} = \frac{1}{2} \times \frac{4}{3}\pi R^3 = \frac{2}{3}\pi R^3$
  
	 - **球面面积公式（整个完整球面的表面积）**：  $$S = 4\pi R^2$$
		- 若为第一象限圆弧绕 $x$ 轴旋转一周得到的**半球面**，其侧表面积为 $S_{\text{半球外表面}} = \frac{1}{2} \times 4\pi R^2 = 2\pi R^2$
	- **体积**：$V = V_{外} - V_{内}$
	- **表面积**：$S = S_{外侧} + S_{内侧} + S_{底面1} + S_{底面2}$ （全部相加！）
	- “侧面积” vs “总表面积”（严防漏算底面）  
		* 侧面积：仅指平面曲线绕轴旋转扫出的那张**弯曲曲面**。  
		* 总表面积（全面积）：包含**侧面积 + 所有平底面（端面）**。  
		* **自检提问**：平面图形的**边界线上**有没有落在**坐标轴**或**直线**上的线段？如果有，旋转后会**生成平的圆形或圆环形底面**，必须**加进总表面积**！  
		* 对比示例：  
			* **本题**：两条曲线在 $(0,1)$ 和 $(1,0)$ 直接首尾相接，封闭成“月牙形”，边界全是弯曲曲线，因此**总表面积 = 外侧曲面 + 内侧曲面**（无底面）。  
			* **变式题**：如果是由 $y = x^2$ 与 $y = 1$ 围成的区域绕 $y$ 轴旋转，求所得立体的总表面积，答案必须是 **抛物面侧面积 + 顶部圆盘底面积 $\pi \times 1^2$**。
- 下次提醒，如何避免：
	- 遇到**两条曲线围成的区域**：
		- 体积：$V = V_{外} - V_{内}$
		- 表面积：$S = S_{外侧} + S_{内侧} + S_{底面1} + S_{底面2}$ （**全部相加**！）
			- 学的那个公式是**侧面积**公式。
			- 本题中**无底面**。

## 第 23 题｜考点/题型：矩阵运算/矩阵相似对角化求高次幂

### 分析
- 我的问题：
	- **第二问**没有思路，**不知道怎么构造出**$A$的**高次幂**。
	- 仅尝试了$B^{100} = (B^2)^{50}$，发现做不了，然后就没思路了。（思维太浅了）

- 错因：
	- 知识性错误 / 方法性错误

- 正确思路/方法：
	- **归纳推理**，巧用$B^2 = BA$：
		- 两边**左乘**$B$，变为$B^3 = B^2A = (BA)A = BA^2$，同理，$B^4=B^2A^2=BAA^2 = BA^3$，用**数学归纳法**（验、设、证）来证明$B^n = BA^{n-1}$。
			- **左乘的原因**：凑$B^2$，再把$B^2$代换成$BA$，**根本目的**是找$B^n$与A的关系。
		- 则$B^{100} = BA^{99}$，$A^{99}$**刚好是第一问求的**。
			- 由“前列线，则后系数”可知，$A^{99}$的**各列**就是$B$的**列向量的线性组合系数**，利用分块矩阵乘法即可（向量组的矩阵表示）

- 下次提醒，如何避免：
