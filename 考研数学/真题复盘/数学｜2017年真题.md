## 第 17 题｜考点/题型：定积分定义求极限 | 思路记录
- 题目：![[数学2017年真题 17.png]]

### 分析
- 正确思路/方法：
	- 对于有理函数积分[[一元积分小观#有理函数积分]]：
		- 核心：<u>想方设法凑分母/分母的导数</u> + 拆开算。
		- ① 分子次数 = 分母次数：直接拆项 → 分子凑出分母（恒等变形）+ 拆开算。
		- ② 分子次数 > 分母次数：提项 + 拆项 → 提 $x^m$，在括号里凑出分母（恒等变形） + 拆开算。
		- ③ 分子次数 < 分母次数：
			- 分子0次，分母2次：
				- 分母不可因式分解：配方 + 凑微分（arctanx）
				- 分母可因式分解：**待定系数法**（分子比分母的底数低1次，几次幂就加几个。）
			- 分子1次，分母2次：分子**凑出分母的导数** + 拆开算。

## 第 20 题｜考点/题型：二重积分 | 思路记录
- 题目：![[数学2017年真题 20.png]]

### 分析
- 正确思路/方法：
	- 和答案思路不一样，但是**利用对称性化简**的思路可以学习借鉴。
	- **偏心圆** → **平移换元**（构建新的u-v坐标系），左加右减，上减下加。
	- 被积函数变成$(u+1)^2$，这时要**学会展开**，再利用**对称性**，简化计算。
		- 区域关于$u=0$对称，$(u+1)^2 = u^2 + 2u + 1$，$2u$的积分没了，1 的积分是**圆的面积**，所以我们**只需要算$u^2$的二重积分**了。
		- 此时，用极坐标和直角坐标都行。
	- 没化简前，感觉极坐标似乎不太好用，所以选了直角坐标，**但也要三角换元**，**殊途同归**。

	- <font color="#ff0000">总之</font>，要学会这种**化简思路**：**被积函数能展开就展开，展开便于逐项化简**！
		- 相当于把一个被积函数**拆成多个被积函数**，**各个被积函数的对称性不同**，可以<u>逐个击破</u>。


## 第 22 题｜考点/题型：行列式和秩与特征值的关系 /解线性方程组 / 线性组合找特解
- 题目：![[数学2017年真题 22.png]]

### 分析
- 我的问题：
	- 第(I)问卡住了，原因：
		- **不知道怎么用**“有三个不同的特征值”这个条件。
		- 后面回头做的时候，**才慢慢推导出来**。

- 错因：
	- 知识性错误 / 方法性错误

- 正确思路/方法：
	- “**有三个不同的特征值**”这个条件的用法：
		- ① 三阶矩阵，有<u>三个不同的特征值</u>，则**必可相似对角化**。
		- ② **可对角化矩阵**，其秩**等于**非零特征值的个数。（**核心**）
		- ③ 由另一个条件，易得$\alpha1,\alpha2,\alpha3$线性相关，即$r(A) \le 2$，不满秩。
		- ④ **不满秩**，则$|A| = 0$，则**必存在一个特征值为0**。（重要）
		- ⑤ 又因为三个特征值互不相同，则**只有一个特征值为0**，**其余两个特征值不为零**，则$r(A) = r(\Lambda) = 2$
	- 第(I)问还有一个**好思路**：
		- $Ax=0$的**非零解**，**是特征值0对应的特值向量**。
			- 如果$Ax=0$**有非零解**，那就说明**A有0特征值**。
			- **根据题目条件**，可以很容易的找出它有非零解。
	- 第(I)问是第(II)问的**提示/阶梯**，提示了$Ax=0$的基础解系中**只包含一个解向量**，所以，**任意一个解向量**都可以当成其基础解系中的解向量。
		- 所以，**目标转换**为：找**齐次**、非齐次方程组的一个**特解**。

## 第 23 题｜考点/题型：二次型的正交变换/实对称矩阵的正交相似对角化
- 题目：![[数学2017年真题 23.png]]

### 分析
- 我的问题：
	- 首先，用错了方法 + 计算错误 导致**浪费了很多时间**，**问题很大**。
		- **错误的方法**是指：**没有想到**利用秩得到行列式的信息，从而求解参数，<u>而是</u>**直接求特值多项式的零点，然后比较系数，从而计算出参数**，这种方法**计算量很大**，一不小心就错了。（太暴力了）
		- 计算错误是指：求解带参数的特值多项式行列式时，**不易化简**，<u>导致计算混乱，抄错项等诸多计算问题</u>。
	- 其次，正交相似对角化时，特值向量**忘记正交化、单位化**，也是一个**大问题**。

- 错因：
	- 方法性错误 / 计算性错误

- 正确思路/方法：
	- 本题**确定参数的核心思路**：
		- **可相似对角化的矩阵**，其**秩**等于**非零特征值的个数**。（**22题**也要用这个结论！**必须牢记**！）
			- 底层原因：**相似的必要条件**——$r(A) = r(\Lambda)$，$r(\Lambda) = 非零特征值的个数$
			- **实对称矩阵**必可相似对角化，必可正交相似对角化。
	- 正交相似对角化/求正交矩阵时，**不要忘记正交化、单位化**！

- 下次提醒，如何避免：
	- 下次遇到**可以相似对角化的矩阵/实对称矩阵(二次型矩阵)时**，如果**给出了特征值相关信息**(以**不同表现形式**给出)，让你求秩/参数/行列式，可考虑使用：**可相似对角化的矩阵**，其**秩**等于**非零特征值的个数**。
		- 也就是说，**可相似对角化矩阵的特征值/秩/行列式是密切相关的**，它们之间可以互推。
	- 正交相似对角化/求正交矩阵时，**不要忘记正交化、单位化**！
		- 重根才需要正交化 → 用避开⑩的技巧，但也**不要忘了正交化的公式**。
