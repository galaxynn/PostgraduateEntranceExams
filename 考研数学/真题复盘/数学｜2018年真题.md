
## 第 4 题｜考点/题型：函数的凹凸性 / 举特例 / 泰勒公式 
- 题目：![[数学2018 4.png]]

### 分析
- 我的问题：
	- A、C可以画图举特例排除，B、D不知道怎么排除。
	- 不知道用什么方法，**误用了弦和曲线的位置关系**，事实上这题用的是**切线和曲线的位置关系**，因为要求的是**一点处的信息**。

- 错因：
	- 知识性错误 / 方法性错误 

- 正确思路/方法：
	- ![[数学2018 4-2.png]]
	- **为什么**用切线，而不是用弦：
		- 由于研究的是**一点处即$f(1/2)$处的正负信息**，所以要用切线方程。
		- 之所以**想到切线，而不是弦**，根本原因在于：**切线**不等式**能把“单点函数值 $f\left(\frac{1}{2}\right)$”作为主体分离出来**，而**割线**（弦）一定会**引入端点值** $f(0)$ 和 $f(1)$，导致信息被“污染”无法闭环。
		- 如果用**割线（弦）**，连接 $(0, f(0))$ 和 $(1, f(1))$ 的**割线方程**是：  $$g(x) = f(0) + [f(1) - f(0)]x$$
		- **切线是局部的**，它只需要一个点：$x = \frac{1}{2}$。  在 $x = \frac{1}{2}$ 处的**切线方程**为：  $$y = f\left(\frac{1}{2}\right) + f'\left(\frac{1}{2}\right)\left(x - \frac{1}{2}\right)$$
	- 给曲线凹凸性，**什么时候用切线，什么时候用弦**？
		- 涉及“**两端点值**”用**弦**，涉及“**区间内部某点值（或导数值）**”用**切线**。

	- 这种**含定积分**的题，一般都是要**画图分析**，利用定积分的几何性质，<u>举特例</u>**排除选项**，增加正确概率，要**培养这种能力**。
	- 给单调信息/凹凸信息**举特例**思路：<u>构造</u>**简单的满足题意的函数**。
		- **简单**的$f'(x)>0/f'(x)<0$函数：
			- 线性函数 $f(x) = ax+b$：
				- $a>0时，f'(x)>0$
				- $a<0时，f'(x)<0$
		- **简单**的$f''(x)>0/f''(x)<0$函数：
			- 二次函数 $f(x) = ax^2 + bx + c$：
				- $a>0时，f''(x)>0$
				- $a<0时，f''(x)<0$
			- 本题中进一步简化，取$b=0$，怎么简单怎么来！

- 下次提醒，如何避免：
	- 给曲线凹凸性，涉及“**两端点值**”用**弦**，涉及“**区间内部某点值（或导数值）**”用**切线**。
	- 平时要养成**举特例解题排除**的习惯和能力，而不是造轮子。
		- **遇到难题时**（一眼**没思路**的题），想想能不能**举特例**，就好像代码题遇到难题了，直接**暴力解**。（举特例就像暴力解。）
		- 选择题**不是看你会不会**，而是看你**能不能选出正确答案**。

## 第 15 题｜考点/题型：不定积分的计算
- 题目：![[数学2018年真题 15.png]]

### 分析
- 我的问题：
	- **分部积分时，系数抄错了**，$t^4$的系数$1/2$抄成$1/4$了，可能是由于指数是4，抄写时**混淆了指数和系数**。
	- **选择的方法也不太好**，直接换元再凑微分再分部积分了，有点暴力。

- 错因：
	- 知识性错误 / 方法性错误 / 计算性错误 

- 正确思路/方法：
	- 计算复杂的不定积分时，通常是**先凑微分，凑到不能凑了之后，(可分部积分)，再换元，这时式子会更简单一点**！
	- **指数相加**是**相乘**，$2x = x + x$，则$e^{2x}$可以写成$e^x × e^x$，然后凑微分。

- 下次提醒，如何避免：
	- 计算时要细心，耐心，一个不小心就可能抄错了，所以**每次抄写时要回头检查一下系数是否都抄对了**。
	- 多练<u>积分计算</u>的题目，**练熟练度、练思路**。

## 第 17 题｜考点/题型：二重积分的计算/三角定积分的计算
- 题目：![[数学2018年真题 17.png]]

### 分析
- 我的问题：
	- **不会计算**三角相关定积分，式子太复杂，**不知道用什么方法**，思路混乱。
	- 式子复杂时，**不会创造条件**，利用**奇偶性化简**。
	- 对**二倍角公式**不熟练。

- 错因：
	- 知识性错误 / 方法性错误 / 计算性错误 

- 正确思路/方法：
	- ① 区间**不对称**时，<u>区间减，函数加</u> / **敌退我进换元法** → 人为构造对称区间（**没条件时，创造条件也要上**）
		- 区间减，函数加 或者说 <u>敌退我进换元法 </u>**考试时直接用就行了，不要顾虑**。
		- **敌退我进换元法**：<u>积分变量</u>和<u>积分上下限</u>做相反的操作(运算)。
			- 其中，对于积分变量$t$，$dt$里面的$t$**也要做对应的操作**！（本质就是换元，只不过**简化步骤，更方便！**）
			- 考试时直接使用，**无需顾虑太多**。
	- ② **二倍角公式(降幂公式)** 的变式：$cosx$的**消1作用**
		- 看到 $cosx$ 和 1 呆在一起，要**警觉**起来。
		- 原式：
			- $cos^2 x = \frac{1+cos2x}{2}$
			- $cos2x=2cos^2x-1=1-2sin^2x=cos^2x-sin^2x$
			- 变式：令$x=\frac{x}{2}$，则$cosx=2cos^2\frac{x}{2}-1=1-2sin^2\frac{x}{2}=cos^2\frac{x}{2}-sin^2\frac{x}{2}$
		- ![[数学2018年真题 17-6.png]]
	- ③ 巧用**分配律** + 凑微分
		- ![[数学2018年真题 17-7.png]]
		- 如图，把$(1-cost)^2$**当成一个整体**，**巧妙使用分配律**，因而后面的式子可以**凑微分**。
- 下次提醒，如何避免：
	- 区间**不对称**用不了奇偶性 / 区间**不适配**点火公式 / 区间与题目体条件**不匹配**时，就要想到**人为创造条件**，不要想换元（**太绕**），直接用**敌退我进换元法**！（重要）
