## 第 6 题｜考点/题型：导数的应用 / 曲率 / 相切
- 题目：![[数学2019年真题 6.png]]

### 分析
- 我的问题：
	- **充分性不会证**，必要性**误以为曲率相等就是二阶导数相等**，<u>把绝对值忽略了</u>。
	- 想不到用**泰勒公式**。

- 错因：
	- 知识性错误 / 方法性错误

- 正确思路/方法：
	- 在求极限的问题中，分母出现 $(x - a)^k$ 的形式，本质上就是在**测量分子在 $x \to a$ 时的无穷小阶数**。  
		- 分母是 $(x - a)^2$  
		- 极限结果是 $0$  
  
		- 这用极限语言直白地翻译出来就是：  $$\text{分子 } [f(x) - g(x)] \text{ 是比 } (x - a)^2 \text{ 更高阶的无穷小，即 } o((x - a)^2)$$  
		- 而**把一个未知函数在某点附近展开成 $(x-a)$ 的幂次多项式 + 高阶无穷小**，数学里<u>最直接、最通用的工具</u>就是**泰勒公式**。
	- $$\begin{matrix}  
\text{看到 } \frac{h(x)}{(x-a)^2} \to 0 \\  
\Downarrow \\  
\text{意识到 } h(x) \text{ 需要展开到 } (x-a)^2 \text{ 阶} \\  
\Downarrow \\  
\text{题干恰好给了“2阶可导”} \\  
\Downarrow \\  
\text{展开后的多项式系数正好直接对应 } h(a), h'(a), h''(a) \\  
\Downarrow \\  
\text{直接对应结论里的“交点、切线斜率、曲率”}  
\end{matrix}$$
	  - 因此，只要看到 **“$n$阶导数” + “分母为 $(x-a)^n$ 的极限”**，**泰勒公式**几乎是第一反应的最优解。
	  - **坑**：曲率相等 $\implies$切点处对应的**二阶导数绝对值相等**，但是并**不能说明二阶导数相等**。
	- 相切：<u>函数值相等，导数值相等</u>。

- 下次提醒，如何避免：
	- 在求极限的问题中，分母出现 $(x - a)^k$ 的形式，本质上就是在**测量分子在 $x \to a$ 时的无穷小阶数**，要想到**佩亚诺余项的泰勒公式。**
	- **坑**：曲率相等 $\implies$切点处对应的**二阶导数绝对值相等**，但是并**不能说明二阶导数相等**。

## 第 13 题｜考点/题型：积分的计算 / 分部积分 / 交换次序 | 思路记录
- 题目：![[数学2019年真题 13.png]]

### 分析
- 正确思路/方法：
	- 除了交换积分次序，还可以**用分部积分法**。
		- <u>分部积分用法</u>：
			- ① 把**要求导的部分F(x)** 留在$d$前面，其他部分都用凑微分法**凑**到$d$里面去。
				- 求导部分**导数已知** / **可以用公式求出来**时，经常这样用。
			- ② 凑完后**再用分部积分公式**，积分里就会出现$F'(x)$了。
		- 好像<u>也可以直接用表格法，上导下积，感觉更方便</u>。
	- <u>二次积分/累次积分</u> 和 <u>二重积分</u> 的**细节**：
		- ![[数学2019年真题 13-4.png]]
		- 二重积分**写成二次积分时**，上限**一定**要大于下限。
		- 二次积分**换积分限**时，需要**先把二次积分还原成二重积分的形式**，<u>再换限</u>，此时：
			- **如果出现上限小于下限，还原为二重积分时，需要添加负号**。
				- 添一个负号：内层积分或外层积分**之一**的上限小于下限，写成二重积分时前面是**负号**。
				- 添两个负号/不添负号：内层积分和外层积分的上限**都**小于下限，写成二重积分时前面是**正号**，无需添加负号。
		- 综上，题目直接给出的**二次积分的上下限不一定是上限大于下限**，<u>绘制并确定其积分区域</u>时要**小心**！

## 第 22 题｜考点/题型：向量组等价 / 向量组之间的线性表示
- 题目：![[数学2019年真题 22.png]]

### 分析
- 我的问题：
	- 知识性错误，**误以为**只有一种线性表示方式，**误以为**写出一种表示方式即可。
	- **遗漏/没考虑到** $a≠±1$ 的情况。
		- **忽视了**当 $a \neq \pm 1$ 时，向量组也是**等价**的！
		- **误认为** $只有a=1$ 时向量组**等价**，**没充分考虑**$a$的其他取值。
	- **没有充分掌握** 用 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \boldsymbol{\alpha}_3$ 线性表示 $\boldsymbol{\beta}_3$ 的方法！
		- 本质：求**非齐次**线性方程组的**通解**！
			- 要**求出通解**，**不要光看出来其中一个**！

- 错因：
	- 知识性错误

- 正确思路/方法：
	- 将 $\boldsymbol{\beta}_3$ 用 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \boldsymbol{\alpha}_3$ 线性表示，**本质上就是求解非齐次线性方程组**：  $$x_1\boldsymbol{\alpha}_1 + x_2\boldsymbol{\alpha}_2 + x_3\boldsymbol{\alpha}_3 = \boldsymbol{\beta}_3 \iff A\boldsymbol{x} = \boldsymbol{\beta}_3$$
		- $r(A)=r(A,β_3) < 3$ 时，非齐次方程组有**无穷**多解，**有无穷多种线性表示方式**！
		- $r(A)=r(A,β_3) = 3$ 时，非齐次方程组有**唯一**解，**只有一种线性表示方式**。
		- 方法：先<u>解出</u>**非齐次线性方程组的通解**（一个列向量的形式，非多个列向量相加的形式），再**把通解代回原方程**，再**把A列分块，展开成列向量线性组合的形式**。

	- **坑点**：
		- 当 $a \neq \pm 1$ 时，向量组**也是满足等价的**！
		- 也就是说，$a$的取值**不只局限于** $± 1$，而我的视野**只局限于**$a=±1$了！
		- “取值”<u>不一定就是取等号</u>，而可以是**取值范围**。
		- $a$的取值不同，导致**秩不同**，导致**线性表示方式不同**，要**分别求解**。
	- $$  
\begin{matrix}  
\text{① 审题：向量组 } \mathrm{I} \text{ 与 } \mathrm{II} \text{ 等价，含有参数 } a \\  
\Downarrow \\  
\color{blue}{\text{【动机1】回忆等价的充要条件：} r(A) = r(B) = r(A, B) \text{，切忌只算 } r(A)=r(B)} \\  
\Downarrow \\  
\color{blue}{\text{【动机2】避免分别求秩引发重复计算 $\to$ 拼接分块增广矩阵 } (A, B) \text{ 统筹处理}} \\  
\Downarrow \\  
\text{② 对 } (A, B) \text{ 实施初等行变换，化简出关键第3行：} \\  
(0,\ 0,\ a^2-1 \mid a-1,\ 1-a,\ a^2-1) \\  
\Downarrow \\  
\color{blue}{\text{【动机3】抓住公因式 } (a-1) \text{ 与特殊点 } a = \pm 1 \text{ 展开严密分类讨论}} \\  
\Downarrow \\  
\begin{cases}  
a = 1 \implies r(A)=r(B)=r(A,B)=2 \quad (\text{等价}) \\  
a = -1 \implies r(A)=2 \neq r(A,B)=3 \quad (\text{不等价，排除！}) \\  
a \neq \pm 1 \implies r(A)=r(B)=r(A,B)=3 \quad (\text{等价})  
\end{cases} \\  
\Downarrow \\  
\text{③ 锁定参数范围：} a \neq -1 \\  
\Downarrow \\  
\color{blue}{\text{【动机4】求 } \boldsymbol{\beta}_3 \text{ 的表示 $\to$ 提取 } (A, \boldsymbol{\beta}_3) \text{，注意 } a=1 \text{ 时解不唯一}} \\  
\Downarrow \\  
\text{④ 分 } a \neq \pm 1 \text{（唯一解）与 } a = 1 \text{（无穷多解/通解）写出完整表示式}  
\end{matrix}  
$$
- 下次提醒，如何避免：
	- 看到**向量组等价**，**三秩相等**不必多说。
	- <u>下次看见</u>用 $\boldsymbol{\alpha}_1, \boldsymbol{\alpha}_2, \boldsymbol{\alpha}_3$ 线性表示 $\boldsymbol{\beta}_i$ ，**就是求**$A\boldsymbol{x} = \boldsymbol{\beta}_i$的**通解**！
		- 要想到**上面总结的方法**。要**求出通解**，**不要光看出来其中一个**！
		- **求解带参数的方程组**，<u>秩的情况要讨论完整</u>。
	- $A\boldsymbol{x}$的本质就是$A$的**列向量**的**线性组合**（一个式子有**多种理解形式**。）
