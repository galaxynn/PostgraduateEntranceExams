
## 第 5 题｜考点/题型：二重积分比较大小 / 二重积分保序性

### 分析
- 我的问题：
	- 写之前看过讲解，不知道怎么想出来“圆”的。

- 错因：
	- 知识性错误 / 方法性错误 

- 正确思路/方法：
	- 从**原点距离的角度**比构造出“**圆**”更好理解：
		- 当然，也要学习这种思路：<u>如果在正方形区域内，它一定在圆的区域内</u>，要学会**数形结合**，**自己找出条件**。
	- 区域内**任意一点到原点的距离**为 $r = \sqrt{x^2+y^2}$
		- **距离原点最近的点**为原点本身，此时 $r = 0$；  
		- **距离原点最远的点**为正方形的**四个顶点**，此时最大距离为 $r_{\max} = \frac{\pi}{2}$。  
		- 因此，在区域 $D$ 内，**恒有** $0 \le r \le \frac{\pi}{2}$。
	-  $0 \le u \le \frac{\pi}{2}$时，$y = sin u$ 和$y = 1 - cos u$ 的**比较方法**（可推广至其他**涉及函数比较**的题目）：
		- ① 转换为 **证明** $sinu + cosu - 1 >(<) 0$，
			- 即**构造辅助函数** $f(x) = sinx + cosx - 1$, $0 \le x \le \frac{\pi}{2}$，并**注意到** $f(0) = 0 = f(\frac{\pi}{2})$（每构造一个函数，就要找特殊点）
			- 该函数在$[0, \frac{\pi}{2}]$既有单调增区间，又有单调减区间，此时要转换为**一元函数最值问题**，比较各**可疑点**处的函数值，证**最小值/最大值为0**。
		- ② 根据**常见基本初等函数的图像**，**画图**，**数形结合**。（最快）
			- ![[数学2019年真题 5-3.png]]
			- 如图所示，$1-cosx$ 根据**对称** + **上加下减**可以画出来。

## 第 6 题｜考点/题型：导数的应用 / 曲率 / 相切
- 题目：![[数学2019年真题 6.png]]

### 分析
- 我的问题：
	- **充分性不会证**，必要性**误以为曲率相等就是二阶导数相等**，<u>把绝对值忽略了</u>。
	- 想不到用**泰勒公式**。

- 错因：
	- 知识性错误 / 方法性错误

- 正确思路/方法：
	- 在求极限的问题中，分母出现 $(x - a)^k$ 的形式，本质上就是在**测量分子在 $x \to a$ 时的无穷小阶数**。  
		- 分母是 $(x - a)^2$  
		- 极限结果是 $0$  
  
		- 这用极限语言直白地翻译出来就是：  $$\text{分子 } [f(x) - g(x)] \text{ 是比 } (x - a)^2 \text{ 更高阶的无穷小，即 } o((x - a)^2)$$  
		- 而**把一个未知函数在某点附近展开成 $(x-a)$ 的幂次多项式 + 高阶无穷小**，数学里<u>最直接、最通用的工具</u>就是**泰勒公式**。
	- $$\begin{matrix}  
\text{看到 } \frac{h(x)}{(x-a)^2} \to 0 \\  
\Downarrow \\  
\text{意识到 } h(x) \text{ 需要展开到 } (x-a)^2 \text{ 阶} \\  
\Downarrow \\  
\text{题干恰好给了“2阶可导”} \\  
\Downarrow \\  
\text{展开后的多项式系数正好直接对应 } h(a), h'(a), h''(a) \\  
\Downarrow \\  
\text{直接对应结论里的“交点、切线斜率、曲率”}  
\end{matrix}$$
	  - 因此，只要看到 **“$n$阶导数” + “分母为 $(x-a)^n$ 的极限”**，**泰勒公式**几乎是第一反应的最优解。
	  - **坑**：曲率相等 $\implies$切点处对应的**二阶导数绝对值相等**，但是并**不能说明二阶导数相等**。
	- 相切：<u>函数值相等，导数值相等</u>。

- 下次提醒，如何避免：
	- 在求极限的问题中，分母出现 $(x - a)^k$ 的形式，本质上就是在**测量分子在 $x \to a$ 时的无穷小阶数**，要想到**佩亚诺余项的泰勒公式。**
	- **坑**：曲率相等 $\implies$切点处对应的**二阶导数绝对值相等**，但是并**不能说明二阶导数相等**。

## 第 13 题｜考点/题型：积分的计算 / 分部积分 / 交换次序 | 思路记录
- 题目：![[数学2019年真题 13.png]]

### 分析
- 正确思路/方法：
	- 除了交换积分次序，还可以**用分部积分法**。
		- <u>分部积分用法</u>：
			- ① 把**要求导的部分F(x)** 留在$d$前面，其他部分都用凑微分法**凑**到$d$里面去。
				- 求导部分**导数已知** / **可以用公式求出来**时，经常这样用。
			- ② 凑完后**再用分部积分公式**，积分里就会出现$F'(x)$了。
		- 好像<u>也可以直接用表格法，上导下积，感觉更方便</u>。
	- <u>二次积分/累次积分</u> 和 <u>二重积分</u> 的**细节**：
		- ![[数学2019年真题 13-4.png]]
		- 二重积分**写成二次积分时**，上限**一定**要大于下限。
		- 二次积分**换积分限**时，需要**先把二次积分还原成二重积分的形式**，再换限。
			- **如果出现上限小于下限，需要添加负号**。

				- 添两个负号/不添负号：内层和外层的上限**都**小于下限，写成二重积分时前面是正号，无需添加负号。
