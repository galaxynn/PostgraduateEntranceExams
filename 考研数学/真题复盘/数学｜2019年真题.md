
## 第 5 题｜考点/题型：二重积分比较大小 / 二重积分保序性
- 题目：![[数学2019年真题 5.png]]

### 分析
- 我的问题：
	- 写之前看过讲解，不知道怎么想出来“圆”的。

- 错因：
	- 知识性错误 / 方法性错误 

- 正确思路/方法：
	- 从**原点距离的角度**比构造出“**圆**”更好理解：
		- 当然，也要学习这种思路：<u>如果在正方形区域内，它一定在圆的区域内</u>，要学会**数形结合**，**自己找出条件**。
	- 区域内**任意一点到原点的距离**为 $r = \sqrt{x^2+y^2}$
		- **距离原点最近的点**为原点本身，此时 $r = 0$；  
		- **距离原点最远的点**为正方形的**四个顶点**，此时最大距离为 $r_{\max} = \frac{\pi}{2}$。  
		- 因此，在区域 $D$ 内，**恒有** $0 \le r \le \frac{\pi}{2}$。
	-  $0 \le u \le \frac{\pi}{2}$时，$y = sin u$ 和$y = 1 - cos u$ 的**比较方法**（可推广至其他**涉及函数比较**的题目）：
		- ① 转换为 **证明** $sinu + cosu - 1 >(<) 0$，
			- 即**构造辅助函数** $f(x) = sinx + cosx - 1$, $0 \le x \le \frac{\pi}{2}$，并**注意到** $f(0) = 0 = f(\frac{\pi}{2})$（每构造一个函数，就要找特殊点）
			- 该函数在$[0, \frac{\pi}{2}]$既有单调增区间，又有单调减区间，此时要转换为**一元函数最值问题**，比较各**可疑点**处的函数值，证**最小值/最大值为0**。
		- ② 根据**常见基本初等函数的图像**，**画图**，**数形结合**。（最快）
			- ![[数学2019年真题 5-3.png]]
			- 如图所示，$1-cosx$ 根据**对称** + **上加下减**可以画出来。
