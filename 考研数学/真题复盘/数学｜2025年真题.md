- 我的问题：

	- 只能说**运气也是实力的一部分**。
	- **没发觉**到$r$不能等于0：![[数学2025年真题 3-1.png]]
		- 因为误以为和20年那道题一样，**其实是不一样的**。
			- 那道题是**判断函数是否有界**。
			- 这道题是**判断反常积分是否收敛**。
- 错因：
	- 知识性错误 / 方法性错误 

- 正确思路/方法：
	- ![[数学2025年真题 3-2.png]]
	- **正确做法**：
		- ![[数学2025年真题 3-3.png]]
		- <u>算出 Δ 的表达式</u>(含$a$) 以及 <u>列出 韦达定理 的方程组</u>。
		- 讨论 Δ > 0，Δ = 0, Δ < 0 时，$a$的取值范围，**使得积分收敛**。
			- Δ > 0时，**要讨论**λ = 0，λ > 0，λ < 0的情况。
			- Δ = 0时，可以**直接算出**$a$，从而**算出**λ。（如果**不能直接算出**，则**也是要讨论λ = 0，λ > 0，λ < 0的情况**）
			- Δ < 0时，**找出** α 和 $a$ 的关系，**要讨论**α = 0，α > 0，α < 0的情况。
			- 三种情况**取并集**。
