- 我的问题：
	- **感觉没讨论清楚**，只用了韦达定理讨论出大致范围。

		- 因为误以为和20年那道题一样，**其实是不一样的**。
			- 那道题是**判断函数是否有界**。
			- 这道题是**判断反常积分是否收敛**。
- 错因：
	- 知识性错误 / 方法性错误 

- 正确思路/方法：
	- ![[数学2025年真题 3-2.png]]
	- **正确做法**：
		- ![[数学2025年真题 3-3.png]]
		- <u>算出 Δ 的表达式</u>(含$a$) 以及 <u>列出 韦达定理 的方程组</u>。
		- 讨论 Δ > 0，Δ = 0, Δ < 0 时，$a$的取值范围，**使得积分收敛**。
			- Δ > 0时，**要讨论**λ = 0，λ > 0，λ < 0的情况。
			- Δ = 0时，可以**直接算出**$a$，从而**算出**λ。（如果**不能直接算出**，则**也是要讨论λ = 0，λ > 0，λ < 0的情况**）
			- Δ < 0时，**找出** α 和 $a$ 的关系，**要讨论**α = 0，α > 0，α < 0的情况。
			- 三种情况**取并集**。

- 下次提醒，如何避免：
	- 下次遇到类似的题时，**要讨论清楚情况**，注意是积分类型还是有界类型。

## 第 10 题｜考点/题型：矩阵的秩 / 齐次方程组的解的情况 / 同解问题
- 题目：![[数学2025年真题 10.png]]

### 分析
- 我的问题：
	- **蒙的**，**感觉**D是对的。
	- 秩的不等式**混淆**，**误排除**C，**虽然C确实是错误的**。
		- 由 $r(A) \le 2$ 且 $r(B) \le 2$，**无法**得出 $r\begin{pmatrix} A \\ B \end{pmatrix} \le 2$。它的秩最大可以达到 3，$\max(r(A), r(B)) \le r\begin{pmatrix} A \\ B \end{pmatrix} \le r(A) + r(B)$，秩越拼越大。
	- A选项**没排除掉**，没举出反例。
	
- 错因：
	- 知识性错误 / 方法性错误

- 正确思路/方法：
	- “方程组 $Ax=0$ 与 $Bx=0$ 有**公共解**” 等价于 “方程组 $\begin{pmatrix} A \\ B \end{pmatrix} x = 0$ **有解**，且该解即为**公共解**”
	- A、C选项**要通过举反例才能排除**，也就是说题目条件无法完全推出A、C选项，所以A、C选项是错的。
		- “推不出来”就意味着“**不是必然成立**”，而证明一个命题“**不是必然成立**”的**最高标准**就是给出一个满足题干却违背结论的**反例**。
		- 千万不要在考场上花大量时间去给 A、C 构造反例！书上的解析为了严谨，必须向读者证明为什么 A、C 错；但你在考场上做单选题时，**一旦通过正面推理锁死了 D 一定正确，就可以直接选 D 走人**，把宝贵的时间**留给后面的大题**。平时复习时研究反例，是为了加深对概念边界的理解。
	- D选项用了 $r\begin{pmatrix} A \\ B \end{pmatrix} \le r(A) + r(B)$（用$r(A^T) = r(A)$ 和 分块矩阵的**转置**（大转 + 小转）推导的，**直接记也行**），以及 $r(AB) \le \min(r(A),r(B))$, 
		- 技巧：
			- ABA**可拆分**为：A · (BA)！
			- BAB**可拆分**为：B · (AB)！
		- “方程组 $ABAx=0$ 与 $BABx=0$ 有**公共非零解**” 等价于 “方程组 $\begin{pmatrix} ABA \\ BAB \end{pmatrix} x = 0$ **有非零解**”，即$r\begin{pmatrix} ABA \\ BAB \end{pmatrix} < 3$

- 下次提醒，如何避免：
	- 遇到**方程组的解的问题**，优先转换为<u>秩的语言</u>，更加**清晰**。
		- 重要：<u>文字语言</u> → <u>代数语言</u>
