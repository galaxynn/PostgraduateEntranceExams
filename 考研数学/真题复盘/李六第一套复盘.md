- 第8题：
	- r(A) = 1, r($A^2$) = 0 的例子：<u>只有一个1，其余元素全0</u>，且**1不在主对角线上。**（幂零矩阵特征之一：对角线元素为0）
	- r(A) = 2, r($A^2$) = 0 的例子：A利用<u>幂零矩阵B</u>构造一个**分块对角矩阵**，根据秩的等式，其秩为 $r(B) + r(B) = 2r(B) = 2$，且$r(A^2) = r(B^2) + r(B^2) = 0$。
		- **分块对角矩阵的幂等于各对角块分别取幂后组成的分块对角矩阵**。
	- r(A) = 4(满秩)，则$r(A^2)=4$，为什么？
		- 因为 $r(A^2) = r(A×A)$，A**满秩**，A为**可逆矩阵**，<u>左乘/右乘可逆矩阵不改变矩阵的秩</u>！
	- 遇到**秩的取值情况**，可以<u>将秩的可能情况都列举出来</u>，再利用好<u>秩的不等式/等式</u>，**分情况讨论是否可能**。
	- 记一下**西尔韦斯特不等式**，即$r(A) + r(B) \le r(AB) + n$（**通用**）
		- $r(A) + r(B) \le n$ 是 $AB = O$ 时的特例！
