
- 第4题：
	- 思路：
	- 选择题见到**二阶连续函数**，想到<u>泰勒公式</u>/<u>凹凸性</u>。
		- 给了**二阶导正负**信息 → 凹凸性。
		- 直接或间接给出$f(x_0)$，$f'(x_0)$的值（点的信息）→ **泰勒公式**。
			- 泰勒公式可以<u>把函数表达式写出来</u>，从而**进行积分**。
	- 泰勒公式，把值代入后，得$f(x) = \frac{1}{2}xf''(ξ)$，再**利用题目条件放缩**，可得$xf''(x)$的<u>取值范围</u>，接着利用<u>定积分的保号性</u>，即可得到选项A。

- 第6题：
	- 思路：
		- 利用<u>被积函数放缩 + “大收则小收，小发则大发”</u>处理。
		- 有些被积函数**放缩之后可以直接积分**，不能直接积分的可以利用p积分结论。
		- 分母放缩口诀：
			- <u>大于分母变大，小于分母变小</u>。

- 第7题：
	- 思路：
		- 方法1：见到**偏心圆域** → **平移换元**，**利用对称性化简**二重积分。
			- 化简完之后，甚至**可以再换回去**。
		- 方法2：几何意义
			- 利用：$0 < x < 1$时，$x > x^2 > x^3$
			-  $x + y$ 和 1 比大小，比较 $x + y ＞ 1$ 和 $x + y < 1$ 的**区域大小**，**发现 $x + y > 1$ 的区域更大**。
			- 因此，$(x + y)^3$ 的积分**最大**。
