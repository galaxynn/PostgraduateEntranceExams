	- 选择题见到**二阶连续函数**，想到<u>泰勒公式</u>/<u>凹凸性</u>。
		- 给了**二阶导正负**信息 → 凹凸性。

- 第7题：
	- 思路：
		- 方法1：见到**偏心圆域** → **平移换元**，**利用对称性化简**二重积分。
			- 化简完之后，甚至**可以再换回去**。
		- 方法2：几何意义
			- 利用：$0 < x < 1$时，$x > x^2 > x^3$
			-  $x + y$ 和 1 比大小，比较 $x + y ＞ 1$ 和 $x + y < 1$ 的**区域大小**，**发现 $x + y > 1$ 的区域更大**。
			- 因此，$(x + y)^3$ 的积分**最大**。

- 第13题：
	- 错因：脑子抽了，令Δ ≥ 0了。
		- <u>无零点是 Δ ≤ 0！</u>
	- $f(x)$（一元三次函数）没有极值点，即 $f'(x)$ **不变号**（一元二次函数），恒大于等于0或恒小于等于0。
		- ① 先令Δ < 0，必然有$f'(x)>0$ 或 $f'(x) < 0$成立，求出$a$的取值范围。
		- ② 再讨论$Δ=0$时，求出$a$的取值情况，**代回原式，判断是否有极值点**。
