
- 第1题：
	- 错因：**换元没换上下限**。

- 第2题：
	- **导数定义**可以写成$狗→0, \frac{f(1 ± 狗) - f(1)}{1 ± 狗 - 1}$，$f$中间**不一定是加号**。
		- 也就是$Δx$可以是负数。

- 第3题：
	- 没思路。
	- 核心思路：
		- 遇到反函数，则**换元**，利用**反函数**的性质，即$f^{-1}[f(x)] = x = f[f^{-1}(x)]$
		- 换完后，**观察**可知分部积分**可以消去前面的积分**。

- 第6题：
	- 求导后，分式注意**负号的摆放**。

- 第8题：
	- 错因：**不会分块**，不确定分块是不是对的，学一下思路。
	- 由题意得$β^Tα = 0$，则$B^TA = 0$，<u>B行分块，A列分块</u>，**大可乘 + 小可乘**。
	- 见到 $猫 × 狗 = O$，或$狗^2 = O$，**要敏感一点**，立刻想到西尔韦斯特不等式，即$r(A) + r(B) \le r(AB) + n(A的列, B的行)$
	- 由题意得$r(B^T)=r(B)=3$，则$1\le r(A)\le1$(A是非零矩阵)，即$r(A)=1$，得$r(A^*)=0$，则$A^*=O$
	- 则$A^*x = Ox = O$的解，是**全体4维向量**，A的**基础解系中向量个数**为$4 - r(A) = 3$个，故$Ax=0$的解**必然**是$A^*x=0$的解。

- 第10题：
	- 注意到$B$是**实对称矩阵**，则$B-E$，$B-2E$也是**实对称矩阵**，<u>必可相似对角化</u>，可通过**非零特征值个数**反映其**秩**。
	- 求出B的特征值，**即可得出**$B-E$，$B-2E$的**特征值**。
	- $|λE-B|$ 是**分块对角**行列式，可使用**拉普拉斯公式 + 秩1矩阵结论计算**特征值。

- 第11题：
	- 错因：**只求出来** $a = b$，没求出来具体的值，**不确定能不能求具体的值**。
	- 实际上，是**可以通过一个极限式子，确定出多个参数的**。
	- 本题用**同除的方法**定不出$a、b$，那就用**比阶的思想**，<u>通分比阶</u>。

- 第13题：
	- 我的做法：**加项减项、提项**，在分母上凑出$f(x) - f(t)$

	- 其他做法：
		- ① **极限只要不是趋于0**，可**通过换元化成趋于0**。
		- ② 上下**同除**$xt$，**化为另一个函数**的**导数定义**。

- 第14题：
	- 二重积分遇到**取整函数**$[f(x, y)]$时，要**先求出$f(x,y)$的取值范围（两端都是具体数值）**，再**写成分段函数的形式**，**拆分**<u>原积分区域D</u>。
	- 根据向下取整的定义，当整数 $n≤f(x, y)<n+1$ 时，函数值为 $n$。
