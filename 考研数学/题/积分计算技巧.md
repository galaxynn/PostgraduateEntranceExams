针对定积分的计算，尤其是涉及分部积分和正负号较多的情况，结论非常明确：

**绝大多数情况下，“计算过程中直接代值（随走随代、带限计算）”显著优于“先求原函数最后统一代值”。**

下面为你详细解析为什么直接代值更不容易出错，以及如何系统性解决“负号烦人”和“代值容易算错”的问题。

---

### 一、 为什么推荐“过程中直接代值”？

很多人习惯“先求出原函数 $F(x)$，最后算 $F(b)-F(a)$”，觉得这样思维更线性，但在考研或高数考试中，这种方法反而是**致错率最高**的，原因有三：

1. **“边界项快速消零”（核心优势）**
   在分部积分 $\int_a^b u \, \mathrm{d}v = [uv]_a^b - \int_a^b v \, \mathrm{d}u$ 中，边界项 $[uv]_a^b$ 往往**有一端甚至两端算出来直接是 0**（例如遇到 $x=0$、$\sin(k\pi)=0$、$\ln 1 = 0$ 等）。
   * **随走随代**：算出一项是 0 就直接扔掉，草稿纸上的式子越来越短。
   * **最后统一代**：你必须拖着一个包含多项的长串表达式反复写几行，每抄写一遍，抄错正负号或漏乘系数的概率就翻倍。
2. **换元不需要“回代原变量”**
   如果求原函数，设 $t = \sqrt{1-x^2}$ 或 $x = \tan t$，求完积分后你必须把 $t$ 极其痛苦地还原回 $x$ 才能代原上下限；而定积分只需在换元的同时**把上下限换成 $t$ 的取值**，彻底免去回代过程，直接断绝了回代出错的可能。
3. **可以随时利用定积分的特殊性质**
   定积分独有的**奇偶性、对称性（如区间再现公式 $\int_a^b f(x)\mathrm{d}x = \int_a^b f(a+b-x)\mathrm{d}x$）、华里士公式（点火公式）**，在化简过程中可以随时把剩下的积分迅速变成已知常数，而不定积分无法使用这些武器。

---

### 二、 积分代值与消灭“负号”的四大硬核技巧

负号容易错，本质是因为**分部积分的减号、上下限相减的减号、被积函数自带的负号**多层叠加在一起。用好以下技巧可以把负号化解在萌芽状态：

#### 技巧 1：颠倒上下限，直接“吃掉”负号
这是处理负号最漂亮也最严谨的方法。
当你求出的原函数**自带负号**时（如 $-\cos x$、$-\frac{1}{x}$、$-e^{-x}$），**不要写 $-[F(x)]_a^b$，而是直接把上下限颠倒**：
$$[-F(x)]_a^b \equiv [F(x)]_b^a = F(a) - F(b)$$
* **示例**：计算 $[-\cos x]_0^{\pi}$
  * 容易错的写法：$-(\cos\pi - \cos 0) = -(-1 - 1) = 2$（极易数错负号个数）。
  * **颠倒上下限写法**：$[\cos x]_\pi^0 = \cos 0 - \cos \pi = 1 - (-1) = 2$（式子外没有任何负号，一眼看清）。

#### 技巧 2：在分部积分写出积分号的“瞬间”吸收负号
分部积分公式：$\int u \, \mathrm{d}v = uv - \int v \, \mathrm{d}u$。
当 $v$ 本身自带负号时（例如凑微分出现 $\mathrm{d}(-\cos x)$ 或 $\mathrm{d}(-e^{-x})$）：
* **绝对不要**写成：$[u(-v)] - \int (-v)\mathrm{d}u$ 留到下一步。
* **必须在笔尖写下的那一刻，立即把负负得正**：
  $$\int x \sin x \, \mathrm{d}x = [-x \cos x] \mathbf{+} \int \cos x \, \mathrm{d}x$$
  第二项的“减号变加号”必须同步完成，不在纸面上留下任何双重负号。

#### 技巧 3：多次分部积分，强制使用“表格法（DI 法）”
凡是遇到 $P_n(x)e^{ax}$、$P_n(x)\sin(ax)$、$P_n(x)\cos(ax)$ 这类需要做 2 次及以上分部积分的题，**手写多层括号极易符号混乱**，必须改用表格积分法：

以 $\int_0^{\pi} x^2 \sin x \, \mathrm{d}x$ 为例：
1. 列两列：**D 列**（求导项 $x^2$ 直到为 0）、**I 列**（积分项 $\sin x$）。
2. 在连接线标上固定的交替符号（$+ - +$）：

| 符号 | D (求导) | I (积分) |
| :---: | :---: | :---: |
|   | $x^2$ | $\sin x$ |
| **$+$** | $2x$ | $-\cos x$ |
| **$-$** | $2$ | $-\sin x$ |
| **$+$** | $0$ | $\cos x$ |

配对相乘得到各项，直接对每一项分别或统一代限：
原式 $= \Big[ -x^2\cos x + 2x\sin x + 2\cos x \Big]_0^\pi$
* 利用前面的技巧代入：
  * 第一项 $[ -x^2\cos x ]_0^\pi$：上限为 $-\pi^2(-1)=\pi^2$，下限为 $0$。得 $\pi^2$。
  * 第二项 $[ 2x\sin x ]_0^\pi$：上下限都是 $0$（$\sin \pi = \sin 0 = 0$）。得 $0$。
  * 第三项 $[ 2\cos x ]_0^\pi = 2(-1 - 1) = -4$。
* 结果秒出：$\pi^2 - 4$。全过程符号井然有序，没有一层层脱括号的烦恼。

#### 技巧 4：多项式代值——“单项代入”优于“整体代入”
如果你有一个较长的**代数多项式需要代值**，例如求：
$$F(x) = \frac{1}{3}x^3 - 2x^2 + 5x \quad \text{在 } [1, 2] \text{ 的值}$$
* **常规写法（整体代入）**：
  $$\left(\frac{8}{3} - 8 + 10\right) - \left(\frac{1}{3} - 2 + 5\right)$$
  后面整个大括号前面有个减号，括号里各项正负容易变错，且**通分很麻烦**。
* **防错写法（分项代入）**：**把系数留在外面，内部只算 $(b^k - a^k)$**：
  $$= \frac{1}{3}(2^3 - 1^3) - 2(2^2 - 1^2) + 5(2 - 1)$$
  $$= \frac{1}{3}(7) - 2(3) + 5(1) = \frac{7}{3} - 6 + 5 = \frac{7}{3} - 1 = \frac{4}{3}$$
  这种方法每一步都是简单的自然数相减，**完全规避了负号分配律错误和复杂分数反复通分**。

---

### 三、 总结：推荐你的标准做题流

1. **只要涉及分部积分**：
   * 优先**随走随代**。
   * 第一项边界项算完，若有 0 立刻划掉；若带负号，用“颠倒上下限”算完变成常数，不让它进入下一步。
   * 积分号自带的负号在下笔瞬间与内层负号抵消，写成加号。
2. **只要涉及换元积分**：
   * 变元同时**必换限**，永远不再回代。
3. **只有一种极少数情况适合“先求原函数”**：
   * 只有 integrand 是纯粹的有理分式积分（比如需要拆项、待定系数法拆成几个对数和反三角函数，过程中**不包含分部积分、不包含多次换元**），可以把不定积分草稿打完，最后代值。
