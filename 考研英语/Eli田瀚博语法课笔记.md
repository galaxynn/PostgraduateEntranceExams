## 1. 语义
主语 -> 主角
谓语 -> 关系
宾语 -> 配角
定语 -> 修饰 **名词**（主语 / 宾语）
状语 -> 修饰 **动词**（怎么发生的） / 形容词
补语

## 2.词性

### 1. 名词 / 代词
- n.
- 作 主语 / 宾语
- 可数名词
- 不可数名词
- Doing 动名词

- 注意：代词的宾格形式（宾语形式）。
- 核心：找代词代替了谁, 如 It / He / They / This
- This / That 单独做主语, 阅读中一般代替上一句话。
- These / Those 单独做主语, 阅读中一般指代人。
### 2. 形容词
- adj.
- 作 定语, 修饰名词。
- 位置：形容词可以在名词前面, **也可以在名词后面**！例如：
	- Something important is good. 
	- I like this apple red.

### 3. 动词
- v.
- 及物动词vt. / 不及物动词vi.
- 作谓语

- 不及物动词没有宾语。

- 时态 / 语态
	- 时态只有动词有, 不是语法, 是意思。
	- 过去式( v. + ed )：过去做过。无需管现在是否还做。I liked this book yesterday.
