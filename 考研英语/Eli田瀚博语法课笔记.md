## 1. 语义
主语 -> 主角
谓语 -> 关系
宾语 -> 配角
定语 -> 修饰 **名词**（主语 / 宾语）
状语 -> 修饰 **动词**（怎么发生的） / 形容词
补语

## 2.词性

### 1. 名词 / 代词
- n.
- 作 主语 / 宾语
- 可数名词
- 不可数名词
- Doing 动名词

- 注意：代词的宾格形式（宾语形式）。
- 核心：找代词代替了谁, 如 It / He / They / This
- This / That 单独做主语, 阅读中一般代替上一句话。
- These / Those 单独做主语, 阅读中一般指代人。
### 2. 形容词
- adj.
- 作 定语, 修饰名词。
- 位置：形容词可以在名词前面, **也可以在名词后面**！例如：
	- Something important is good. 
	- I like this apple red.

### 3. 动词
- v.
- 及物动词vt. / 不及物动词vi.
- 作谓语

- 不及物动词没有宾语。

- 时态 / 语态
	- 时态只有动词有, 不是语法, 是意思。
	- 过去式( v. + ed )：过去做过。不体现现在是否还做, 纯过去、和现在切断。I liked this book yesterday.
	- 现在完成时( have done )：关联过去和现在, 强调**过去的事和当下有紧密关联, 有某种影响** 。
	- 过去完成时( had done )：过去的过去, 关联过去和过去, 不是到现在, 而是**截止到过去**。
	- 现在完成进行时（have been doing ）：从过去到现在**一直**在做, 以后可能也会做。
	- 过去完成进行时（had been doing ）：从过去到过去**一直**在做。
