## 一、宏观策略与文章阅读法

### 1. 先题后文，串联主旨
- **只看题干，不看选项**：选项含错误信息，会干扰对文章的理解。
- **划定位词**：
  - ① 大写、人名、地名、时间、数字等显眼词。
  - ② 名词、形容词等实义关键词。
- **串联题干**：五道题题干中反复出现的词或信息，就是文章中心。通过串联题干可预判主旨，作为主旨题的双重保险。
- **题文同序**：出题顺序一般与文章行文顺序一致，可据此快速定位。

### 2. 文章精读要点
- **抓态度，抓情感**：考研阅读均为**议论文**，作者观点最重要。重点关注**形容词、副词**等“**满含深情的词**”，**情态动词**，它们直接体现作者立场。
- **抓逻辑，抓重点**：
  - **转折**：but / however / yet 等转折词后是重点；while 大多数情况表强对比（尽管/然而）。
  - **并列**：**多个并列句重复的信息为重点**，需自己总结一下这些句子讲了什么事，减少记忆负担。
  - **递进与强调**：Now 常引出并列或递进的重点内容，后面的信息更重要、更常考。
  - **因果关系**：除了 because，since / as / for 也可表因果。derive from / originate from / stem from / result from / owing to / due to / attribute to 后接**原因**；contribute to 后接**结果**。定语从句也常表因果关系。
- **标点符号利用**：
  - **逗号**：两逗号间或逗号后的补充说明为非主干，先抓主干。
  - **冒号**：前后等价，后面解释前面（抽象→具体）。
  - **分号**：前后为并列关系。
- **情态动词信号**：should 常表示理想与现实的相反；情态动词后接 not 的结构，往往是作者的建议和观点。
- **第一人称**：文中出现 I / we 时，直接表明作者观点，要**重点关注**。
- **引号、反语**：带引号的词常表反语或负面评价。
- **承上启下句**：注意文中起过渡作用的句子，常暗含逻辑。
- **括号内容**：括号里的内容一定要看，常含重要解释。
- **观点明确性**：作者态度通常非模棱两可，一面硬币朝上，抓住主要态度。

### 3. 行文套路预判
- **少数派原则**：作者观点往往是少数人（few, little）的观点。引用大众观点多是为了对比——“我的观点和他们不一样”。
- **今昔对比**：过去的情况与现在的情况通常是相反的，现在的情况往往是文章中心观点，也是答案所在。
- **干扰范围**：出题者喜欢用非定位范围内的信息（如过去、未来、他人观点）误导你，注意区分定位范围。

## 二、六大题型解法及各自选项特征

### 1. 细节题
- **标志**：what, when, how, 因果等具体信息提问；非其他题型即为细节题。
- **方法**：
  1. 在题干中集齐**所有**定位信息（不可偷懒），回**原文定位**。
  2. **精准比对定位句**，**逐词对照**，注意**偷换概念**。
  3. 若**难以找到明确定位句**，则遵循**细节服从主旨**原则，选与主题最相关的选项。
- **正确选项特征**：
  - **同义改写**（原文信息的另一种说法）。
  - 语气缓和、不绝对（常用 some, may, partly 等）。
- **干扰选项特征**：
  - **正反混淆**：与原文意思相反。
  - **偷换概念**：替换核心名词或修饰对象。
  - **答非所问**：信息正确，但并非题干所问。
  - **不同内容拼接**：将不同处内容拼成一句，看似全对实则逻辑混乱。
  - **绝对化用词**：出现 only, all, never 等极端词。
  - **90%雷同**：绝大部分与原文相符，但10%的关键细节错误，需逐词比对。
  - **定位范围错误**：用现在代替过去、他人观点代替作者观点等。

### 2. 例证题
- **标志**：example, case 等 + to, demonstrate, prove, illustrate。
- **核心原则**：**例子本身不重要，所支持的观点才是答案**。
  - 观点通常出现在例子前（80%）或例子后（20%）。
- **方法**：
  - 定位到例子后，往前或往后找观点句。
  - 可用**代词**（如 this, such）来**界定例子的起止范围**。
  - 例子也要读（因为观点抽象，例子具体易懂），但绝**不能选就事论事的选项**。
- **正确选项特征**：
  - 并非描述例子本身，而是例子所支撑的抽象观点。
- **干扰选项特征**：
  - **就事论事**：直接描述例子本身的具体事实，这是最大干扰源。
  - **偏离观点**：内容正确但与例子要证明的观点无关。

### 3. 中心思想题
- **标志**：mainly about, discuss, the best title, purpose 等。
- **方法**：
  1. **串线法**：串联各段首句/末句，注意转折处。
  2. **中心句**：文章开头提问的回答；或独立成段的一句话，往往即为中心。
  3. **中心词**：文中反复高频出现（5次以上）的词或同义替换。
  4. **回头作文**：拿捏不定时，假想以此标题自己会怎么写，再与原文比对。
  5. **二次串联题干**：通读全文后再串联题干，进一步确认主旨。
- **三个补充窍门**：
  - “否定词 + 比较级” 常译为最高级。
  - 注意并列结构的省略。
  - 分词作状语时常常表因果。
- **正确选项特征**：
  - 包含文章高频中心词或其同义替换。
  - 覆盖全文主线，不片面。
- **干扰选项特征**：
  - **范围太窄**：仅概括某一段落或细节，不能覆盖全篇。
  - **范围太宽**：包含文章未提及的内容，超出主题。
  - **偷换主题词**：文章讨论A，选项换成类近但不同的B。

### 4. 作者态度题
- **标志**：attitude，或问作者对某事的态度（那件事通常就是文章主题）。
- **方法**：
  - 先**汇总选项词汇**：正面、负面（否定、怀疑）、中立。
  - **抓满含深情的形容词、副词**（⭐）；**抓转折处**（⭐⭐）；**抓情态动词**（尤其后接 not 结构）。
  - 结合**中心思想**题的方法（**串线法、中心句**等）判断态度。
- **正确选项特征**：
  - 多为正面支持、负面批评、或客观中立。
  - 有明显情感倾向时，准确对应原文褒贬。
- **干扰选项特征**（含小墓碑选项）：
  - 永远不选的“小墓碑”：
    - 漠不关心类：uninterested, unconcerned, indifferent
    - 困惑迷惑类：confused, puzzled
    - 偏见歧视类：biased, prejudice, discriminate
    - 蔑视主观类：contemptuous, subjective
  - **过度强烈**：作者仅是轻微质疑，选项却用“鄙视、厌恶”等重词。

### 5. 猜词题
- **标志**：“xxx” most probably means...
- **方法**：
  - 回原文定位该词句，根据上下文逻辑关系（转折、并列、因果等）寻找同义词或反义词。
- **正确选项特征**：
  - 具有概括性，是上下文逻辑推出来的意思，而非词典里的常用义。
- **干扰选项特征**：
  - **字面理解**：直接给出该词最常见的表面意思，不结合语境，极易误选。

### 6. 推理判断题
- **标志**：infer, suggest, imply, **learn from**。
- **本质**：定位范围放大的细节题，但必须区分于例证题。
- **方法**：
  - 正确答案常为**原文信息的同义改写**（服从细节/主旨/逻辑）。
  - 推理题多在**转折处**，常需要**逻辑取反**（推出与前文相反的意义）。
  - 答案必须**源自原文**，不可主观引申。
- **正确选项特征**：
  - 原文信息的同义改写或**逻辑上的合理延伸**。
  - 语气缓和，不绝对（常用 some, may, partly 等）。
- **干扰选项特征**：
  - **主观引申**：脱离原文，凭常识或主观想象做题。
  - **绝对化用词**：出现 only, all, never 等极端词。
  - **颠倒逻辑**：将原文的逻辑关系倒置或窜改。

## 三、通用做题习惯与心态
- **先题后文，判断题型**：不同题型方法截然不同，最先一步**分清细节题、例证题**等。
- **逐词比对，不偷懒**：**正确答案是比出来的，不是凭感觉选出来的**。选项间“相同之处缩范围，不同之处见真章”。
- **不跳读，不加戏**：阅读理解建立在把每个词看对的基础上，**不过度推断，实事求是**，抓主旨重于逐字翻译。
- **可作标记，杀回马枪**：第一题往往因信息有限最难，**不确定时先标记**，读完后续段落后再回看确定。
- **互为相反，易含答案**：两个表意完全相反的选项，**往往其中一个就是正确答案**。
- **重复复习，反人性坚持**：听懂不够，需不断重复，对抗喜新厌旧。
- **相信老头出题是严谨的**：老头出题是很严谨的，**有相关证据时，要敢于排除选项**，这可是考研卷子，不可能不严谨。
